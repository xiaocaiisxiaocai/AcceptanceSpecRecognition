## ADDED Requirements

### Requirement: 数据库备份配置接口
系统 SHALL 提供数据库备份配置接口，用于读取当前配置、保存页面配置并手动触发一次备份。

#### Scenario: 读取备份配置
- **WHEN** 管理员访问数据库备份配置页面
- **THEN** API 返回当前备份配置、最近一次执行状态和可见备份文件列表

#### Scenario: 保存备份配置
- **WHEN** 管理员保存备份配置
- **THEN** API 持久化配置并返回保存后的当前配置

#### Scenario: 手动触发备份
- **WHEN** 管理员点击立即备份
- **THEN** API 执行一次数据库备份并更新最近一次执行状态
