## ADDED Requirements

### Requirement: 数据库备份配置页面
系统 SHALL 在配置管理中提供数据库备份页面，允许管理员配置备份计划并查看最近执行状态。

#### Scenario: 配置备份计划
- **WHEN** 管理员进入数据库备份页面
- **THEN** 页面允许配置启用状态、每日执行时间、备份目录和保留份数

#### Scenario: 查看备份状态
- **WHEN** 管理员查看数据库备份页面
- **THEN** 页面展示最近一次备份时间、结果、文件名和错误信息

#### Scenario: 手动立即备份
- **WHEN** 管理员点击立即备份
- **THEN** 页面显示执行中状态，并在完成后刷新最近备份结果
