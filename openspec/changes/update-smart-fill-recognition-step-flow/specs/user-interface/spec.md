## MODIFIED Requirements

### Requirement: 智能填充分步结构识别流
系统 SHALL 在智能填充页面将上传归属、结构识别确认、匹配配置和预览确认划分为职责独立的四个步骤，并能将确认后的识别结果组装为既有匹配预览配置。

#### Scenario: 上传与归属可用后触发识别
- **WHEN** 用户上传待填充文件并确定客户
- **AND** 用户在上传归属步骤发起识别
- **THEN** 页面调用智能结构识别 API
- **AND** 识别执行期间页面留在上传归属步骤展示加载状态
- **AND** 客户未确定时页面不得发起识别

#### Scenario: 识别成功后进入独立确认步骤
- **GIVEN** 智能结构识别返回至少一张可展示的表
- **WHEN** 页面完成识别结果和逐表配置组装
- **THEN** 页面自动进入独立的“识别确认”步骤
- **AND** 该步骤不再展示上传区、归属表单或 AI 辅助配置
- **AND** 页面从确认内容顶部或首个待确认 Sheet 开始展示

#### Scenario: 确认步骤集中处理结构结果
- **WHEN** 用户进入识别确认步骤
- **THEN** 页面展示来源摘要、识别汇总、Sheet 选择、业务范围和确认原因
- **AND** 当前 Sheet 的调整范围、确认学习操作及其阻断原因在清晰可见的操作区展示
- **AND** 页面不使用被禁用且原因笼统的底部按钮代替具体确认入口

#### Scenario: 待确认 Sheet 阻止进入匹配配置
- **GIVEN** 至少一个参与填充的 Sheet 仍为待确认或不可用状态
- **WHEN** 用户查看识别确认步骤
- **THEN** 页面显示剩余待确认 Sheet 数量和当前具体原因
- **AND** 用户确认该 Sheet、修正范围或将其设为不导入后才能继续

#### Scenario: 自动采用结果仍先展示确认页
- **GIVEN** 所有参与填充的识别结果均为自动采用
- **WHEN** 识别成功
- **THEN** 页面仍进入识别确认步骤展示参与填充和跳过范围
- **AND** 用户无需额外确认即可主动进入匹配配置步骤
- **AND** 页面不得从上传步骤直接触发匹配预览

#### Scenario: 识别失败留在上传步骤
- **WHEN** 识别请求失败或未生成任何可填充配置
- **THEN** 页面保留在上传归属步骤
- **AND** 页面在发起识别的操作附近显示失败原因和重试或手动处理入口

#### Scenario: 从确认步骤返回保留识别结果
- **WHEN** 用户从识别确认步骤返回上传归属步骤
- **THEN** 页面保留当前文件、归属和识别结果
- **AND** 用户上传新文件、删除文件或切换客户时页面清除失效的识别结果

#### Scenario: 混合匹配模式保守处理
- **GIVEN** 同一文档中同时存在仅规格表和项目规格表
- **WHEN** 页面准备从识别确认进入智能填充匹配配置或执行
- **THEN** 页面拆分请求或要求后端先支持表级匹配模式
- **AND** 不得把表级仅规格模式伪装为现有表配置字段
