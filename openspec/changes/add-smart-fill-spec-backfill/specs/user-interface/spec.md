## MODIFIED Requirements
### Requirement: 智能填充界面
系统 SHALL 提供基于统一多阶段匹配引擎的智能匹配与文档填充界面，并允许用户在预览阶段对本次导出的验收标准与备注做单行修订；用户也可以开启仅精确匹配模式，只采用 `项目+规格` 完全一致的结果；当用户手动修改过预览行内容时，系统 SHALL 允许用户选择性将这些修改回填到验收规格主数据。

#### Scenario: 匹配参数配置
- **WHEN** 用户进入匹配配置步骤
- **THEN** 系统提供 Embedding 服务、LLM 服务、高置信阈值、候选过滤阈值、实体判别参数与复核并行参数
- **AND** 系统提供 `仅精确匹配` 开关，说明开启后只采用 `项目+规格` 完全一致结果，未命中行可手工填写后导出
- **AND** AI 复核门禁固定开启，不再提供 `SingleStage / MultiStage` 或 `LLM 复核开关` 之类的策略切换
- **AND** 页面不再展示 `UseLlmReview`、`UseLlmSuggestion`、`SuggestNoMatchRows` 等旧兼容项

#### Scenario: 仅精确匹配预览
- **GIVEN** 用户开启 `仅精确匹配`
- **WHEN** 用户执行预览
- **THEN** 页面仍按现有规则要求 Embedding 服务可用
- **AND** 页面展示 `项目+规格` 完全一致的自动命中结果
- **AND** 页面展示未精确命中的行
- **AND** 页面不启动 AI 等价裁决流式复核展示

#### Scenario: 匹配预览
- **WHEN** 用户执行预览
- **THEN** 系统显示每行的匹配结果、最终决策状态、高置信状态与人工确认状态
- **AND** 对无法自动采用的样本给出明确提示
- **AND** 主表与详情以服务端返回的 `decision`、`confidenceLevel`、证据与 AI 裁决结果为准，不再由前端旧兼容字段自行推断

#### Scenario: 预览阶段编辑本次导出值
- **GIVEN** 某行存在于匹配预览表中
- **WHEN** 用户点击该行的 `编辑`
- **THEN** 系统打开独立编辑弹窗
- **AND** 弹窗只读展示 `项目` 与 `规格`
- **AND** 弹窗允许编辑 `验收标准` 与 `备注`
- **AND** 页面明确这些修改将用于本次导出，并可在执行填充前选择是否回填验收规格主数据

#### Scenario: 未命中行保存为手工填写
- **GIVEN** 某行没有匹配到验收规格
- **WHEN** 用户在编辑弹窗中填写 `验收标准` 或 `备注` 并点击 `保存并采用`
- **THEN** 系统保存该行手工填写值
- **AND** 自动将该行标记为已选择填充
- **AND** 预览表展示该行已手工填写状态
- **AND** 执行填充时不要求该行存在 `specId`

#### Scenario: 保存并采用
- **GIVEN** 用户已在编辑弹窗中修改 `验收标准` 或 `备注`
- **WHEN** 用户点击 `保存并采用`
- **THEN** 系统保存该行覆盖值
- **AND** 自动将该行标记为已选择填充
- **AND** 预览表中的 `验收标准` 与 `备注` 列优先显示覆盖值
- **AND** 页面展示该行已编辑状态

#### Scenario: 取消采用不清空覆盖值
- **GIVEN** 某行已经保存过本次导出的覆盖值
- **WHEN** 用户点击 `不填充`
- **THEN** 系统仅取消该行采用状态
- **AND** 不自动清空已保存的覆盖值

#### Scenario: 执行填充前选择回填验收规格
- **GIVEN** 用户已手动修改一行或多行预览结果
- **WHEN** 用户点击 `执行填充`
- **THEN** 系统弹出回填验收规格确认框
- **AND** 确认框仅展示用户手动修改过的行
- **AND** 确认框支持全选、取消全选和逐行勾选
- **AND** 确认框区分展示 `更新现有规格` 与 `新增规格`
- **AND** 用户可以选择 `不回填，仅执行填充`

#### Scenario: 已匹配行回填为更新规格
- **GIVEN** 某个手动修改行存在匹配到的 `specId`
- **WHEN** 用户在回填确认框中勾选该行并确认回填
- **THEN** 系统将编辑后的 `验收标准` 与 `备注` 回填到对应验收规格
- **AND** 不修改该验收规格的 `项目` 与 `规格`

#### Scenario: 未匹配行回填为新增规格
- **GIVEN** 某个手动修改行没有匹配到 `specId`
- **WHEN** 用户在回填确认框中勾选该行并确认回填
- **THEN** 系统以源文档行的 `项目` 与 `规格` 新增验收规格
- **AND** 新规格使用编辑后的 `验收标准` 与 `备注`
- **AND** 新规格归属到当前智能填充选择的客户、制程与机型范围

#### Scenario: 执行填充
- **WHEN** 用户确认匹配结果并点击填充
- **THEN** 系统执行填充；Word 提供结果文件下载，Excel 写回源文件后提供下载入口
- **AND** 对需要人工确认但未确认的样本阻止直接自动采用
- **AND** 页面提交当前文件中的 `specId`、人工确认状态、本次导出覆盖值与手工填充标记，不再透传旧 suggestion / compatibility 字段
