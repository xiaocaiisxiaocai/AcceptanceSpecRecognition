## ADDED Requirements

### Requirement: 智能填充执行前汇总验收规格写入决策

系统 SHALL 在执行智能填充前，将本次已选择参与填充且属于“AI/普通可填充”或“需要确认”的记录汇总到一个悬浮确认框，供用户决定是否写入验收规格库。

#### Scenario: 一个确认框展示全部相关记录
- **GIVEN** 本次执行跨一个或多个 Sheet 包含相关候选
- **WHEN** 用户点击执行填充
- **THEN** 页面在一个可滚动确认框中展示全部相关记录
- **AND** 不按记录逐个弹框
- **AND** 不因当前筛选、分页或活动 Sheet 漏掉其他已选择记录

#### Scenario: 展示覆盖判断所需的前后值
- **WHEN** 页面展示某条写入决策记录
- **THEN** 页面同时展示数据库已有的项目、规格、验收标准、备注
- **AND** 展示本次当前行将写入的项目、规格、验收标准、备注
- **AND** 用户可以直观看出原值与新值差异

#### Scenario: 逐行或批量选择写入决策
- **WHEN** 用户处理汇总确认框
- **THEN** 每行可选择“覆盖已有”“增加一条”或“跳过写库”
- **AND** 页面提供“全部覆盖”“全部增加”“全部跳过”批量动作
- **AND** 每行默认选择“跳过写库”

#### Scenario: 跳过写库仍继续填充文件
- **GIVEN** 某行已选择参与本次文件填充
- **AND** 用户对该行选择“跳过写库”
- **WHEN** 用户确认并执行
- **THEN** 系统不修改或新增验收规格库记录
- **AND** 仍按当前匹配结果填充该行的目标文件

#### Scenario: 不绕过既有人工确认门禁
- **GIVEN** 某条“需要确认”记录尚未通过既有人工采用门禁
- **WHEN** 用户准备执行填充
- **THEN** 写入决策确认框不得把该记录自动变为可采用
- **AND** 系统继续按既有规则阻止未确认记录进入文件填充

#### Scenario: 精准直达与不可填充记录不进入决策框
- **WHEN** 系统汇总写入决策候选
- **THEN** “100%精准直达”“不建议填充”和“无匹配”记录不进入该确认框
