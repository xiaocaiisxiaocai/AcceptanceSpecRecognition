## ADDED Requirements

### Requirement: 智能填充写入决策保持验收规格主数据一致性

系统 SHALL 在现有验收规格数据模型中执行智能填充写入决策，并保持业务范围、来源和缓存一致性。

#### Scenario: 覆盖保留记录身份
- **GIVEN** 用户选择覆盖已有规格
- **WHEN** 写入成功
- **THEN** 系统保留原验收规格 ID
- **AND** 更新项目、规格、验收标准、备注和更新时间
- **AND** 不改变该记录的访问权限边界

#### Scenario: 新增记录使用当前业务归属
- **GIVEN** 用户选择增加一条
- **WHEN** 写入成功
- **THEN** 新记录归属于当前客户、机型、制程和当前有权业务组织
- **AND** 记录当前操作者和导入时间

#### Scenario: 跳过不产生持久化副作用
- **GIVEN** 用户选择跳过写库
- **WHEN** 系统完成回填决策处理
- **THEN** 验收规格、来源记录和 Embedding 缓存均保持不变
