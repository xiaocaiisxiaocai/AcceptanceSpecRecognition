# Change: 新增智能填充验收规格写入决策

## Why

智能填充当前只在用户手动修改验收或备注时弹出回填确认框，并根据是否存在匹配规格自动决定更新或新增。用户无法在执行前统一查看所有“AI/普通可填充”和“需要确认”记录，也无法明确选择覆盖已有规格、保留已有并新增，或仅跳过数据库写入。

## What Changes

- 在智能填充执行前，将本次已选择参与填充且属于“AI/普通可填充”或“需要确认”的记录汇总到一个悬浮确认框。
- 在同一确认框中完整展示所有候选记录，并允许逐行或批量选择“覆盖已有 / 增加一条 / 跳过写库”。
- “覆盖已有”使用当前行的项目、规格、验收标准和备注完整更新匹配到的验收规格；“增加一条”保留原记录并新增当前行；“跳过写库”不修改验收规格库但仍继续填充当前文件。
- 默认使用“跳过写库”，避免用户未明确选择时误改主数据。
- 扩展现有智能填充验收规格回填契约，显式承载写入决策，并保持旧请求的既有行为兼容。

## Impact

- Affected specs: `user-interface`, `api`, `data-storage`
- Affected code: 智能填充候选汇总、回填确认框与执行编排、匹配 API 契约、`SmartFillSpecBackfillAppService`、Embedding 缓存失效和相关前后端测试
- Data migration: 无数据库结构迁移
