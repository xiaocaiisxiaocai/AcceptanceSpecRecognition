# Change: 导入冲突改为模态框左右对比确认

## Why
当前导入流程在检测到数据库已有同键但内容不同的数据时，直接在页面下方用表格逐条选择“导入/跳过”。该交互不直观，无法清晰展示“数据库已有值”和“本次导入值”的对照关系，用户难以判断是否覆盖。

## What Changes
- 将导入冲突确认从页面内表格改为模态框交互。
- 模态框按条展示左右对比：左侧为数据库已有数据，右侧为本次待导入数据。
- 用户可逐条选择“覆盖导入”或“跳过”，并继续完成导入。
- 调整前端导入结果累计逻辑，确保多表导入且分批确认时统计结果准确。

## Impact
- Affected specs: `user-interface`
- Affected code: `web/src/views/data-import/index.vue`
