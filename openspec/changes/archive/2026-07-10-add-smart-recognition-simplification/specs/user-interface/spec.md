## ADDED Requirements

### Requirement: 数据导入智能识别两步流
系统 SHALL 在数据导入页面支持上传/目标选择后的智能结构识别流程，并保留手动配置兜底。

#### Scenario: 上传与目标选择后触发识别
- **WHEN** 用户在数据导入页面上传文件并选择客户
- **THEN** 页面调用智能结构识别 API
- **AND** 客户未选择时不得调用识别 API

#### Scenario: 高置信结果进入预览
- **GIVEN** 所有相关表的识别结果均为自动采用
- **AND** 识别结果满足现有 Word 或 Excel 导入接口必填列要求
- **WHEN** 识别完成
- **THEN** 页面展示识别摘要和导入预览
- **AND** 用户可继续执行现有导入流程

#### Scenario: 低置信结果进入确认卡
- **GIVEN** 至少一个相关表需要确认
- **WHEN** 识别完成
- **THEN** 页面展示内嵌确认卡
- **AND** 用户可逐表确认或进入手动配置高级模式

#### Scenario: 不满足导入必填列时不直达
- **GIVEN** 识别结果缺少当前导入接口必填列
- **WHEN** 页面处理识别结果
- **THEN** 页面不得直接提交导入
- **AND** 页面进入确认卡或手动配置高级模式

### Requirement: 智能填充智能识别两步流
系统 SHALL 在智能填充页面支持上传/归属选择后的智能结构识别，并能组装既有匹配预览配置。

#### Scenario: 归属可用后触发识别
- **WHEN** 用户上传待填充文件
- **AND** 客户选择已经确定
- **THEN** 页面调用智能结构识别 API
- **AND** 客户未确定时页面等待用户选择客户

#### Scenario: 自动采用后启动匹配预览
- **GIVEN** 识别结果全部自动采用
- **WHEN** 页面获得识别结果
- **THEN** 页面将识别结果转换为现有逐表预览配置
- **AND** 页面触发既有智能填充预览链路

#### Scenario: 混合匹配模式保守处理
- **GIVEN** 同一文档中同时存在仅规格表和项目规格表
- **WHEN** 页面准备调用智能填充预览或执行
- **THEN** 页面拆分请求或要求后端先支持表级匹配模式
- **AND** 不得把表级仅规格模式伪装为现有表配置字段

### Requirement: 智能结构识别确认卡
系统 SHALL 提供共享确认卡组件，用于展示低置信表并收集用户修正。

#### Scenario: 确认卡展示列选项
- **GIVEN** 识别 API 返回表头列表
- **WHEN** 页面展示确认卡
- **THEN** 项目、规格、验收和备注列选择器使用返回的表头生成选项
- **AND** 若返回表头为空，页面使用表格预览加载出的表头作为选项

#### Scenario: 确认卡提交修正明细
- **WHEN** 用户修改识别出的列并确认
- **THEN** 页面向确认 API 提交最终配置
- **AND** 页面只把用户改动过的字段作为修正明细提交
