## MODIFIED Requirements
### Requirement: 权限与组织管理界面
系统 SHALL 提供角色、用户、权限与组织层级的 Web 管理页面；其中系统用户在创建、编辑、展示时仅允许配置一个角色和一个组织，导航容器菜单需要支持独立菜单权限控制。

#### Scenario: 角色管理
- **WHEN** 用户访问角色管理页面
- **THEN** 系统显示角色列表，并支持维护菜单级、页面级、按钮级和 API 级权限

#### Scenario: 用户管理
- **WHEN** 用户访问用户管理页面
- **THEN** 系统显示用户列表，并支持分配单个角色与单个所属组织

#### Scenario: 创建或编辑用户选择组织
- **WHEN** 管理员在新增或编辑用户弹窗中配置组织
- **THEN** 页面使用单选组件，且不允许提交空组织

#### Scenario: 导航容器菜单受权限控制
- **WHEN** 当前用户缺少某个顶层菜单对应的 `menu:*` 权限
- **THEN** 左侧导航中不显示该菜单容器，即使其下仍存在页面定义

#### Scenario: 权限字典查看
- **WHEN** 用户访问权限字典页面
- **THEN** 系统显示当前菜单、页面、按钮与 API 权限编码清单
