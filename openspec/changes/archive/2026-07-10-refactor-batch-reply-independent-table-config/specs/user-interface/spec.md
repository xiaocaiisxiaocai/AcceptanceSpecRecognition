## ADDED Requirements

### Requirement: 批量回复页面使用步骤化文件工作区
系统 SHALL 在“批量回复”页面中使用“步骤 Tab -> 文件 Tab -> Sheet/表格 Tab”的工作区结构，确保用户始终在当前文件与当前表格上下文内完成配置。

#### Scenario: 顶层按步骤分 Tab
- **GIVEN** 用户进入“批量回复”页面
- **WHEN** 页面渲染主流程
- **THEN** 页面按“来源文件 / 目标文件 / 执行结果”展示步骤 Tab
- **AND** 不再将来源配置与目标配置混在同一个内容区块中

#### Scenario: 来源文件按文件与 Sheet 分层
- **GIVEN** 用户已上传来源文件
- **WHEN** 用户进入来源文件步骤
- **THEN** 页面先展示来源文件 Tab
- **AND** 在文件 Tab 内继续按 `Sheet/表格` 展示子 Tab
- **AND** 当前 Sheet/表格内直接展示行设置与项目列、规格列、验收列、备注列配置

#### Scenario: 目标文件按文件与 Sheet 分层
- **GIVEN** 用户已上传多个目标文件
- **WHEN** 用户进入目标文件步骤
- **THEN** 页面按“目标文件 -> Sheet/表格”展示多层级 Tab
- **AND** 每个目标表都允许单独配置行设置、列映射和是否参与执行

#### Scenario: 目标表允许显式选择来源表
- **GIVEN** 来源文件中存在多张来源表
- **WHEN** 用户配置某个目标表
- **THEN** 页面提供来源表选择下拉
- **AND** 默认带出首选来源表
- **AND** 用户可改为任意其他来源表

#### Scenario: Word 页面支持列映射
- **GIVEN** 来源文件或目标文件为 Word 文档
- **WHEN** 用户配置某张 Word 表格
- **THEN** 页面仍允许配置项目列、规格列、验收列和备注列
- **AND** 不要求 Word 使用固定列位

### Requirement: 批量回复页面支持按表预览而不是整批预检门禁
系统 SHALL 将批量回复的反馈方式调整为按表预览与按文件执行，不再要求用户先经过独立预检查区域。

#### Scenario: 当前目标表在本地上下文内预览
- **GIVEN** 用户已完成某个目标表的来源表选择和映射配置
- **WHEN** 用户点击该目标表的预览
- **THEN** 页面展示该目标表的逐行匹配与写回结果预览
- **AND** 页面展示不可写回原因（如缺列、重复键、键不一致）
- **AND** 预览结果展示在当前目标文件与当前 Sheet/表格上下文内

#### Scenario: 页面按文件判断是否可执行
- **GIVEN** 某个目标文件下存在多张参与执行的目标表
- **WHEN** 用户准备执行批量回复
- **THEN** 页面仅在该目标文件所有参与表都配置完整且可预览时允许执行该文件
- **AND** 其他未完成配置的目标文件不影响已完成文件的执行

#### Scenario: 执行结果独立展示
- **WHEN** 用户执行批量回复
- **THEN** 页面在结果区域按目标文件和目标表展示成功/失败结果
- **AND** 用户无需回到配置区域即可查看失败原因

#### Scenario: 页面移除独立预检查区域
- **GIVEN** 用户位于批量回复页面
- **WHEN** 页面展示来源文件、目标文件和执行结果步骤
- **THEN** 页面不再额外展示独立的预检查或“当前表回写预览”区域
- **AND** 用户不需要先完成一个单独的预检查步骤才能继续配置或执行
