## ADDED Requirements
### Requirement: 执行记录数据库持久化
系统 SHALL 在 MySQL 中持久化智能填充与批量回复的执行记录摘要，并将详情明细以数据库字段形式保存。

#### Scenario: 保存任务摘要与详情
- **WHEN** 系统保存一次执行记录
- **THEN** 数据库中保存任务级摘要字段
- **AND** 同时保存该任务的详情 JSON
- **AND** 不依赖本地 JSON 文件作为正式查询来源

#### Scenario: 详情按文件与 Sheet 组织
- **WHEN** 系统保存执行记录详情
- **THEN** 详情 JSON 按 `文件 -> Sheet -> 行记录` 层级组织
- **AND** 每条行记录都包含状态、置信度百分比与人工选择标记

### Requirement: 执行记录摘要支持列表查询
系统 SHALL 为执行记录建立面向列表分页与筛选的结构化摘要字段与索引。

#### Scenario: 按任务摘要分页
- **WHEN** 用户按时间倒序查询执行记录列表
- **THEN** 系统使用任务级摘要字段完成分页与排序
- **AND** 不要求从详情 JSON 现场计算总行数、已采用数或人工选择数
