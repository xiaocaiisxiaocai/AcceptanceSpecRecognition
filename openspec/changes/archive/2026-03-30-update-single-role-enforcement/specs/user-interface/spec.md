## MODIFIED Requirements
### Requirement: 权限与组织管理界面
系统 SHALL 提供角色、用户、权限与组织层级的 Web 管理页面；其中系统用户在创建、编辑、展示时仅允许配置一个角色。

#### Scenario: 角色管理
- **WHEN** 用户访问角色管理页面
- **THEN** 系统显示角色列表，并支持维护页面级、按钮级和 API 级权限

#### Scenario: 用户管理
- **WHEN** 用户访问用户管理页面
- **THEN** 系统显示用户列表，并支持分配单个角色与所属组织

#### Scenario: 创建或编辑用户选择角色
- **WHEN** 管理员在新增或编辑用户弹窗中配置角色
- **THEN** 页面使用单选组件，且不允许提交空角色

#### Scenario: 组织层级管理
- **WHEN** 用户访问组织管理页面
- **THEN** 系统显示公司、事业部、部门、课别的层级结构，并允许按实际情况跳级配置

#### Scenario: 权限字典查看
- **WHEN** 用户访问权限字典页面
- **THEN** 系统显示当前页面、按钮与 API 权限编码清单
