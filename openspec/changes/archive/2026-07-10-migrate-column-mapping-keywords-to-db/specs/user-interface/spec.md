## MODIFIED Requirements

### Requirement: 配置管理界面
系统 SHALL 提供 AI 服务、Prompt 模板与列映射规则的 Web 配置页面。列映射规则页面 SHALL 能维护包括内置默认词在内的全部表头字段识别词，并提供"恢复默认词"操作。

#### Scenario: AI服务配置
- **WHEN** 用户访问AI配置页面
- **THEN** 系统显示AI服务列表并支持新增、编辑、删除

#### Scenario: 连接测试
- **WHEN** 用户点击测试连接按钮
- **THEN** 系统测试AI服务连接并显示结果

#### Scenario: Prompt 模板配置
- **WHEN** 用户访问 Prompt 模板页面
- **THEN** 系统显示系统模板场景列表并支持编辑、预览测试与恢复默认
- **AND** 页面不再以"设为默认模板"作为主操作

#### Scenario: 列映射规则配置
- **WHEN** 用户访问列映射规则页面
- **THEN** 系统显示列映射规则列表（含内置默认词）并支持新增、编辑、删除
- **AND** 用户对某表头词的新增/停用/删除会改变后续文档识别结果

#### Scenario: 恢复默认词
- **WHEN** 用户在列映射规则页面点击"恢复默认词"
- **THEN** 系统补齐缺失的内置默认词且不改动手动、学习与客户级规则
- **AND** 界面提示"删除单个内置词后可通过恢复默认词补齐；重启只在某字段内置词全空时兜底补齐"
