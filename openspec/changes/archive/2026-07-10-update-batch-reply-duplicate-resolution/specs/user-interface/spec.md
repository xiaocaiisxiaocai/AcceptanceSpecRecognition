## ADDED Requirements
### Requirement: 批量回复界面支持重复键冲突弹窗处理
系统 SHALL 在批量回复页面的当前 Sheet/表格上下文内，以弹窗方式引导用户处理重复的“项目 + 规格”冲突，而不是只显示底部错误标签。

#### Scenario: 预览时弹出冲突处理对话框
- **GIVEN** 用户在某个目标 Sheet/表格点击“预览回写”
- **AND** 后端返回结构化重复键冲突
- **WHEN** 页面接收到预览响应
- **THEN** 页面在当前文件与当前 Sheet/表格上下文内弹出冲突处理对话框
- **AND** 对话框展示每个冲突组的键值、来源类型、相关行与候选内容

#### Scenario: 用户确认策略后重试当前表预览
- **GIVEN** 用户已经在对话框中为每个冲突组选择处理策略
- **WHEN** 用户点击确认处理
- **THEN** 页面携带该策略重新请求当前表预览
- **AND** 预览结果继续展示在当前 Sheet/表格区域内

#### Scenario: 不恢复独立预检查区
- **GIVEN** 用户正在批量回复页面处理重复键冲突
- **WHEN** 页面展示冲突处理与预览结果
- **THEN** 页面仍保持“步骤 Tab -> 文件 Tab -> Sheet/表格 Tab”的工作区结构
- **AND** 不额外恢复独立预检查区域
