## ADDED Requirements
### Requirement: 智能填充一次性严格复用界面
系统 SHALL 在智能填充完成后提供一次性严格复用界面，用于将当前已确认的填充结果应用到其他完全相同模板的文件。

#### Scenario: 填充完成后显示复用入口
- **GIVEN** 用户已经完成当前文件的智能填充
- **WHEN** 页面展示填充完成状态
- **THEN** 页面显示“应用到相同验规”入口
- **AND** 页面说明该能力基于当前填充结果执行严格复用

#### Scenario: 复用流程明确不使用 AI 且不保存模板
- **GIVEN** 用户进入严格复用流程
- **WHEN** 页面展示复用说明
- **THEN** 页面明确提示该流程不会重新匹配、不会调用 AI
- **AND** 页面明确提示本次复用不会保存为长期模板

#### Scenario: 展示逐文件预检结果
- **GIVEN** 用户上传多个目标文件
- **WHEN** 系统完成严格复用预检
- **THEN** 页面逐个展示文件是否可应用
- **AND** 对不可应用的文件显示失败原因
- **AND** 对可应用的文件允许继续批量执行

#### Scenario: 批量复用执行与下载
- **GIVEN** 存在一个或多个通过预检的目标文件
- **WHEN** 用户确认执行严格复用
- **THEN** 页面展示批量执行结果
- **AND** 单文件场景提供直接下载
- **AND** 多文件场景提供统一打包下载
