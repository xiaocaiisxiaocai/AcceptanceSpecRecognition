# Change: 增加文档结构模板管理入口

## Why

智能结构确认会按客户保存文档结构模板，但当前系统没有列表、详情或删除入口。用户只能在识别结果中看到英文来源标记 `Template`，无法确认命中了哪个模板，也无法清理已经过时或识别错误的模板。

## What Changes

- 在“配置管理”下新增“结构模板”页面，支持按客户和模板名称查询已学习模板。
- 提供模板详情，按顺序展示每个逻辑区域的表头、数据范围以及项目、规格、验收、备注 A1 坐标。
- 支持管理员删除错误或过时模板；删除前必须二次确认，删除模板时同时删除关联区域。
- 将识别确认卡中的英文来源 `Template` 显示为“历史模板”，其他内部来源也使用中文展示，不改变后端识别协议。
- 保留现有“表格路由规则”：它继续作为人工维护的辅助覆盖信号，不与结构模板管理合并。

## Impact

- Affected specs: `api`, `user-interface`
- Affected code: 文档模板应用服务与 API 控制器、权限/导航清单、前端 API 封装、配置管理结构模板页面、智能结构确认卡
- Data compatibility: 不新增数据表，不修改现有模板结构；复用 `DocumentTemplates` 与 `DocumentTemplateRegions`
