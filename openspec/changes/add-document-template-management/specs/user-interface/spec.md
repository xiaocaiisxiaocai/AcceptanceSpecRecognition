## ADDED Requirements

### Requirement: 文档结构模板管理界面

系统 SHALL 在配置管理中提供“结构模板”页面，使授权用户能够查询、审阅和删除智能结构确认产生的客户级模板。

#### Scenario: 查看结构模板列表

- **WHEN** 用户进入“配置管理 → 结构模板”
- **THEN** 页面展示模板所属客户、名称、表格类型、区域数、使用次数和最近更新时间
- **AND** 用户可以按客户和关键字筛选

#### Scenario: 查看模板区域坐标

- **GIVEN** 一个模板包含一个或多个区域
- **WHEN** 用户打开模板详情
- **THEN** 页面按区域顺序展示项目、规格、验收和备注的 A1 范围
- **AND** 页面展示推导出的表头范围和数据行范围
- **AND** 区域坐标只读，提示用户应通过上传真实文件重新确认来修正模板

#### Scenario: 删除错误模板

- **WHEN** 有删除权限的用户选择删除模板
- **THEN** 页面显示包含客户、模板名称和区域数的二次确认
- **AND** 用户确认后删除模板并刷新当前列表

#### Scenario: 识别来源中文展示

- **GIVEN** 当前识别结果来源为 `Template`
- **WHEN** 页面展示识别证据
- **THEN** 页面显示“历史模板”而不是内部英文值

### Requirement: 结构模板与表格路由规则职责分离

系统 SHALL 将“结构模板”和“表格路由规则”作为两个独立配置概念展示。

#### Scenario: 保留表格路由规则入口

- **WHEN** 管理员查看配置管理菜单
- **THEN** 系统同时提供“结构模板”和“表格路由规则”入口
- **AND** 结构模板用于复用已确认的行列结构
- **AND** 表格路由规则用于人工覆盖表格类型或推荐结果
