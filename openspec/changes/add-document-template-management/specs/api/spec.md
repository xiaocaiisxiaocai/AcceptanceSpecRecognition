## ADDED Requirements

### Requirement: 文档结构模板管理 API

系统 SHALL 提供受权限保护的文档结构模板查询、详情和删除 API，不直接暴露持久化实体或内部 JSON 字段。

#### Scenario: 分页查询客户模板

- **WHEN** 管理员按客户、模板关键字和分页参数查询结构模板
- **THEN** 系统返回匹配模板的分页列表
- **AND** 每项包含模板标识、客户、名称、表格类型、区域数、使用次数和时间信息

#### Scenario: 查看多区域模板详情

- **GIVEN** 一个结构模板关联多个逻辑区域
- **WHEN** 管理员查询该模板详情
- **THEN** 系统按区域序号返回每个区域的表头位置、数据起止行和四列映射

#### Scenario: 查看旧单区域模板

- **GIVEN** 历史模板尚未持久化关联区域
- **WHEN** 管理员查询该模板详情
- **THEN** 系统根据模板主记录返回一个兼容的单区域结构

#### Scenario: 删除结构模板

- **WHEN** 有删除权限的管理员删除指定结构模板
- **THEN** 系统在同一事务中删除模板及其关联区域
- **AND** 后续识别不再命中该模板

#### Scenario: 无权限访问模板管理 API

- **WHEN** 当前用户缺少结构模板相应查看或删除权限
- **THEN** 系统拒绝对应请求
