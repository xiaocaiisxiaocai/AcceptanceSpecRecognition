## ADDED Requirements

### Requirement: 仪表盘只接受当前周期响应

系统 MUST 在仪表盘周期切换和刷新时取消或废弃旧请求，避免迟到响应覆盖当前状态。

#### Scenario: 快速切换统计周期

- **WHEN** 用户在旧周期请求完成前选择新周期
- **THEN** 页面取消或废弃旧周期请求
- **AND** 旧响应不得覆盖新周期摘要、趋势或周期选择

#### Scenario: 周期切换与手动刷新

- **WHEN** 用户只切换统计周期
- **THEN** 页面只刷新汇总和趋势
- **AND** 不重复请求与周期无关的最近执行列表
- **WHEN** 用户执行手动刷新
- **THEN** 页面分别刷新汇总和最近执行且每类只请求一次

### Requirement: 前端构建执行可阻断的包体积预算

系统 MUST 对主入口和关键异步页面的压缩后资源建立可执行预算，超限时构建门禁失败。

#### Scenario: 资源在预算内

- **WHEN** CI 完成生产构建并统计 gzip 资源
- **THEN** 主入口和 Dashboard 异步块满足已记录预算
- **AND** CI 保存或输出可比较的资源大小

#### Scenario: 资源超过预算

- **WHEN** 新依赖或全量注册使受控资源超过预算
- **THEN** 预算脚本返回非零退出码
- **AND** 不通过提高 Vite 告警阈值静默绕过

### Requirement: 核心导航支持键盘和语义访问

系统 MUST 让顶部操作、搜索结果和页面标签通过原生语义或等价 ARIA 模式支持键盘和读屏操作。

#### Scenario: 键盘使用搜索与设置

- **WHEN** 用户只使用键盘打开搜索、选择结果或打开系统设置
- **THEN** 每个入口可聚焦并可通过 Enter 或 Space 激活
- **AND** 焦点样式清晰可见
- **AND** 图标入口具有可读的无障碍名称

#### Scenario: 键盘操作页面标签

- **WHEN** 焦点位于页面标签组
- **THEN** 标签组使用 tablist/tab 语义和 `aria-selected`
- **AND** 左右键、Home、End 可移动焦点
- **AND** Enter/Space 可激活，Delete 可在允许时关闭当前标签

#### Scenario: 图标和头像语义

- **WHEN** 读屏软件读取顶部导航
- **THEN** 用户头像具有替代文本
- **AND** 仅图标按钮具有 aria-label
- **AND** 可点击目标的触达区域至少为 44×44px
