## ADDED Requirements

### Requirement: 仪表盘汇总返回连续每日趋势

系统 SHALL 在仪表盘汇总响应中按当前用户数据范围一次返回所选周期的摘要和连续每日趋势。

#### Scenario: 查询周期趋势

- **WHEN** 用户请求一个有效日期周期的仪表盘汇总
- **THEN** 响应包含该周期摘要和按日期排序的 `dailyTrend`
- **AND** 趋势查询遵循当前公司的数据范围和系统时区规则

#### Scenario: 日期没有业务记录

- **WHEN** 所选周期中的某一天没有导入或智能填充记录
- **THEN** `dailyTrend` 仍包含该日期
- **AND** 对应计数为零

#### Scenario: 不以逐日请求拼接趋势

- **WHEN** 客户端请求完整周期汇总
- **THEN** 服务端通过分组查询或等价有界方式生成趋势
- **AND** 不要求客户端为每个日期分别调用汇总接口
