## ADDED Requirements

### Requirement: 验收规格查询统一遵守组织范围
系统 MUST 让验收规格分组、普通搜索、全局搜索、重复排查和 AI 语义搜索使用服务端解析的同一组织数据范围。

#### Scenario: 管理员查看公司总体
- **WHEN** 管理员未指定部门执行验收规格查询或搜索
- **THEN** 系统可以返回当前公司范围内的数据
- **AND** 返回结果包含所属部门以便识别归属

#### Scenario: 管理员筛选具体部门
- **WHEN** 管理员选择当前公司内的有效部门执行任一验收规格查询或搜索
- **THEN** 系统只返回该部门的规格、分组、重复项或语义搜索候选

#### Scenario: 普通用户尝试跨部门搜索
- **WHEN** 普通用户提交其他部门标识调用任一验收规格查询或搜索接口
- **THEN** 系统返回 403
- **AND** 响应不包含其他部门的数据

### Requirement: 部门内批量替换验收规格备注
系统 MUST 提供预览和执行接口，在一个服务端授权的明确部门内对备注字段执行固定文本替换。

#### Scenario: 预览部门内备注替换
- **WHEN** 有权限的用户提交具体部门、非空查找文本和替换文本
- **THEN** 系统只统计该部门内备注包含查找文本的规格
- **AND** 返回受影响规格数、匹配次数、有限样例和确认信息

#### Scenario: 管理员在公司总体执行
- **WHEN** 管理员未选择具体部门请求预览或执行批量替换
- **THEN** 系统拒绝请求且不修改任何规格

#### Scenario: 普通用户伪造其他部门
- **WHEN** 普通用户提交其他部门标识请求预览或执行批量替换
- **THEN** 系统返回 403 且不修改任何规格

#### Scenario: 确认后执行替换
- **GIVEN** 用户已获得仍然有效的替换预览
- **WHEN** 用户确认执行
- **THEN** 系统在事务内完成该部门的字面替换
- **AND** 清除所有受影响规格的 Embedding 缓存
- **AND** 返回实际修改数量

#### Scenario: 预览后影响范围变化
- **GIVEN** 用户已经获得替换预览
- **WHEN** 执行前匹配规格或匹配次数已经变化
- **THEN** 系统拒绝使用旧确认执行并要求重新预览
