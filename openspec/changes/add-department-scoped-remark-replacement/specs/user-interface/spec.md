## ADDED Requirements

### Requirement: 验收规格页面支持部门内批量替换备注
系统 SHALL 在验收规格页面提供与当前部门范围绑定的备注批量替换交互。

#### Scenario: 管理员位于公司总体
- **WHEN** 管理员在“公司总体”范围点击批量替换备注
- **THEN** 页面不允许直接执行
- **AND** 引导管理员先选择一个具体部门

#### Scenario: 用户预览替换影响
- **GIVEN** 当前页面已经锁定一个具体部门
- **WHEN** 用户输入非空查找文本和替换文本并点击预览
- **THEN** 页面显示部门名称、受影响规格数、匹配次数和有限样例
- **AND** 未经二次确认不修改数据

#### Scenario: 用户确认批量替换
- **GIVEN** 替换预览仍然有效且用户具有批量替换权限
- **WHEN** 用户确认执行
- **THEN** 页面显示实际修改结果并刷新当前分组和列表
- **AND** 已打开的重复排查或 AI 搜索结果不得继续显示旧备注

#### Scenario: 用户取消批量替换
- **WHEN** 用户关闭弹窗或取消确认
- **THEN** 页面保留当前查询范围且不修改任何规格
