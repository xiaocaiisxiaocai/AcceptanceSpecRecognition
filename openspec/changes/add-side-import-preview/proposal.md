# Change: 在结构确认右侧提供实时待导入预览

## Why
数据导入的待导入清单当前位于结构确认卡下方的折叠区，用户调整 Sheet 范围后需要向下滚动才能核对结果和移出无关行。桌面宽屏存在可利用的横向空间，可以将配置与预览并置，缩短确认反馈路径。

## What Changes
- 将待导入清单从确认面板中拆成可复用的独立预览组件。
- 数据导入智能确认步骤在宽屏采用左侧结构配置、右侧实时预览的双栏布局。
- 右侧保留待导入统计、Sheet 分组、行选择、移出和恢复操作，并随现有预览状态实时更新。
- 窄屏自动恢复为上下排列，避免压缩表格可读性。

## Impact
- Affected specs: `user-interface`
- Affected code: 数据导入确认页、确认面板、待导入预览组件及相关前端测试
- Compatibility: 不改变 API、导入请求、预览数据结构和行移出语义
