## ADDED Requirements

### Requirement: 数据导入结构确认支持并排实时预览
系统 MUST 在数据导入智能结构确认步骤中，为宽屏用户并排展示结构配置和待导入清单，并复用当前预览状态实时反映配置结果。

#### Scenario: 宽屏并排确认与预览
- **GIVEN** 用户进入数据导入智能结构确认步骤
- **AND** 当前视口满足宽屏布局条件
- **WHEN** 页面展示识别结果和待导入数据
- **THEN** 页面在左侧展示 Sheet 与结构配置
- **AND** 页面在右侧展示待导入统计、Sheet 分组和数据表格
- **AND** 用户无需展开底部折叠区即可执行行选择、移出和恢复操作

#### Scenario: 结构调整后刷新右侧预览
- **GIVEN** 用户正在并排查看结构配置与待导入清单
- **WHEN** 用户修改并保存当前 Sheet 的识别范围
- **THEN** 右侧预览复用现有预览加载链路更新
- **AND** 页面不创建与现有预览状态并行的第二份数据源

#### Scenario: 窄屏恢复上下布局
- **GIVEN** 用户进入数据导入智能结构确认步骤
- **AND** 当前视口不足以同时容纳配置与表格
- **WHEN** 页面应用响应式布局
- **THEN** 结构配置与待导入清单按上下顺序展示
- **AND** 待导入表格仍保留全部选择和移出操作

#### Scenario: 大数据量预览保持可操作
- **GIVEN** 待导入清单包含超过单页容量的数据
- **WHEN** 完整预览加载完成
- **THEN** 右侧清单每页最多渲染 50 行并提供分页
- **AND** 用户滚动当前页数据时表头保持可见
- **AND** 用户切换页码后已选择的其他页数据保持选中
- **AND** 右栏、底部操作栏和页脚均保持在当前视口内
