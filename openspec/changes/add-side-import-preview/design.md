## Context
智能确认步骤当前先展示结构确认卡，再在 `DataImportConfirmPanel` 的折叠区中展示待导入清单。确认面板同时承担导入设置、文件摘要和预览表格，不能直接整体移动到右侧。

## Goals / Non-Goals
- Goals: 宽屏中让结构调整与待导入结果同时可见。
- Goals: 复用现有预览状态与行操作，不增加并行状态源。
- Goals: 保持紧凑工业管理界面，并为窄屏提供完整降级。
- Goals: 大数据量预览采用分页渲染，固定表头并保留跨页选择。
- Non-Goals: 修改导入、去重、冲突确认或完整数据加载逻辑。
- Non-Goals: 修改完成步骤和高级模式的现有确认面板布局。

## Decisions

### 1. 提取独立待导入预览组件
从 `DataImportConfirmPanel` 提取待导入统计、操作栏和按 Sheet 表格。确认面板继续通过该组件展示原有折叠预览，智能确认步骤则直接在右栏复用它。

### 2. 仅智能确认步骤启用双栏
桌面端使用左侧结构确认、右侧预览的双栏网格。导入设置与文件摘要保留在左侧下方，完成步骤和高级模式保持现有流程。

### 3. 右栏使用视口内粘性工作区
右栏在宽屏内保持粘性并设置内部滚动区域，使用户滚动左侧长内容时仍能查看预览。低于布局断点时取消粘性并恢复上下排列。

### 4. 完整数据分页渲染并固定表头
完整预览仍按现有有界窗口加载，但右栏每页只渲染 50 行。Element Plus 表格使用固定高度数据区，表头与顶部单行操作栏保持可见；页码切换时合并当前页选择，保留其他页已选行。

## Risks / Trade-offs
- 右侧表格列较多，半宽下可能出现横向滚动；保留 Element Plus 表格的横向滚动能力并为右栏设置合理最小宽度。
- 同一预览组件存在两种宿主；通过单一事件契约和布局回归测试防止行为漂移。
- 完整预览可能与最后一次结构校正并发；旧配置取消属于正常并发控制，静默等待最新结构稳定后重试，不向用户显示错误提示。

## Migration Plan
仅前端组件重构，无数据迁移。回退时将预览组件恢复到确认面板折叠区并移除双栏容器即可。

## Open Questions
无。用户已确认采用桌面双栏、窄屏上下排列方案。
