## ADDED Requirements

### Requirement: 表格预览前端可视高度
前端 MUST 以视口剩余空间展示表格预览内容，避免固定小高度导致用户在局部区域内低效滚动。

#### Scenario: 预览表随视口伸缩
- **WHEN** 用户在 1080p 视口查看文档表格预览
- **THEN** 预览表使用页面剩余高度展示内容
- **AND** 主预览表不得使用固定三位数像素 `max-height` 限制可视行数

#### Scenario: 弹窗内表格使用视口相对高度
- **WHEN** 用户在弹窗中查看表格预览、差异或冲突明细
- **THEN** 表格高度使用视口相对值或弹窗内部剩余空间
- **AND** 小屏下内容保持可滚动且不溢出视口
