## ADDED Requirements

### Requirement: 前端视觉令牌
前端 MUST 使用统一设计令牌管理全局文字、背景、边框、语义色、业务决策色、diff 色、字号、圆角和阴影。

#### Scenario: 全局中性主题
- **WHEN** 用户访问任一业务页面
- **THEN** 正文、页面背景、表头和边框使用中性令牌
- **AND** 紫色主色仅用于按钮、链接、选中态、进度条、菜单激活等交互强调

#### Scenario: 禁止新增散装色值
- **WHEN** 开发者新增或修改 `web/src/views/**` 内的业务页面样式
- **THEN** 新增颜色使用 `var(--app-*)` 或 `var(--el-*)`
- **AND** 不新增未纳入令牌体系的十六进制色值

### Requirement: 前端紧凑密度
前端 MUST 在管理后台页面中采用紧凑密度，优先展示业务内容而不是装饰性留白。

#### Scenario: 全局控件尺寸
- **WHEN** 用户访问管理后台页面
- **THEN** Element Plus 默认控件尺寸不大于 32px
- **AND** 主内容区边距、卡片内边距和表格单元格 padding 不得显著压缩首屏可用内容区

#### Scenario: 页面头部紧凑
- **WHEN** 页面展示标题、筛选条件和主要操作
- **THEN** 页面优先使用单行或紧凑布局组织这些信息
- **AND** 不使用重复标题、副标题和说明横幅占用主要内容区域

### Requirement: 全高表格页面骨架
前端 MUST 为列表和预览类页面提供可随视口伸缩的全高表格区域。

#### Scenario: 列表页表格自适应
- **WHEN** 用户在 1080p 视口访问列表页
- **THEN** 页面表格区域随剩余视口高度伸缩
- **AND** 页面避免使用固定三位数像素高度作为主表格高度

#### Scenario: 简单 CRUD 工具栏
- **WHEN** 用户访问客户、制程、机型等简单 CRUD 页面
- **THEN** 搜索、筛选和主操作按钮展示在表格区域的紧凑工具栏中
- **AND** 不为少量筛选控件单独占用一整张搜索卡片

### Requirement: 向导页内容优先布局
前端 MUST 在向导式流程中压缩导航性内容占高，并保证当前步骤的业务内容优先展示。

#### Scenario: 向导页头部合并
- **WHEN** 用户访问数据导入或智能填充向导页
- **THEN** 页面将页标题与步骤导航合并为紧凑头部
- **AND** 首屏导航性内容占高不超过 80px

#### Scenario: 删除重复步骤说明
- **WHEN** 当前步骤已经通过步骤条表达位置和含义
- **THEN** 页面不再重复展示占用空间的步骤标题和长说明文案
- **AND** 必要说明通过提示、折叠区或局部辅助文本呈现

### Requirement: 统一前端组件视觉
前端 MUST 统一上传区、决策标签、diff 视图、弹窗宽度和结果提示的视觉规则。

#### Scenario: 上传区统一
- **WHEN** 用户在导入、智能填充或批量回填流程上传文件
- **THEN** 上传区使用一致的图标尺寸、边框、主文案、副文案和状态样式

#### Scenario: 决策标签统一
- **WHEN** 页面展示自动采用、需人工确认、拒绝、失败或 AI 裁决参与状态
- **THEN** 页面使用统一业务决策色令牌
- **AND** 不通过局部 `!important` 硬编码覆盖全局主题

#### Scenario: 弹窗宽度规格化
- **WHEN** 页面打开业务弹窗
- **THEN** 弹窗宽度使用 S、M、L、XL 四档规格之一
- **AND** 小屏下宽度不得溢出视口

### Requirement: 核心流程表格可视行数
前端 MUST 保证数据导入和智能填充等核心流程的主预览表具备足够可视行数。

#### Scenario: 智能填充预览表可视行数
- **WHEN** 用户在 1080p 视口执行智能填充预览
- **THEN** 预览表可见数据行数不少于 15 行
- **AND** 页面不得通过固定 500px 高度限制主预览表

#### Scenario: 数据导入预览表使用剩余视口
- **WHEN** 用户在数据导入流程查看表格预览
- **THEN** 表格预览区域优先使用剩余视口高度展示数据
- **AND** 页面不得通过固定 400px 高度限制主预览表
