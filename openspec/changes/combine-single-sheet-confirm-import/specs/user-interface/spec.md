## ADDED Requirements

### Requirement: 所选 Sheet 确认学习与导入一键执行

系统 SHALL 在数据导入确认页将所有已勾选 Sheet 的结构确认学习和开始导入合并为一个文件级有序操作，并避免在每个 Sheet 中展示语义重复的独立确认按钮。

#### Scenario: 单 Sheet 确认成功后开始导入

- **GIVEN** 本次仅勾选一张可确认且可导入的 Sheet
- **WHEN** 用户点击“确认、学习并开始导入”
- **THEN** 系统先提交该 Sheet 当前最终区域和字段映射
- **AND** 系统等待结构模板与列映射学习完成并刷新导入配置
- **AND** 系统加载完整待导入预览后开始正式导入
- **AND** 页面不再同时展示独立的“开始导入”按钮

#### Scenario: 多 Sheet 一次确认后开始导入

- **GIVEN** 本次勾选多张可确认且可导入的 Sheet
- **AND** 用户可能已在不同 Sheet 中调整识别范围或列映射
- **WHEN** 用户点击唯一的“确认所选 Sheet、学习并开始导入”
- **THEN** 系统按工作表顺序提交每张待确认 Sheet 的当前最终草稿
- **AND** 已经自动采用的 Sheet 不重复提交学习
- **AND** 全部确认成功后系统只刷新一次导入配置和完整预览
- **AND** 系统随后开始包含全部已勾选 Sheet 的正式导入
- **AND** 用户无需切换 Sheet 逐个点击确认

#### Scenario: 确认失败时不得导入

- **GIVEN** 单 Sheet 一键操作已经开始
- **WHEN** 结构确认、学习或导入配置刷新失败
- **THEN** 页面显示对应失败信息
- **AND** 系统不得继续正式导入

#### Scenario: 未勾选 Sheet 不参与批量操作

- **GIVEN** 文件包含未勾选的 Sheet
- **WHEN** 用户执行文件级确认学习与导入
- **THEN** 系统不得学习或导入未勾选 Sheet
- **AND** 未勾选 Sheet 不得阻塞其他已勾选 Sheet

#### Scenario: 已勾选 Sheet 配置不完整

- **GIVEN** 至少一张已勾选 Sheet 缺少必填列或存在无效范围
- **WHEN** 用户查看文件级主操作
- **THEN** 系统阻止批量确认与正式导入
- **AND** 页面明确显示待处理 Sheet 数量并可定位到对应 Sheet

#### Scenario: 多 Sheet 中途确认失败

- **GIVEN** 文件级批量确认已经开始
- **WHEN** 任一 Sheet 确认或学习失败
- **THEN** 系统停止处理后续步骤并显示失败 Sheet
- **AND** 系统不得刷新正式导入配置或开始导入
- **AND** 用户重试时已经成功学习的 Sheet 不产生重复模板

#### Scenario: 智能填充不触发数据导入

- **GIVEN** 用户位于智能填充流程
- **WHEN** 用户确认并学习结构
- **THEN** 系统继续智能填充预览流程
- **AND** 系统不得触发数据导入
