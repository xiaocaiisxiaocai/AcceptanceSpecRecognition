## ADDED Requirements

### Requirement: 组织子树原子重定位
系统 MUST 在移动组织节点时原子维护父级、物化路径和深度，并保持所有稳定组织引用不变。

#### Scenario: 原子更新路径与深度
- **WHEN** 组织节点从原上级移动到新的合法上级
- **THEN** 源节点保存新的 `ParentId` 和基于新上级路径生成的 `Path`
- **AND** 全部后代保留相对路径关系并按统一深度差更新 `Path`、`Depth` 和 `UpdatedAt`

#### Scenario: 保持稳定引用
- **WHEN** 被移动子树中的节点已被用户、角色范围、验收规格或历史文件引用
- **THEN** 系统不修改节点 ID 及这些关系中的组织 ID
- **AND** 引用仍指向移动前的同一业务组织节点

#### Scenario: 移动失败整体回滚
- **WHEN** 移动校验失败、检测到非法历史路径或事务保存失败
- **THEN** 系统不保留部分父级、路径或深度更新
- **AND** 原组织树和关联引用保持一致

#### Scenario: 组织范围缓存失效
- **WHEN** 组织子树移动成功
- **THEN** 所有受影响组织节点的更新时间发生变化
- **AND** 后续组织子树范围查询按新路径重新计算可见组织集合
