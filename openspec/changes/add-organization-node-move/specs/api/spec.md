## ADDED Requirements

### Requirement: 组织节点安全移动 API
系统 SHALL 提供当前公司内非根组织节点的独立移动接口，并以独立权限和审计动作保护该操作。

#### Scenario: 移动组织子树
- **WHEN** 具备移动权限的管理员将当前公司内的组织节点移动到合法的新上级
- **THEN** 系统在同一事务中更新源节点的父级及源节点和全部后代的路径与深度
- **AND** 返回移动后的组织节点并记录组织移动审计

#### Scenario: 重复移动到当前上级
- **WHEN** 管理员把组织节点移动到其当前上级
- **THEN** 系统按幂等成功返回当前节点
- **AND** 不重复改写组织层级

#### Scenario: 拒绝非法移动
- **WHEN** 管理员尝试移动公司根节点、跨公司节点，或选择自身、后代、停用节点、课别或类型层级不合法的目标上级
- **THEN** 系统拒绝请求并返回具体中文原因
- **AND** 原组织树保持不变

#### Scenario: 缺少移动权限
- **WHEN** 已登录用户不具备 `api:org-unit:move` 权限并调用移动接口
- **THEN** 系统返回 403
- **AND** 不改变任何组织节点
