## ADDED Requirements

### Requirement: 组织节点移动交互
系统 SHALL 在组织管理页面提供明确、可确认且受权限控制的组织节点移动操作。

#### Scenario: 打开移动弹窗
- **WHEN** 具备 `btn:org-unit:move` 权限的管理员点击非根组织节点的“移动”操作
- **THEN** 页面显示源组织、当前上级和目标上级树形单选
- **AND** 公司根节点不显示移动入口

#### Scenario: 过滤非法目标上级
- **WHEN** 管理员选择目标上级
- **THEN** 页面禁用源节点自身、其后代、当前上级、停用节点及类型层级不合法的节点
- **AND** 服务端仍独立执行全部移动校验

#### Scenario: 确认移动影响
- **WHEN** 管理员选择合法目标上级准备移动
- **THEN** 页面显示将随源节点一起移动的节点数量
- **AND** 明确提示组织子树数据范围会按新层级立即变化，但用户和业务数据的组织归属不会丢失

#### Scenario: 移动成功或失败
- **WHEN** 移动接口成功
- **THEN** 页面关闭弹窗、刷新组织树并显示成功反馈
- **WHEN** 移动接口失败
- **THEN** 页面保留当前选择并显示服务端返回的具体原因
