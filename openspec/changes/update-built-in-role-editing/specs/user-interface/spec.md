## MODIFIED Requirements
### Requirement: 权限与组织管理界面
系统 SHALL 提供角色、用户、权限与组织层级的Web管理页面。

#### Scenario: 角色管理
- **WHEN** 用户访问角色管理页面
- **THEN** 系统显示角色列表，并支持维护页面级、按钮级、API 级和菜单级权限

#### Scenario: 内置角色编辑
- **WHEN** 用户编辑内置角色
- **THEN** 系统允许修改角色名称、描述、状态、权限配置与验收规格数据范围

#### Scenario: 用户管理
- **WHEN** 用户访问用户管理页面
- **THEN** 系统显示用户列表，并支持分配角色与所属组织

#### Scenario: 组织层级管理
- **WHEN** 用户访问组织管理页面
- **THEN** 系统显示公司、事业部、部门、课别的层级结构，并允许按实际情况跳级配置

#### Scenario: 权限字典查看
- **WHEN** 用户访问权限字典页面
- **THEN** 系统显示当前页面、按钮、API 与菜单权限编码清单
