## ADDED Requirements

### Requirement: 验收规格列表查询保持最新结果
前端 MUST 保证验收规格列表存在并发查询时，只有最新一次查询可以更新列表数据、总数和加载状态。

#### Scenario: 快速切换验收规格分组
- **WHEN** 用户在前一次列表请求完成前切换到另一个客户、机型或制程分组
- **THEN** 页面只展示最后选择分组对应的查询结果
- **AND** 较早请求完成时不得覆盖最新结果或提前结束最新请求的加载状态

### Requirement: 验收规格分页保留受控大页
前端 SHALL 为验收规格列表提供 `100 / 200 / 500` 三种每页数量，并以 100 条作为默认值。

#### Scenario: 用户选择每页五百条
- **WHEN** 用户在验收规格列表选择每页 500 条
- **THEN** 页面请求并展示最多 500 条当前查询结果
- **AND** 分页选择器不再提供每页 1,000 条
