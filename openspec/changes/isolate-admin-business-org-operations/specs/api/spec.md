## ADDED Requirements

### Requirement: 业务文件上传绑定单一组织归属
系统 MUST 在上传导入或智能填充源文件时绑定当前公司内的单一业务组织，并在后续业务接口中以该文件归属作为服务端可信范围。

#### Scenario: 管理员上传业务文件
- **WHEN** 管理员上传文件并选择当前公司内有效的非公司级组织
- **THEN** 系统将文件绑定到所选组织并返回归属组织标识与名称

#### Scenario: 管理员未选择有效组织
- **GIVEN** 当前公司已经存在有效的非公司级组织
- **WHEN** 管理员未提交业务组织、选择公司根节点、其他公司节点或已停用节点
- **THEN** 系统拒绝上传且不保存文件元数据

#### Scenario: 单组织公司兼容上传
- **GIVEN** 当前公司尚未配置任何有效的非公司级组织
- **WHEN** 管理员上传文件且未提交业务组织
- **THEN** 系统将文件绑定到管理员的有效根组织

#### Scenario: 普通用户上传业务文件
- **WHEN** 普通用户上传文件
- **THEN** 系统自动绑定该用户的唯一有效组织归属
- **AND** 普通用户提交其他组织标识时系统返回 403

### Requirement: 智能填充接口使用源文件业务归属
系统 MUST 让智能填充预览、LLM 复核、最终执行和规格回填使用同一个源文件业务归属范围。

#### Scenario: 管理员执行部门智能填充
- **GIVEN** 管理员上传的源文件已归属 A 部门
- **WHEN** 管理员依次调用预览、LLM 复核、执行和回填接口
- **THEN** 所有接口只读取或写入 A 部门范围内的验收规格
- **AND** 管理员的公司级权限不能使 B 部门规格进入该任务

#### Scenario: 回填请求缺少可信源文件
- **WHEN** 客户端提交规格回填但未提供可访问的源文件
- **THEN** 系统拒绝回填且不产生部分写入
