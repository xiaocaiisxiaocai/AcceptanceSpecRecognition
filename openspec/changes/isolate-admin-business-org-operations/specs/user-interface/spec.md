## ADDED Requirements

### Requirement: 数据导入与智能填充显示业务归属部门
系统 SHALL 在数据导入和智能填充共用上传区域中明确显示本次任务的业务归属部门。

#### Scenario: 管理员选择业务归属
- **WHEN** 管理员进入数据导入或智能填充上传步骤
- **THEN** 页面显示当前公司有效非公司级组织的必选下拉框
- **AND** 未选择时不能上传文件

#### Scenario: 普通用户查看业务归属
- **WHEN** 普通用户进入数据导入或智能填充上传步骤
- **THEN** 页面以只读方式显示其唯一组织归属
- **AND** 页面不提供切换到其他组织的控件

#### Scenario: 上传后保持归属稳定
- **WHEN** 文件已经上传成功
- **THEN** 页面锁定业务归属并在文件摘要中显示组织名称
- **AND** 用户移出当前文件后才可以重新选择归属并上传新文件

#### Scenario: 尚未配置业务部门
- **GIVEN** 当前公司没有有效的非公司级组织
- **WHEN** 管理员进入上传步骤
- **THEN** 页面显示当前任务将归属公司级根组织
- **AND** 页面提示配置部门后新任务将要求选择明确部门
