## ADDED Requirements

### Requirement: 重复项近似分析避免全量平方比较
系统 MUST 在近似重复分析前执行精确分组和稳定分桶，并对候选数和实际比较次数设置硬上限。

#### Scenario: 正常候选集执行分析
- **GIVEN** 候选不超过 2,000 条且桶内累计比较不超过 1,000,000 次
- **WHEN** 系统执行重复项分析
- **THEN** 系统先输出精确归一化重复组
- **AND** 只在稳定候选桶内计算近似相似度

#### Scenario: 比较过程中达到硬上限
- **WHEN** 实际近似比较次数即将超过 1,000,000
- **THEN** 系统停止比较并返回预算超限错误
- **AND** 不把当前已计算分组作为完整结果返回

#### Scenario: 分析请求被取消
- **WHEN** 请求取消信号到达
- **THEN** 候选枚举、分桶和相似度循环及时停止
- **AND** 不继续占用高成本匹配并发额度
