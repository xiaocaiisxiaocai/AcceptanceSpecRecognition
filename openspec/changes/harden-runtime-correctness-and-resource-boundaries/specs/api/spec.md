## ADDED Requirements

### Requirement: 控制器操作审计反映最终响应
系统 MUST 以最终 HTTP 结果记录控制器操作审计，并将审计持久化与业务工作单元隔离。

#### Scenario: 已处理业务冲突记录为冲突
- **GIVEN** 业务操作因并发或唯一约束冲突返回 `409`
- **WHEN** 系统写入该操作的控制器审计
- **THEN** 审计记录的响应状态为 `409`
- **AND** 不把该操作记录为成功或普通信息

#### Scenario: 业务上下文失败后写入审计
- **GIVEN** 业务工作单元的 `SaveChanges` 已经失败并保留失败实体状态
- **WHEN** 系统写入控制器审计
- **THEN** 审计使用独立依赖注入作用域和独立持久化上下文
- **AND** 不重新提交失败的业务实体

#### Scenario: 审计写入失败不覆盖业务结果
- **GIVEN** 业务操作已经形成最终响应
- **WHEN** 审计持久化失败
- **THEN** 系统保留原始业务响应
- **AND** 通过结构化日志记录审计失败及 `traceId`

### Requirement: API 错误响应使用真实 HTTP 语义
系统 MUST 根据稳定错误码返回对应 HTTP 状态，并且未知异常不得向客户端暴露内部实现信息。

#### Scenario: 已知业务错误映射
- **WHEN** 请求触发不存在、冲突、处理预算超限或限流
- **THEN** API 分别返回 `404`、`409`、`422` 或 `429`
- **AND** 响应保留稳定错误码、中文提示和 `traceId`

#### Scenario: 未知异常被收敛
- **WHEN** 服务端发生未映射异常
- **THEN** API 返回 `500`
- **AND** 响应不包含堆栈、SQL、内部路径或异常类型

### Requirement: 高成本 API 支持取消与预算拒绝
系统 MUST 为重复分析和文件比较执行候选、操作量与并发预算，并在请求取消后停止继续处理。

#### Scenario: 重复分析超出预算
- **GIVEN** 候选数量超过 2,000 或预计比较次数超过 1,000,000
- **WHEN** 客户端请求重复分析
- **THEN** API 返回 `422`
- **AND** 提示用户缩小筛选范围
- **AND** 不返回未标明的不完整结果

#### Scenario: 文件比较超出预算
- **GIVEN** 文件比较将扫描超过 1,000,000 个单元格或等价节点，或生成超过 100,000 条差异
- **WHEN** 客户端请求比较
- **THEN** API 返回 `422`
- **AND** 不以进程内存异常或通用 `500` 结束

#### Scenario: 客户端取消高成本请求
- **WHEN** 客户端取消重复分析、文件解析或比较请求
- **THEN** 服务端停止后续枚举、比较和结果生成
- **AND** 清理本次请求创建的临时资源
