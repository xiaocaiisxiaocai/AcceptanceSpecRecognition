## ADDED Requirements

### Requirement: 异步页面结果绑定发起上下文
系统 MUST 让执行历史、语义搜索和批量预览的异步响应只更新其发起时的业务上下文。

#### Scenario: 快速切换执行记录
- **GIVEN** 用户先选择任务 A 且详情请求仍在进行
- **WHEN** 用户切换到任务 B
- **THEN** 页面取消任务 A 请求并递增请求代次
- **AND** 任务 A 的迟到响应不得覆盖任务 B 详情

#### Scenario: 切换语义搜索分组
- **GIVEN** 用户在客户、机型、制程分组 A 发起语义搜索
- **WHEN** 用户在响应返回前切换到分组 B
- **THEN** 页面取消旧请求并清空旧结果
- **AND** 分组 A 的响应和编辑动作不得写入分组 B

#### Scenario: 批量预览配置发生变化
- **GIVEN** 当前目标表已有可执行预览
- **WHEN** 上传会话、目标文件、目标表或影响写回的配置变化
- **THEN** 页面立即使该预览和 `canApply` 失效
- **AND** 只有匹配当前配置指纹的新预览可以恢复可执行状态

### Requirement: 智能填充执行历史支持完整回放与分页
系统 SHALL 使用服务端分页展示执行记录，并按需加载智能填充完整逐行回放。

#### Scenario: 浏览超过首批记录的历史
- **WHEN** 执行记录数量超过单页大小
- **THEN** 用户可以通过服务端分页或远程检索访问后续记录
- **AND** 页面不固定只加载第一页前 200 条

#### Scenario: 查看智能填充完整详情
- **WHEN** 用户打开 `smart-fill` 任务详情
- **THEN** 页面按需加载完整逐行回放 API
- **AND** 展示来源行、候选、证据、AI 裁决、人工覆盖和最终写回值

#### Scenario: 完整详情不可用
- **WHEN** 完整逐行回放请求失败但轻量概要仍可读取
- **THEN** 页面明确展示降级说明和重试入口
- **AND** 不把轻量概要描述为完整回放

### Requirement: 长任务页面失活时暂停连接并恢复对账
系统 MUST 在 SmartFill 页面失活时取消仍在运行的上传、识别、轮询和 SSE，并在重新激活时通过任务状态对账。

#### Scenario: 页面被 keep-alive 隐藏
- **WHEN** 用户离开 SmartFill 页面但组件未卸载
- **THEN** 页面取消本次视图拥有的上传、识别、轮询和 SSE
- **AND** 保留安全的步骤状态和 `taskId`

#### Scenario: 用户返回页面
- **WHEN** SmartFill 页面重新激活且存在 `taskId`
- **THEN** 页面先请求任务当前状态
- **AND** 只根据最新状态决定恢复结果、轮询或 SSE

### Requirement: 批量执行成功与下载结果分离
系统 SHALL 分别表达批量回复业务执行状态和结果文件下载状态。

#### Scenario: 执行成功但自动下载失败
- **WHEN** 后端已成功执行批量回复并返回 `taskId`
- **AND** 浏览器下载结果文件失败
- **THEN** 页面保留执行成功状态和 `taskId`
- **AND** 只提示下载失败并提供重试下载

### Requirement: 上传区移除文件不删除持久文件
系统 SHALL 把上传工作区的文件移除限定为当前流程状态操作。

#### Scenario: 用户移除当前上传文件
- **WHEN** 用户点击“移出当前流程”或“更换文件”
- **THEN** 页面清除当前流程中的文件引用和派生状态
- **AND** 不调用服务器持久文件删除接口
- **AND** 不使用“永久删除”语义误导用户

### Requirement: SmartFill 文件级确认覆盖旧逐表确认交互
系统 SHALL 以文件级统一确认作为 SmartFill 当前交互，不恢复每个 Sheet 卡片内的重复确认按钮。

#### Scenario: 多个 Sheet 等待确认
- **WHEN** 用户查看当前文件的智能识别结果
- **THEN** 页面提供一次文件级确认操作并按顺序处理需要确认的 Sheet
- **AND** 不在每个 Sheet 卡片内显示独立确认按钮
