## ADDED Requirements

### Requirement: 文件比较使用有界流式临时存储
系统 MUST 在文件比较中使用请求隔离临时文件和有界结果生成，避免为上传、解析和下载重复保留完整内存副本。

#### Scenario: 上传比较文件
- **WHEN** 客户端上传符合 50 MiB 单文件限制的比较文件
- **THEN** 系统把上传流写入请求隔离临时目录
- **AND** 不通过完整 `byte[]` 复制上传内容

#### Scenario: 流式生成比较下载
- **WHEN** 用户下载允许预算内的完整比较结果
- **THEN** 系统流式写入响应或耐久临时产物
- **AND** 不要求先把完整下载内容序列化到单一内存缓冲区

#### Scenario: 请求结束后清理临时文件
- **WHEN** 比较请求成功、失败或被取消
- **THEN** 系统清理本次请求拥有的临时目录
- **AND** 不删除其他请求或持久文件目录

#### Scenario: Linux 容器使用原生请求隔离
- **GIVEN** API 运行在受支持的 Linux x64 或 Arm64 容器中
- **AND** 容器提供可访问的 procfs，且 `/proc/self/fd` 可用于从固定元数据句柄精确重开数据句柄
- **WHEN** 系统创建、读取或清理文件比较临时资源
- **THEN** 系统使用固定目录句柄和不跟随符号链接的原生相对操作
- **AND** 目录与文件采用仅当前运行用户可访问的最小权限
- **AND** 符号链接、FIFO、设备或其他非普通文件必须快速拒绝并保留待巡检对象
- **AND** 不得回退到可跟随路径或递归删除未知条目的通用托管实现

#### Scenario: Linux 容器缺少句柄精确重开前置
- **GIVEN** API 运行在 Linux 上
- **AND** `/proc/self/fd` 不可访问或无法从固定元数据句柄精确重开数据句柄
- **WHEN** 系统需要读取既有文件比较临时资源
- **THEN** 系统明确拒绝该操作并保持失败关闭
- **AND** 不得退回到按原始名称重新打开资源

#### Scenario: Linux 文件系统缺少安全原子隔离能力
- **GIVEN** API 运行在 Linux 上
- **AND** 临时存储所在文件系统不支持无覆盖原子重命名
- **WHEN** 系统尝试发布或隔离文件比较临时资源
- **THEN** 系统明确拒绝该操作并保持失败关闭
- **AND** 不得以可能覆盖其他请求资源的重命名方式降级

### Requirement: 持久文件物理删除由幂等清理器执行
系统 MUST 由幂等后台清理器处理已标记待删除的持久文件，而不是在数据库提交后进行不可追踪的一次性删除。

#### Scenario: 清理成功
- **GIVEN** 文件记录处于 `PendingDeletion`
- **WHEN** 清理器成功删除物理文件
- **THEN** 系统完成对应元数据删除或归档

#### Scenario: 清理任务重复执行
- **GIVEN** 同一待删除记录因重试被再次处理
- **WHEN** 物理文件已删除或前次只完成部分步骤
- **THEN** 清理器安全收敛到完成状态
- **AND** 不删除不属于该记录的文件
