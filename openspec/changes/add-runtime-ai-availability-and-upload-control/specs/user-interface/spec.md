## ADDED Requirements

### Requirement: AI 辅助控件展示运行可用性

系统 MUST 在数据导入和智能填充页面按运行可用性自动采用 AI 服务，并在缓存页面恢复时刷新状态。

#### Scenario: 缓存页面返回后服务可用

- **GIVEN** 用户从业务页面跳转到 AI 配置并完成有效配置
- **WHEN** 用户返回 keep-alive 缓存的业务页面
- **THEN** 页面重新获取自动选择结果
- **AND** 无需整页刷新即可显示并采用当前可用服务

#### Scenario: 服务正在检测

- **WHEN** 自动选择状态为 `checking`
- **THEN** 页面显示正在检测
- **AND** 在结果确定前不允许发起声称使用 AI 的识别

#### Scenario: 发起识别时服务短暂处于检测中

- **GIVEN** 用户已经开启 AI 辅助疑难识别
- **WHEN** 数据导入或智能填充发起结构识别且自动选择暂时返回 `checking`
- **THEN** 页面在有上限且可取消的等待窗口内重新检测
- **AND** 若窗口内恢复为 `available`，识别请求 MUST 携带最新服务 ID 并启用 AI 辅助
- **AND** 页面不得提前显示已降级为规则识别
- **AND** 只有状态明确为 `unavailable` 或等待窗口结束后仍为 `checking` 时才使用规则识别

#### Scenario: 没有运行可用服务

- **WHEN** 自动选择状态为 `unavailable`
- **THEN** 页面关闭并禁用 AI 增强开关
- **AND** 明确说明规则识别仍可使用或 Embedding 流程被阻断的原因
- **AND** 仅对有权限用户显示检测或配置入口

### Requirement: 上传组件展示真实传输和处理阶段

系统 MUST 让共享上传组件绑定真实上传请求，展示可用的传输进度，并区分网络上传与服务端文档处理。

#### Scenario: 文件正在上传

- **WHEN** 浏览器正在向 API 传输文件
- **THEN** 页面显示真实百分比或已传字节
- **AND** 上传请求完成前组件保持 loading
- **AND** 用户可以取消仍在传输的请求

#### Scenario: 文件已上传正在解析

- **WHEN** 网络传输完成但表结构或文档元数据仍在读取
- **THEN** 页面显示“文件已上传，正在解析结构”等独立处理状态
- **AND** 不继续显示为正在上传

#### Scenario: 用户取消上传

- **WHEN** 用户取消仍在执行的上传
- **THEN** 页面不写入已上传文件状态
- **AND** 不把主动取消显示为失败 Toast
- **AND** 可以重新选择文件重试
