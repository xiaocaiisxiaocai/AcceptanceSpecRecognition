## ADDED Requirements

### Requirement: 验收规格引用次数可查看时间明细

系统 SHALL 允许用户从验收规格列表和详情中的引用次数查看按内容版本记录的引用时间明细。

#### Scenario: 非零引用次数打开明细
- **WHEN** 用户点击列表或详情中的非零引用次数
- **THEN** 系统打开该规格的引用历史抽屉
- **AND** 展示当前版本累计、已记录时间次数和时间不可追溯次数
- **AND** 默认加载当前内容版本的第一页历史

#### Scenario: 从未引用的规格不发起查询
- **WHEN** 某条规格当前引用次数为 0 且仍为初始内容版本
- **THEN** 界面以只读数字显示 0
- **AND** 不提供会触发空历史请求的入口

#### Scenario: 当前零次但存在旧版本历史
- **WHEN** 某条规格因内容变更进入后续版本且当前引用次数为 0
- **THEN** 界面仍允许用户点击 0 打开引用历史
- **AND** 用户可以切换为包含历史版本以查看变更前的引用记录

#### Scenario: 展示逐次引用记录
- **WHEN** 同一任务中多行采用同一规格
- **THEN** 界面分别显示每一次引用及其引用时间
- **AND** 时间相同时仍通过引用序号稳定区分

#### Scenario: 查询第一次和第二次引用时间
- **WHEN** 用户切换为最早在前
- **THEN** 界面按引用序号从小到大显示已知时间记录
- **AND** 用户可以直接查看第一次、第二次及后续引用时间

#### Scenario: 查看旧内容版本历史
- **WHEN** 用户切换为包含历史版本
- **THEN** 界面重新请求并显示当前与旧版本记录
- **AND** 每条记录标识内容版本及是否为当前版本

#### Scenario: 明确显示未知历史时间
- **WHEN** 引用历史为迁移前基线且引用时间为空
- **THEN** 界面显示“记录功能上线前，时间不可追溯”
- **AND** 仍显示该基线包含的引用次数
- **AND** 不显示伪造日期或当前日期

#### Scenario: 引用时间本地化
- **WHEN** 引用历史包含 UTC 时间
- **THEN** 界面使用系统现有日期时间格式化规则显示浏览器本地时间

#### Scenario: 服务端分页历史
- **WHEN** 引用历史超过一页
- **THEN** 用户可以切换页码
- **AND** 界面按服务端返回的记录总数和页大小更新分页状态

#### Scenario: 列表直接展示最近引用时间
- **WHEN** 验收规格存在可追溯的引用记录
- **THEN** 列表在独立的“最近引用时间”列显示所有内容版本中最近一次成功引用的本地时间
- **AND** 该列与表示验规内容修改时间的“更新时间”保持区分
- **AND** 从未引用或只有迁移前不可追溯次数时显示 `-`
