## ADDED Requirements

### Requirement: 验收规格引用历史按内容版本持久化

系统 SHALL 逐次持久化验收规格每次成功引用的内容版本和引用时间，并在内容变化后保留旧版本记录。

#### Scenario: 新引用持久化可追溯时间
- **WHEN** 系统持久化一次新的验收规格引用历史
- **THEN** 记录包含所属规格、非空内容版本、非空任务标识、任务内稳定序号和 UTC 引用时间
- **AND** 未来逐次记录代表的引用次数固定为 1

#### Scenario: 内容变化开启新引用版本
- **GIVEN** 某条验收规格已有当前版本引用次数和历史
- **WHEN** 项目、规格、验收或备注任一字段在归一化后发生实质变化
- **THEN** 系统递增该规格的引用内容版本
- **AND** 将新版本引用次数重置为 0
- **AND** 保留旧版本引用历史

#### Scenario: 等价更新不切换版本
- **WHEN** 验收规格更新仅存在首尾空格或空白可选值与空值的等价差异
- **THEN** 系统不递增引用内容版本
- **AND** 保留当前版本引用次数和历史

#### Scenario: 迁移已有引用次数
- **GIVEN** 应用迁移时某条规格已有非零引用次数
- **WHEN** 系统建立引用历史结构
- **THEN** 系统为其写入版本 1 基线历史
- **AND** 基线本次引用次数等于迁移前引用次数
- **AND** 基线任务标识和引用时间为空
- **AND** 系统不猜测或伪造历史发生时间

#### Scenario: 当前累计与历史合计一致
- **WHEN** 系统核对某条规格的当前引用版本
- **THEN** `ReferenceCount` 等于该版本全部引用历史 `OccurrenceCount` 的合计

#### Scenario: 删除规格同时删除历史
- **WHEN** 验收规格被成功删除
- **THEN** 数据库级联删除其引用历史
- **AND** 不影响其他规格的引用历史
