## ADDED Requirements

### Requirement: 验收规格 API 分页返回引用历史

系统 SHALL 提供受验收规格读取权限和数据范围保护的只读接口，分页返回引用时间历史及当前内容版本汇总。

#### Scenario: 默认查询当前内容版本
- **WHEN** 有权用户请求某条规格的引用历史且未要求包含历史版本
- **THEN** 响应只分页返回当前内容版本的记录
- **AND** 返回当前内容版本、当前引用次数、已记录时间次数和时间不可追溯次数

#### Scenario: 查询包含历史版本
- **WHEN** 有权用户请求包含历史版本的引用历史
- **THEN** 响应分页返回当前和旧内容版本记录
- **AND** 已记录时间次数和时间不可追溯次数汇总所选全部版本
- **AND** 每条记录包含内容版本、是否当前版本、本次引用次数和可空引用时间

#### Scenario: 最早或最新记录稳定分页
- **WHEN** 用户分页查询引用历史并选择最早或最新排序
- **THEN** 已知时间的逐次记录按请求方向排序
- **AND** 相同时间使用任务内序号和记录 ID 稳定排序
- **AND** 时间不可追溯的迁移基线通过独立汇总返回
- **AND** 每页数量被限制在 1 到 100

#### Scenario: 查询第一次和第二次引用时间
- **GIVEN** 某个内容版本没有迁移前不可追溯次数
- **WHEN** 用户按最早顺序查询引用历史
- **THEN** 第一条和第二条分页记录分别表示第一次和第二次引用
- **AND** 每条记录返回当前版本内的引用序号和引用时间

#### Scenario: 迁移前序号不可追溯
- **GIVEN** 某个内容版本存在迁移前不可追溯次数
- **WHEN** 用户查询逐次引用历史
- **THEN** 响应单独返回不可追溯次数
- **AND** 已知时间记录的引用序号从不可追溯次数之后继续

#### Scenario: 沿用规格访问边界
- **WHEN** 用户请求无权访问的规格引用历史
- **THEN** 系统返回 403
- **AND** 不泄露该规格的引用次数、时间或历史是否存在

#### Scenario: 规格不存在
- **WHEN** 用户请求不存在的规格引用历史
- **THEN** 系统返回 404

#### Scenario: 引用历史保持只读
- **WHEN** 客户端尝试通过验收规格创建或更新请求写入引用版本或引用历史
- **THEN** 请求契约不接受这些字段
- **AND** 系统仅通过成功智能填充和内容版本策略维护它们
