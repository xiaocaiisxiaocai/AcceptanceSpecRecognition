## ADDED Requirements

### Requirement: 智能结构识别复用请求级文档快照
系统 MUST 在单次智能结构识别请求中通过一个文档解析生命周期取得表信息和完整表数据，并且不得因确定性表头重定位再次打开同一源文档。

#### Scenario: 关闭 AI 的多工作表识别
- **GIVEN** 用户已关闭 AI 辅助疑难识别
- **WHEN** 系统识别一个包含多个工作表的 Excel 文件
- **THEN** 后端只通过一个工作簿解码生命周期取得识别所需的表信息和完整数据
- **AND** 返回的工作表名称、行列范围、表头映射和数据坐标保持现有契约

#### Scenario: 复杂表头重定位
- **GIVEN** 确定性识别发现表头不在已用区域首行或包含多行
- **WHEN** 系统重建识别用表头和数据区
- **THEN** 系统从当前请求已提取的完整表数据进行投影
- **AND** 不为该工作表重新打开源文档

### Requirement: 智能结构识别复用请求级规则规范化结果
系统 MUST 在单次智能结构识别请求中复用相同表头文本和规则模式的规范化结果，同时保持现有列头匹配语义。

#### Scenario: 区域扫描重复匹配规则
- **GIVEN** 工作表区域扫描需要让多行单元格与同一批列头规则比较
- **WHEN** 系统执行确定性表头和数据区域判定
- **THEN** 相同文本与规则模式在当前请求内只执行一次简繁和空白规范化
- **AND** Equals、Contains、Regex 与模糊匹配结果保持原有契约
