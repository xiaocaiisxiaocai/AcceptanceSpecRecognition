## ADDED Requirements

### Requirement: 数据导入预览使用受控并发
数据导入页面 MUST 在智能识别后以固定上限并发加载多个待预览工作表，同时保持文件作用域和结果归属正确。

#### Scenario: 多工作表预览
- **GIVEN** 智能识别结果中有多个工作表尚未加载预览
- **WHEN** 页面准备确认预览
- **THEN** 页面最多同时加载 2 个工作表预览
- **AND** 预览结果写回对应的工作表配置

#### Scenario: 加载期间切换文件
- **GIVEN** 多工作表预览请求仍在执行
- **WHEN** 用户上传或切换到另一个文件
- **THEN** 旧文件的迟到响应不得写入新文件配置
- **AND** 页面不得将旧请求报告为新文件加载成功
