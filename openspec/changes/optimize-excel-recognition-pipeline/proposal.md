# Change: 优化 Excel 智能结构识别链路

## Why
数据导入在关闭 AI 辅助后仍需等待较久。当前智能结构识别会为同一文件分别读取表信息和完整数据，复杂表头还会再次打开文件；识别完成后的多工作表预览又逐张串行加载，造成可避免的重复解析与等待。

## What Changes
- 智能结构识别通过一次文档快照同时获得表信息和完整表数据。
- 复杂表头基于已提取的完整表数据重新投影，不再为每张表重新打开源文件。
- 同一识别请求复用表头与规则模式的规范化结果，避免区域扫描按“单元格 × 规则”重复执行简繁转换。
- 数据导入的多工作表预览采用最多 2 个任务的受控并发，并保持结果归属、取消和过期响应保护。
- 增加解析快照、表头投影、规则匹配缓存和预览调度回归测试。

## Impact
- Affected specs: `api`, `user-interface`
- Affected code: 文档解析器契约、Word/Excel 解析器、列头规则匹配、智能结构识别应用服务、数据导入预览加载
- Compatibility: 不改变现有 HTTP 契约、识别结果字段和导入坐标语义
