## Context

现有实现分别具备管理员数量保护、进度缓存、上传校验、取消令牌和备份状态，但这些局部保护没有形成端到端边界：管理员有效期与并发写入未进入同一原子操作，进度缓存没有 owner，批量上传在进入 Application 前已被完整复制到内存，外部进程取消也没有产物补偿。

## Goals / Non-Goals

### Goals

- 让最后管理员保护在多实例、并发和角色有效期场景下保持正确。
- 让进度、临时文件和错误信息只对所属用户与公司可见。
- 让上传、数据库访问和外部进程在取消时释放资源并保持可恢复状态。
- 保持现有接口与历史账号兼容。

### Non-Goals

- 不修改匹配算法、候选排序或文档业务格式。
- 不引入消息队列、对象存储或新的数据库表。
- 不在本变更中重写 Git 历史、修改 AI 运行可用性协议或重设计前端壳层。

## Decisions

### Decision 1: 管理员边界在公司级跨实例锁内计算并提交

更新、停用和删除系统用户时，Application 先取得 `system-user-admin-boundary:{companyId}` 操作锁，再读取数据库最新状态、投影请求提交后的角色区间并验证。有效管理员必须同时满足用户启用、角色启用、角色代码为 `admin` 且当前时间位于角色有效期内；已知未来边界之间也不得形成管理员覆盖空档。锁持有到事务提交完成，后进入的并发请求必须基于最新结果重新校验。

### Decision 2: 进度缓存键包含 owner

进度内部键使用 `(companyId, userId, normalizedRequestId)`，响应仍返回原 `requestId`，从而保持 URL 和 JSON 兼容。请求标识限制长度和字符集；同一 owner 的运行中标识不得被重复启动覆盖。查询其他 owner 的标识统一返回 404。缓存只保存安全错误码和用户可读消息，详细异常进入脱敏日志。

### Decision 3: 上传输入使用流工厂和顺序持久化

API 在读取内容前校验文件数量、单文件大小和整批总字节；Application 逐文件打开只读流、写入会话临时目录、解析已落盘文件并释放当前流，不再构造整批 `byte[]`。取消或任一文件失败时删除本次新增文件且不提交 manifest。旧 preview 上传入口复用同一管道。

### Decision 4: 取消只在明确边界传播

通用 Repository、专用查询、事务和 `SaveChangesAsync` 增加尾部可选 `CancellationToken`，Application 传递请求或宿主 token。确实需要脱离请求继续完成补偿的路径必须显式使用独立 token，并通过注释和测试说明原因，禁止机械替换为 `CancellationToken.None`。

### Decision 5: 备份先生成临时产物再原子发布

`mysqldump` 输出写入唯一 `.partial` 文件。取消或异常时终止整个进程树、等待退出并清理 partial；只有进程退出码为 0 且压缩流完整关闭后才同目录原子改名为正式 `.sql.gz`。保留策略只处理正式文件。

### Decision 6: 运行日志永不包含业务原文

移除完整 Prompt、源项目、源规格、候选正文和模型自由文本日志。诊断只保留场景、字符数、哈希摘要、候选数量、结构化 verdict、耗时和 traceId；不提供可被生产误开的“完整 Prompt Debug”旁路。

### Decision 7: 新密码策略只影响新写入

创建用户和重置密码统一要求 12–200 字符，Application 再次执行同一策略，不能只依赖 MVC 注解。登录不按长度拒绝已有密码，避免强制迁移和锁死旧账号。

## Risks / Trade-offs

- 公司级操作锁会串行化同公司的系统用户写操作，但这些操作低频，换取管理员边界的确定性。
- 顺序上传降低单请求峰值吞吐，但显著降低内存峰值；后续如需并行只能使用明确的小并发预算。
- Repository 接口增加 token 会触发较多编译修正，实施时按写操作、大查询、普通查询分批完成并由编译器保证遗漏可见。

## Migration Plan

1. 先补安全回归测试，再切换进度 owner 和管理员锁。
2. 提升新密码策略并同步前端提示。
3. 移除敏感日志，贯穿高价值数据库链路取消。
4. 将 BatchReply 上传改为流式管道并验证补偿。
5. 最后切换备份 partial/原子发布并执行故障注入。

## Rollback Plan

- 所有 API 路径保持不变，可按主题提交回退内部实现。
- 上传流式切换失败时可回退到旧应用端口，但不得恢复无整批预算的并发内存复制。
- 备份新实现可回退进程适配器，不删除既有正式备份文件。
