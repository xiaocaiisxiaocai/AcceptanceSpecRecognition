## ADDED Requirements

### Requirement: 智能结构确认卡按推荐级别分组
系统 SHALL 在智能结构确认卡中按推荐导入、需要确认和建议跳过分组展示表格。

#### Scenario: 推荐表优先展示
- **GIVEN** 智能结构识别返回多张表
- **WHEN** 页面展示确认卡
- **THEN** 推荐导入的表优先展示
- **AND** 建议跳过的表默认折叠

#### Scenario: 用户可展开跳过表
- **GIVEN** 某张表被系统建议跳过
- **WHEN** 用户展开该表
- **THEN** 页面显示该表的表头、字段映射和跳过原因
- **AND** 用户可以手动改为参与导入或填充配置

### Requirement: 智能结构确认卡展示确认原因
系统 SHALL 在智能结构确认卡中展示 NeedConfirm 或 Skip 的具体原因。

#### Scenario: 显示缺列原因
- **GIVEN** 某张表因缺少规格列需要确认
- **WHEN** 页面展示该表
- **THEN** 页面显示缺少规格列的原因提示

#### Scenario: 显示非验收表原因
- **GIVEN** 某张表被识别为报价、Layout、Utility 或备品清单
- **WHEN** 页面展示该表
- **THEN** 页面显示“疑似非验收规格表”的跳过原因

### Requirement: 智能结构识别保留手动兜底
系统 MUST 在新增推荐和跳过分组后继续保留手动配置兜底。

#### Scenario: 用户覆盖系统推荐
- **GIVEN** 系统将某张表建议跳过
- **WHEN** 用户认为该表应导入
- **THEN** 用户可以手动选择字段并继续现有导入或填充流程
