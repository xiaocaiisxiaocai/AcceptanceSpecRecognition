# Change: 优化角色权限选择器

## Why

当前权限目录已达到 198 项，角色编辑弹窗仍按“菜单、页面、按钮、接口”展示四条长列表。按钮与接口权限数量最多，管理员难以按业务模块定位、核对和批量调整，技术编码也压过了权限的业务含义。

## What Changes

- 将角色权限选择区改为按权限类型切换、按业务资源分组的紧凑面板，优先改善按钮和接口权限的浏览效率。
- 增加名称/编码搜索、“仅看已选”、分组已选计数以及分组全选/清空操作。
- 使用业务名称作为主要文案，权限编码作为次要说明，保留管理员核对技术边界的能力。
- 保持现有 `permissionCodes` 请求格式、后端授权语义和保存接口不变，不自动联动或隐式授予权限。

## Impact

- Affected specs: `user-interface`
- Affected code: `web/src/views/config/auth-roles/components/*`、相关前端测试
- Data/API impact: 无数据库迁移，无 API 契约变更
