## MODIFIED Requirements
### Requirement: 数据导入界面
系统 SHALL 提供文档上传与导入的Web界面。

#### Scenario: 文件上传
- **WHEN** 用户点击上传按钮并选择文档
- **THEN** 系统上传文件并显示文件信息

#### Scenario: 表格预览
- **WHEN** 文件上传成功
- **THEN** 系统显示文档中表格列表与预览内容

#### Scenario: 列映射配置
- **WHEN** 用户选择目标表格
- **THEN** 系统允许配置项目、规格、验收、备注列

#### Scenario: 客户制程选择
- **WHEN** 用户完成列映射配置
- **THEN** 系统提供客户与制程选择器

#### Scenario: AI 疑似重复识别配置
- **WHEN** 用户进入导入确认步骤
- **THEN** 页面允许配置是否启用 AI 疑似重复识别、Embedding 服务、召回阈值、LLM 复核与高置信阈值

#### Scenario: 导入冲突确认
- **WHEN** 导入数据命中完全重复、同项目同规格差异或 AI 语义相近的既有规格
- **THEN** 系统弹窗展示数据库已有数据与待导入数据的左右对照
- **AND** 系统展示命中类型、相似度与可选的 LLM 复核说明
- **AND** 用户可以逐条选择覆盖已有或跳过

#### Scenario: 导入确认
- **WHEN** 用户点击导入按钮
- **THEN** 系统执行导入并提示结果
