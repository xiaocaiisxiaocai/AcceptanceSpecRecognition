## MODIFIED Requirements

### Requirement: 配置管理界面

系统 SHALL 提供 AI 服务、Prompt 模板与列映射规则的 Web 配置页面。列映射规则页面 SHALL 能维护包括内置默认词在内的全部表头字段识别词，并提供"恢复默认词"操作。AI 服务连接测试 SHALL 区分快速可达性检查与完整真实调用。

#### Scenario: AI服务配置

- **WHEN** 用户访问AI配置页面
- **THEN** 系统显示AI服务列表并支持新增、编辑、删除

#### Scenario: 快速连接测试

- **WHEN** 用户对 AI 服务执行快速测试
- **THEN** 系统验证 Endpoint 可达性与目标模型可见性
- **AND** 系统不要求模型完成真实推理

#### Scenario: 完整连接测试

- **WHEN** 用户对 AI 服务执行完整测试
- **THEN** 系统对已配置用途执行真实 Chat 或 Embedding 调用
- **AND** Ollama LLM 不得仅因 `/api/tags` 中存在模型就报告完整测试成功
- **AND** 系统显示安全的成功摘要或超时、失败信息

#### Scenario: Prompt 模板配置

- **WHEN** 用户访问 Prompt 模板页面
- **THEN** 系统显示系统模板场景列表并支持编辑、预览测试与恢复默认
- **AND** 页面不再以"设为默认模板"作为主操作

#### Scenario: 列映射规则配置

- **WHEN** 用户访问列映射规则页面
- **THEN** 系统显示列映射规则列表（含内置默认词）并支持新增、编辑、删除
- **AND** 用户对某表头词的新增/停用/删除会改变后续文档识别结果

#### Scenario: 恢复默认词

- **WHEN** 用户在列映射规则页面点击"恢复默认词"
- **THEN** 系统补齐缺失的内置默认词且不改动手动、学习与客户级规则
- **AND** 界面提示"删除单个内置词后可通过恢复默认词补齐；重启只在某字段内置词全空时兜底补齐"

#### Scenario: 旧 matching-knowledge 页面不可访问

- **WHEN** 用户尝试访问 matching-knowledge 配置页、分组作者视图或草稿生成入口
- **THEN** 系统不提供相关页面、导航、权限入口或旧提示文案
