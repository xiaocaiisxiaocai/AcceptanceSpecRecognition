## ADDED Requirements

### Requirement: 智能结构识别支持表内多个连续区域
系统 SHALL 在单个 Excel Sheet 或 Word 表格内识别重复表头块，并为每个通过确定性健康检查的数据块生成独立逻辑区域。

#### Scenario: 重复表头分割两个区域
- **GIVEN** 同一 Sheet 在第 8 行和第 125–126 行出现两组字段表头
- **AND** 两组表头后分别存在连续的项目和规格数据
- **WHEN** 系统执行智能结构识别
- **THEN** 系统生成第 9–112 行和第 128–143 行两个区域候选
- **AND** 章节说明、重复表头和区域之间的行不属于任一区域

#### Scenario: 单区域文件保持原行为
- **GIVEN** 表格只有一组可信表头和一个连续数据区
- **WHEN** 系统执行智能结构识别
- **THEN** 系统返回一个逻辑区域
- **AND** 其表头、列映射和数据范围与既有单区域结果等价

### Requirement: 多区域逐区执行确定性健康检查
系统 MUST 对每个区域独立检查坐标、重叠、有效数据比例、必需字段和合并单元格列冲突，只有所有必要检查通过的区域才允许自动采用。

#### Scenario: 区域重叠降级确认
- **GIVEN** 两个区域候选的数据范围发生重叠
- **WHEN** 系统执行健康检查
- **THEN** 系统不得同时自动采用这两个区域
- **AND** 返回可解释的范围冲突问题

#### Scenario: 规格列与验收列落在同一合并区域
- **GIVEN** 某区域的规格列和验收列对应同一个横向合并单元格
- **WHEN** 系统执行健康检查
- **THEN** 该区域降级为需要确认
- **AND** 系统不得把规格列自动作为验收写回列

#### Scenario: 已确认多区域模板稳定命中后自动采用
- **GIVEN** 用户已确认并保存包含多个区域的客户模板
- **AND** 当前文件的区域数量、坐标、表头、字段列和健康检查均与该模板一致
- **WHEN** 系统再次执行智能结构识别
- **THEN** 系统自动采用该多区域模板，不得仅因区域数量大于一而降级为需要确认
- **AND** 若发现新增区域、结构变化或任一区域校验错误，系统仍降级为需要确认并返回可解释问题

### Requirement: 区域执行严格限制在闭区间
系统 MUST 在数据导入和智能填充提取、匹配与写回时严格限制到每个区域的闭区间，不得仅依赖空行过滤推断区域终点。

#### Scenario: 非空章节行仍被排除
- **GIVEN** 两个有效区域之间存在项目列或规格列非空的校验说明行
- **WHEN** 系统执行导入或智能填充
- **THEN** 这些行因不在任何区域闭区间而被排除
- **AND** `FilterEmptySourceRows` 不承担章节边界识别职责
