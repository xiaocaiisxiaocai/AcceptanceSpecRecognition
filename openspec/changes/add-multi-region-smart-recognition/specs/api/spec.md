## ADDED Requirements

### Requirement: 智能结构识别返回表内多区域
系统 SHALL 在单个 Word 表格或 Excel Sheet 包含多个逻辑数据区时，以表级 `regions` 数组返回每个连续区域的结构，同时保留既有表级单区域字段作为第一个区域的兼容投影。

#### Scenario: Excel Sheet 返回两个逻辑区域
- **GIVEN** 一个 Excel Sheet 在第 8 行和第 125–126 行存在两组可用表头
- **AND** 对应数据分别位于第 9–112 行和第 128–143 行
- **WHEN** 客户端调用 `POST /api/smart-config/recognize`
- **THEN** 该表结果包含两个带稳定区域标识的 `regions`
- **AND** 每个区域包含表头位置、数据起止行、四列映射、置信度、来源、决策和问题
- **AND** 表级旧字段投影第一个区域以保持兼容

#### Scenario: 区域索引口径明确
- **GIVEN** 识别结果来自 Excel
- **WHEN** API 返回区域行列坐标
- **THEN** 区域内部继续使用解析表格的 0-based 相对索引
- **AND** API 或前端在调用工作表绝对坐标接口前统一转换为 1-based A1 坐标

### Requirement: 智能结构确认支持多区域学习
系统 SHALL 允许确认请求提交同一表的最终区域列表，并在确认后保存客户级区域模板和最终采用但尚未录入的列映射学习词。

#### Scenario: 确认两个区域并学习新表头词
- **GIVEN** 用户确认同一 Sheet 的两个区域
- **AND** 最终映射包含尚未录入的“细项”到项目字段
- **WHEN** 客户端调用 `POST /api/smart-config/confirm`
- **THEN** 系统保存或更新两个客户级模板区域
- **AND** 系统幂等保存“细项”到项目字段的客户级学习规则
- **AND** 重复出现的“规格”“OK/NG”和“Remark”不会产生重复规则

#### Scenario: 未确认结果不学习
- **WHEN** 客户端只调用识别或预览接口而未确认最终区域
- **THEN** 系统不得写入新的区域模板或列映射学习词

### Requirement: 导入和智能填充请求支持区域结束行
系统 SHALL 允许导入和智能填充请求为同一表提交多个区域，并为每个区域显式指定数据起始行和数据结束行。

#### Scenario: 智能填充只处理选定区域
- **GIVEN** 同一 Sheet 选择第 9–112 行和第 128–143 行两个区域
- **WHEN** 客户端发起智能填充预览或执行
- **THEN** 后端只提取这两个闭区间内的行
- **AND** 中间章节、后续章节和其他未选行不参与匹配或写回

#### Scenario: 旧单区域请求兼容
- **GIVEN** 客户端仍使用既有表级字段且未提交区域数组
- **WHEN** 后端处理导入或智能填充请求
- **THEN** 后端将其解释为一个默认区域
- **AND** 既有单区域流程行为保持不变
