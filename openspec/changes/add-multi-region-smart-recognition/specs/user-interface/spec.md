## ADDED Requirements

### Requirement: 智能结构确认卡展示业务范围而非底层参数
系统 SHALL 在数据导入和智能填充的默认确认卡中，将每个逻辑区域的字段映射显示为 A1 范围标签，并默认隐藏表头行数、数据起始行和列索引等技术参数。

#### Scenario: 两区域显示 A1 范围
- **GIVEN** `工作表1` 识别出第 9–112 行和第 128–143 行两个区域
- **AND** 项目、规格、验收和备注列分别为 C、D、I、J
- **WHEN** 页面展示识别确认卡
- **THEN** 项目范围显示 `C9:C112` 和 `C128:C143`
- **AND** 规格、验收和备注范围分别显示对应的 D、I、J 范围标签
- **AND** 页面显示区域数量、有效行数和忽略行数

#### Scenario: 表头位置使用自然语言
- **GIVEN** 两个区域表头分别为第 8 行和第 125–126 行
- **WHEN** 页面展示区域摘要
- **THEN** 页面显示“第 8 行、第 125–126 行”
- **AND** 默认视图不分别展示表头起始行、表头行数和数据起始行数字输入框

#### Scenario: 待确认展示区域级原因
- **GIVEN** 表格因旧模板漏区、区域结构变化或区域健康检查问题而需要确认
- **WHEN** 页面展示识别确认卡
- **THEN** 页面在待确认状态旁展示对应的区域级可解释问题
- **AND** 页面不得只显示“待确认”而隐藏后端已经返回的确认原因

### Requirement: 智能结构确认卡以业务范围作为唯一编辑入口
系统 SHALL 允许用户在范围摘要旁打开区域调整界面，并将业务范围作为结构配置的唯一编辑入口；系统内部兼容字段 SHALL 由最终范围和表头反推，不得在确认卡中形成第二套可编辑配置。

#### Scenario: 调整识别区域
- **WHEN** 用户点击“调整范围”
- **THEN** 页面打开不离开当前流程的区域编辑抽屉或弹窗
- **AND** Excel 用户可以直接按 `C9:C112` 格式新增、删除和修改项目、规格、验收及备注范围
- **AND** 系统从用户输入的 A1 范围反算数据起止行和字段列
- **AND** 项目范围留空时系统将该区域反推为仅规格模式，项目范围非空时反推为普通模式
- **AND** 保存前页面校验格式、跨列、范围越界、反向、字段行号不一致、重复列和区域重叠
- **AND** Word 用户继续使用真实行号和字段列配置

#### Scenario: 从数据范围向上反推单行表头
- **GIVEN** 某区域的数据范围从第 128 行开始
- **AND** 第 127 行不是有效表头，第 126 行包含当前项目、规格、验收和备注列对应的表头
- **WHEN** 用户保存该区域范围
- **THEN** 系统从第 127 行开始向上查找并采用最近的有效表头第 126 行
- **AND** 系统将该区域表头行数保存为 1
- **AND** 当第 126 行的单元格属于从第 125 行开始的合并区域时，系统读取该合并区域左上角的实际标题

#### Scenario: 确认卡不再展示重复高级配置
- **WHEN** 页面展示结构确认卡
- **THEN** 页面保留 `C9:C112` 等只读范围摘要和“调整范围”入口
- **AND** 页面不再展示模板名、字段列下拉框、仅规格开关、表头行、表头行数和数据起始行输入框
- **AND** 模板名使用识别到的工作表或表格名称

### Requirement: 确认后自动学习未录入映射
系统 SHALL 将智能确认卡的主确认动作同时用于确认业务范围、保存客户模板和学习最终采用但尚未录入的列映射，不要求用户另行进入规则管理页录入。

#### Scenario: 确认并继续触发学习
- **GIVEN** 用户确认的区域包含新的表头字段词
- **WHEN** 用户点击“确认并继续”
- **THEN** 页面提交最终区域和字段映射到确认 API
- **AND** 成功后继续现有导入预览或智能填充预览
- **AND** 页面可显示模板已保存或列映射已学习状态

#### Scenario: 识别阶段不静默学习
- **WHEN** 页面仅完成上传和识别但用户尚未确认
- **THEN** 页面不得把识别建议作为已学习状态展示
- **AND** 后端不得因页面预览自动写入学习规则

### Requirement: 智能填充不得以规格列代替验收目标列
系统 MUST 在智能填充区域缺少验收目标列时显示明确问题并阻止该区域执行，不得静默使用规格列作为验收列。

#### Scenario: 验收列缺失只确认该问题
- **GIVEN** 某区域已识别项目和规格范围但未识别验收目标列
- **WHEN** 页面展示区域确认卡
- **THEN** 页面标记该区域需要确认验收列
- **AND** 用户无需重新配置其他已高置信字段
- **AND** 该区域在验收列确认前不能进入写回执行
