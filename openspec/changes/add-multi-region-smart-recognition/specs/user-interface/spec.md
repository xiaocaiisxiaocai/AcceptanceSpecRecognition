## ADDED Requirements

### Requirement: Excel 数据导入与智能填充确认卡展示一致的可编辑区域结构

系统 SHALL 在 Excel 数据导入与智能填充确认卡的默认结构摘要中只紧凑、完整地展示每个逻辑区域的项目/规格/验收/备注 A1 数据范围，并通过同一个右侧“调整范围”抽屉提供数据行列配置；两个入口的默认摘要、抽屉和提交 SHALL 由各自当前表格的同一个结构草稿驱动。

#### Scenario: 两区域显示 A1 范围

- **GIVEN** `工作表1` 识别出第 9–112 行和第 128–143 行两个区域
- **AND** 项目、规格、验收和备注列分别为 C、D、I、J
- **WHEN** 页面展示识别确认卡
- **THEN** 项目范围显示 `C9:C112` 和 `C128:C143`
- **AND** 规格、验收和备注范围分别显示对应的 D、I、J 范围标签
- **AND** A1 范围只包含字段列和数据闭区间，不包含自动派生的第 8 行或第 127 行表头
- **AND** 每个 A1 范围完整显示起止坐标，不以省略号截断
- **AND** 页面显示区域数量、有效行数和忽略行数

#### Scenario: 默认卡片隐藏配置控件

- **GIVEN** 两个区域的数据分别从第 9 行和第 128 行开始
- **WHEN** 页面展示区域摘要
- **THEN** 默认卡片的结构配置区域只显示四个紧凑完整 A1 范围和“调整范围”入口
- **AND** 默认卡片不显示数据起止行输入、项目/规格/验收/备注列下拉、A1 编辑框、仅规格开关或表头参数

#### Scenario: 调整范围打开右侧抽屉

- **WHEN** 用户点击“调整范围”
- **THEN** 页面从右侧打开抽屉且不离开当前确认流程
- **AND** 抽屉默认将项目、规格、验收和备注横向排成四列，每个字段的起始单元格和结束单元格分为上下两行
- **AND** 每个字段第一行在起始坐标输入框后显示该起始单元格的实际内容，第二行在结束坐标输入框后显示该结束单元格的实际内容
- **AND** 端点输入框不显示前置可见标签，并通过包含业务字段名和端点示例的占位文字区分用途
- **AND** 起止单元格内容过长时界面允许省略显示，但必须提供完整悬浮提示；空白单元格必须明确显示为空白
- **AND** “添加数据区域”入口始终显示，用户无需展开即可创建第二个及后续区域
- **AND** 每个新增区域立即显示自己的四组起止单元格及对应的起止单元格内容
- **AND** 数据起始行、数据结束行、项目/规格/验收/备注列下拉、仅规格开关及区域复制/删除默认不显示
- **AND** 用户点击“展开更多配置”后才显示并允许操作这些低频配置
- **AND** 用户关闭并重新打开抽屉时恢复为只显示各区域端点编辑区及新增入口的收起态
- **AND** 抽屉不提供可编辑的表头起始行或表头行数控件
- **AND** 页面将表头派生为数据起始行上一行，并将 `headerRowCount` 固定为 `1`

#### Scenario: 待确认展示区域级原因

- **GIVEN** 表格因旧模板漏区、区域结构变化或区域健康检查问题而需要确认
- **WHEN** 页面展示识别确认卡
- **THEN** 页面在待确认状态旁展示对应的区域级可解释问题
- **AND** 页面不得只显示“待确认”而隐藏后端已经返回的确认原因

### Requirement: Excel 数据导入与智能填充行列配置和 A1 双向映射同一草稿

系统 SHALL 将 Excel 数据导入与智能填充右侧抽屉中常驻的四组起止单元格，以及展开后显示的数据行号和字段列下拉，作为同一个结构草稿的双向编辑视图，并从该草稿派生默认卡片的只读 A1 摘要；起止单元格内容仅作为该草稿当前坐标的只读预览，不得成为独立提交状态；结构草稿 SHALL 是确认、学习、预览和导入或填充的唯一来源。

#### Scenario: 手动行列配置生成 A1 数据范围

- **GIVEN** 某区域表头为第 8 行，数据为第 9–112 行
- **AND** 用户将项目、规格、验收和备注列分别选择为 C、D、I、J
- **WHEN** 用户在右侧抽屉中更新该区域草稿
- **THEN** 四个字段范围分别显示 `C9:C112`、`D9:D112`、`I9:I112` 和 `J9:J112`
- **AND** 关闭或收起抽屉后，默认卡片同步显示这些完整范围
- **AND** 页面不得把表头第 8 行包含进任一字段 A1 数据范围

#### Scenario: 编辑起止单元格回写行列

- **GIVEN** 某区域已有共享数据行和四个字段列
- **WHEN** 用户在右侧抽屉中把项目起始单元格修改为 `E10`，并把结束单元格修改为 `E120`
- **THEN** 系统将项目列更新为 E，并将共享数据起止行更新为第 10–120 行
- **AND** 系统保留其他字段列并以第 10–120 行重新生成其非空起止单元格
- **AND** 项目起始坐标后显示 E10 单元格的实际内容
- **AND** 项目结束坐标后显示 E120 单元格的实际内容
- **AND** 系统将唯一表头更新为第 9 行并保持 `headerRowCount = 1`
- **AND** 系统不得保留一套与行列草稿不一致的 A1 提交状态

#### Scenario: 数据起始行驱动唯一表头

- **GIVEN** 某区域的数据起始行为第 9 行
- **WHEN** 用户在右侧抽屉中直接修改数据起始行，或通过任一字段起始单元格修改共享数据起始行
- **THEN** 系统固定使用新数据起始行的上一行作为唯一表头
- **AND** 系统固定 `headerRowCount = 1` 并立即使用该行刷新四个字段列下拉标题
- **AND** 即使原文件存在合并或多行表头，系统也不得向上搜索、扩展或拼接其他表头行

#### Scenario: 仅规格模式必须显式选择

- **GIVEN** 用户正在右侧抽屉中配置 Excel 数据导入或智能填充区域
- **WHEN** 用户开启仅规格开关
- **THEN** 系统允许项目列和项目 A1 为空，并要求规格列、验收列和备注列有效
- **AND** 用户关闭仅规格开关时系统要求项目列、规格列、验收列和备注列都有效
- **AND** 清空或重新选择项目列不得自动改变仅规格开关

#### Scenario: 保存前校验统一结构草稿

- **WHEN** 用户确认 Excel 数据导入区域
- **THEN** 页面校验数据起始行位于工作表已用区域起始行之后，以保证其上一行可作为唯一表头
- **AND** 页面要求规格、验收和备注列始终有效，并在普通模式下同时要求项目列有效
- **AND** 页面校验 A1 格式、单列、范围越界、反向、重复字段列、字段行号一致和区域重叠
- **AND** 校验失败时阻止确认、学习、预览和导入，并定位到对应区域和字段

#### Scenario: Excel 智能填充复用数据导入范围抽屉

- **GIVEN** 当前流程为 Excel 智能填充
- **WHEN** 页面展示结构确认
- **THEN** 页面使用与 Excel 数据导入相同的紧凑 A1 摘要和右侧调整抽屉
- **AND** 页面支持相同的端点内容预览、添加数据区域和展开更多配置
- **AND** 抽屉修改写回智能填充当前表格的结构确认草稿，并继续通过智能填充既有确认与写回执行链路提交
- **AND** Word 继续使用既有真实行号与字段列配置，不要求采用 Excel 的 A1 摘要或右侧调整抽屉

### Requirement: 确认后自动学习未录入映射

系统 SHALL 将智能确认卡的主确认动作同时用于确认业务范围、保存客户模板和学习最终采用但尚未录入的列映射，不要求用户另行进入规则管理页录入。

#### Scenario: 确认并继续触发学习

- **GIVEN** 用户确认的区域包含新的表头字段词
- **WHEN** 用户点击“确认并继续”
- **THEN** 页面提交最终区域和字段映射到确认 API
- **AND** 成功后继续现有导入预览或智能填充预览
- **AND** 页面可显示模板已保存或列映射已学习状态

#### Scenario: 识别阶段不静默学习

- **WHEN** 页面仅完成上传和识别但用户尚未确认
- **THEN** 页面不得把识别建议作为已学习状态展示
- **AND** 后端不得因页面预览自动写入学习规则

### Requirement: 智能填充不得以规格列代替验收目标列

系统 MUST 在智能填充区域缺少验收目标列时显示明确问题并阻止该区域执行，不得静默使用规格列作为验收列。

#### Scenario: 验收列缺失只确认该问题

- **GIVEN** 某区域已识别项目和规格范围但未识别验收目标列
- **WHEN** 页面展示区域确认卡
- **THEN** 页面标记该区域需要确认验收列
- **AND** 用户无需重新配置其他已高置信字段
- **AND** 该区域在验收列确认前不能进入写回执行

### Requirement: 待导入清单支持选中无关项

系统 SHALL 在待导入清单提供“选中无关项”勾选项，将验收列和备注列同时为空的行加入当前选择，是否移出继续由既有“移出所选”操作决定。

#### Scenario: 勾选后选中验收和备注均为空的行

- **GIVEN** 待导入清单同时包含验收和备注均为空的行以及至少一个字段非空的行
- **WHEN** 用户勾选“选中无关项”
- **THEN** 系统只选中验收列和备注列同时为空的行
- **AND** 规格或项目内容不影响无关项判定
- **AND** 系统不得在用户点击“移出所选”前自动移出任何行

#### Scenario: 取消时只取消无关项选择

- **GIVEN** 用户已手工选中其他行并勾选了“选中无关项”
- **WHEN** 用户取消勾选“选中无关项”
- **THEN** 系统只取消验收列和备注列同时为空行的选择
- **AND** 用户此前手工选中的其他行继续保持选中状态
