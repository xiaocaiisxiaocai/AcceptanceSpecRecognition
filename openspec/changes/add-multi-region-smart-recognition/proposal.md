# Change: 支持单个 Sheet 多区域智能识别与范围学习

## Why

当前智能结构识别把一个 Excel Sheet 固定建模为一张连续表，只能保存一套表头、列映射和数据起止行。真实验收规范可能在同一 Sheet 内包含多段重复表头和多个有效数据区，现有模型要么漏掉后续数据，要么把中间章节和尾部资料误当成规格行。现有确认卡后来又把 A1 范围收口为唯一编辑入口，但单个字段范围无法独立表达数据边界和仅规格意图；若再同时开放表头与数据行号，还会产生表头晚于数据起始行等互相矛盾的配置。

## What Changes

- 智能结构识别允许一个 Sheet 输出多个逻辑数据区域，每个区域独立携带表头、连续数据范围、项目/规格/验收/备注列、置信度和问题原因。
- 数据导入和智能填充统一按逻辑区域执行，智能填充补齐数据结束行，避免从起始行一直读取到 Sheet 末尾。
- 客户级文档模板保存多个区域；旧单区域模板兼容迁移为一个默认区域。
- 用户确认识别结果后，系统自动 upsert 尚未录入但最终采用的客户级列映射学习词，并保存多区域结构模板；未确认的识别建议不得写入学习规则。
- Excel 数据导入与智能填充确认卡默认只紧凑、完整地展示项目/规格/验收/备注的 A1 数据范围（例如 `B2:B4`），不在默认卡片中直接展示行号输入或列下拉；用户点击“调整范围”后，两个入口复用同一个右侧抽屉，按四个业务字段横向排成四列，每列第一行填写起始单元格并紧随显示该单元格的实际内容，第二行填写结束单元格并紧随显示该单元格的实际内容，不显示前置可见标签。“添加数据区域”入口始终可见，数据起止行、四个业务列下拉、仅规格以及区域复制/删除在“展开更多配置”后使用。
- Excel 数据导入与智能填充区域的表头固定为数据起始行的上一行，`headerRowCount` 固定为 `1`；即使原文件存在合并或多行表头，列标题也只读取该上一行，不再向上扩展或拼接。
- `C9:C112` 等 A1 范围只表示字段列与数据闭区间，不包含第 8 行表头；用户修改数据起始行或任一字段 A1 后，系统同步刷新这唯一表头行。
- 仅规格模式由用户显式开关控制，不再通过项目范围是否为空进行隐式推断。
- 规格、验收和备注列始终必选；普通模式下项目列也必选，仅规格模式只豁免项目列。
- 上述默认摘要与右侧抽屉配置同时用于 Excel 数据导入和 Excel 智能填充；Word 继续使用既有真实行号与字段列配置。
- 同一 Sheet 的执行、预览和历史记录使用表索引、区域标识和行索引组成稳定身份，避免多区域结果互相覆盖。

## Impact

- Affected specs: `api`, `data-storage`, `matching-engine`, `user-interface`
- Affected code: 智能结构识别模型与用例、Excel 区域检测、文档模板实体与迁移、导入/智能填充请求契约与行提取、数据导入确认卡、共享区域草稿和执行历史
- Compatibility: 旧识别响应顶层单区域字段、旧请求和旧模板继续兼容；Word 默认保持一表一区域并沿用既有配置方式；Excel 智能填充复用数据导入的内联区域编辑器，但继续使用自身既有确认与执行链路
