# Change: 支持单个 Sheet 多区域智能识别与范围学习

## Why
当前智能结构识别把一个 Excel Sheet 固定建模为一张连续表，只能保存一套表头、列映射和数据起止行。真实验收规范可能在同一 Sheet 内包含多段重复表头和多个有效数据区，现有模型要么漏掉后续数据，要么把中间章节和尾部资料误当成规格行；同时页面暴露列索引、表头行数和数据起始行，客户理解成本高。

## What Changes
- 智能结构识别允许一个 Sheet 输出多个逻辑数据区域，每个区域独立携带表头、连续数据范围、项目/规格/验收/备注列、置信度和问题原因。
- 数据导入和智能填充统一按逻辑区域执行，智能填充补齐数据结束行，避免从起始行一直读取到 Sheet 末尾。
- 客户级文档模板保存多个区域；旧单区域模板兼容迁移为一个默认区域。
- 用户确认识别结果后，系统自动 upsert 尚未录入但最终采用的客户级列映射学习词，并保存多区域结构模板；未确认的识别建议不得写入学习规则。
- 数据导入和智能填充确认卡以 `C9:C112` 等 A1 范围作为 Excel 唯一可编辑结构，列映射和数据起止行由范围反推；表头从数据区上方向前定位最近有效行并展开合并单元格，不再暴露重复的高级行列配置。
- 同一 Sheet 的执行、预览和历史记录使用表索引、区域标识和行索引组成稳定身份，避免多区域结果互相覆盖。

## Impact
- Affected specs: `api`, `data-storage`, `matching-engine`, `user-interface`
- Affected code: 智能结构识别模型与用例、Excel 区域检测、文档模板实体与迁移、导入/智能填充请求契约与行提取、共享确认卡和执行历史
- Compatibility: 旧识别响应顶层单区域字段、旧请求和旧模板继续兼容；Word 默认保持一表一区域
