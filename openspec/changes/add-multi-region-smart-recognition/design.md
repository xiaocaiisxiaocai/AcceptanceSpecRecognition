## Context
示例 Excel 的同一 `工作表1` 中，第一段以第 8 行为表头、数据为第 9–112 行；第二段以第 125–126 行为表头、数据为第 128–143 行。两段共用 C/D/I/J 字段列，但中间与尾部仍存在 C/D 非空的校验、说明和文件移交行，无法通过“过滤空行”排除。

当前识别、模板和前端配置都以 `tableIndex` 作为唯一身份，并只允许一个 `DataStartRowIndex/DataEndRowIndex`。智能填充契约甚至没有数据结束行，因此需要同时修改识别结果、持久化、执行链和页面状态键。

## Goals / Non-Goals
- Goals: 一个 Excel Sheet 可识别、确认、学习和执行多个互不重叠的连续逻辑区域。
- Goals: 页面默认展示业务可读的 A1 范围，并只在有歧义时要求用户调整。
- Goals: 用户确认后自动保存未录入的客户级列映射，不增加单独的“录入规则”步骤。
- Goals: 旧单区域文件、模板、请求和 Word 流程保持兼容。
- Non-Goals: 支持任意单元格集合或逐单元格不规则掩码。
- Non-Goals: 改写 Embedding/LLM 匹配排序、等价裁决或写回格式。
- Non-Goals: 未经用户确认就把 AI/规则建议写入列映射学习库。

## Decisions

### 1. 表内使用区域列表，而不是四个字段各存范围字符串
`SmartConfigurationRecognizedTable` 新增 `Regions`。每个区域包含稳定 `RegionId/RegionIndex`、表头起始与行数、数据起止行、四列映射、仅规格模式、置信度、来源、决策和问题。

页面所见的 `C9:C112` 由结构化区域和列索引计算生成，不把 A1 文本作为执行真相。这样同一范围只保存一次，并允许未来某个区域使用不同列映射。

### 2. 保留表级旧字段作为主区域兼容投影
识别响应继续返回现有表级字段，其值投影自第一个区域；新前端优先读取 `regions`，旧前端仍可处理主区域。旧导入/填充请求转换为一个默认区域。

### 3. 模板使用一对多区域实体
新增 `DocumentTemplateRegion`，由 `DocumentTemplate` 一对多拥有。区域保存顺序、表头/数据行坐标、列映射和仅规格模式。迁移为每个旧模板建立一个区域，并暂时保留旧字段用于回滚和兼容读取。

不采用 `RegionsJson`，避免查询、校验、迁移和局部更新依赖不透明 JSON。

### 4. 区域识别以重复表头块和确定性边界为主
Excel 识别先产生候选表头块，再为每个表头块定位数据起止行。候选边界综合：
- 数据字段表头词命中与多行合并表头；
- 后续重复表头、章节标题、长空白带和已用区域终点；
- 项目/规格非空率、映射列重复、区域最小有效行数；
- 区域不重叠和行坐标合法性。

LLM 只在规则无法确定表头或边界时裁决，并且每个区域仍须通过确定性健康检查。

### 5. 导入与智能填充共用区域身份，执行语义保持分离
导入读取区域内项目、规格、验收和备注；智能填充读取项目/规格并向验收/备注列写回。两者请求均携带 `regionId`、`dataStartRow` 和 `dataEndRow`。智能填充不得再在验收列缺失时回退到规格列。

预览、执行选择、错误、跳过行和历史回放使用 `(tableIndex, regionId, rowIndex)` 作为组合身份。

### 6. 确认动作同时保存结构和缺失列映射
智能确认提交最终区域列表。服务从每个区域实际表头重建最终采用的字段词，并按 `(customerId, targetField, normalizedPattern)` 幂等 upsert `Learned/Equals/Priority >= 100` 规则；重复表头只写一次，用户修改时只保存修正后的映射。

识别本身、预览失败、取消和未确认结果不学习。结构模板学习保持客户级，不自动晋升为全局；列映射词继续沿用现有多客户晋升机制。

### 7. 界面采用渐进披露
默认卡片展示 Sheet、区域数量、有效行数、忽略行数，以及项目/规格/验收/备注的 A1 范围标签。表头位置以“第 8 行、第 125–126 行”自然语言显示。

“调整范围”打开区域编辑抽屉，可新增/删除区域、修改表头和数据边界、点击列选角色；原数字输入和列下拉保留在“高级设置”。高置信区域允许直接确认，歧义区域只要求修正具体问题。

## Risks / Trade-offs
- 区域边界误判可能漏行或多读行。缓解：逐区域健康检查、范围预览、忽略行统计和样本回归测试。
- 同一 Sheet 多区域会打破仅以 `tableIndex` 为键的前端 Map。缓解：统一引入组合键工具并禁止局部自行拼接。
- 历史模板只含单区域。缓解：兼容投影、迁移回填单默认区域和回滚保留旧字段。
- 合并单元格会让多个列读到同一主单元格值。缓解：区域健康检查识别映射列落在同一合并区域时降级确认，并禁止验收目标回退到规格列。
- 自动学习可能污染规则。缓解：只在用户确认最终结构后保存，客户级优先，保存前标准化与去重。

## Migration Plan
1. 新增 `DocumentTemplateRegions` 表和索引，并为已有模板回填一个区域。
2. 部署兼容读取：优先区域表，缺失时由旧字段构造单区域。
3. 扩展识别/确认和导入/智能填充契约；旧字段继续可用。
4. 前端切换到区域列表和组合键，保留高级模式。
5. 样本验证稳定后，再评估后续版本是否移除旧模板字段；本变更不删除。

## Open Questions
- 无阻塞问题。示例采用 C/D/I/J 作为项目、规格、验收、备注列；若其他区域列语义不同，由区域级映射独立表达。
