## Context

示例 Excel 的同一 `工作表1` 中，第一段数据为第 9–112 行，第二段数据为第 128–143 行。Excel 数据导入确认时分别只取数据起始行的上一行（第 8 行和第 127 行）作为唯一表头；即使第二段上方存在合并或多行标题，也不向上扩展。两段共用 C/D/I/J 字段列，但中间与尾部仍存在 C/D 非空的校验、说明和文件移交行，无法通过“过滤空行”排除。

当前识别、模板和前端配置都以 `tableIndex` 作为唯一身份，并只允许一个 `DataStartRowIndex/DataEndRowIndex`。智能填充契约甚至没有数据结束行，因此需要同时修改识别结果、持久化、执行链和页面状态键。

## Goals / Non-Goals

- Goals: 一个 Excel Sheet 可识别、确认、学习和执行多个互不重叠的连续逻辑区域。
- Goals: Excel 数据导入与智能填充默认卡片只展示紧凑、完整的 A1 范围，并复用同一个右侧“调整范围”抽屉；抽屉首次打开按四列显示各字段的起止单元格，并在起止坐标后分别显示对应单元格实际内容，同时常驻“添加数据区域”入口；用户展开更多配置后才编辑数据行号、业务列以及复制/删除区域；所有视图使用同一个区域结构草稿。
- Goals: A1 范围只表达字段数据区；Excel 数据导入与智能填充表头始终由数据起始行推导，仅规格选择不再由 A1 隐式推断。
- Goals: 用户确认后自动保存未录入的客户级列映射，不增加单独的“录入规则”步骤。
- Goals: 旧单区域文件、模板、请求和 Word 流程保持兼容。
- Non-Goals: 支持任意单元格集合或逐单元格不规则掩码。
- Non-Goals: 改写 Embedding/LLM 匹配排序、等价裁决或写回格式。
- Non-Goals: 未经用户确认就把 AI/规则建议写入列映射学习库。

## Decisions

### 1. 表内使用区域列表，而不是四个字段各存范围字符串

`SmartConfigurationRecognizedTable` 新增 `Regions`。每个区域包含稳定 `RegionId/RegionIndex`、表头起始与行数、数据起止行、四列映射、仅规格模式、置信度、来源、决策和问题。

页面所见的 `C9:C112` 由结构化区域的字段列、数据起始行和数据结束行计算生成，不把 A1 文本作为独立执行真相。A1 不包含表头；例如数据为第 9–112 行、项目列为 C 时，项目范围为 `C9:C112`，唯一表头自动取第 8 行且 `headerRowCount = 1`。这样同一结构只保存一次，并允许每个区域使用不同列映射。

### 2. 保留表级旧字段作为主区域兼容投影

识别响应继续返回现有表级字段，其值投影自第一个区域；新前端优先读取 `regions`，旧前端仍可处理主区域。旧导入/填充请求转换为一个默认区域。

### 3. 模板使用一对多区域实体

新增 `DocumentTemplateRegion`，由 `DocumentTemplate` 一对多拥有。区域保存顺序、表头/数据行坐标、列映射和仅规格模式。迁移为每个旧模板建立一个区域，并暂时保留旧字段用于回滚和兼容读取。

不采用 `RegionsJson`，避免查询、校验、迁移和局部更新依赖不透明 JSON。

### 4. 区域识别以重复表头块和确定性边界为主

Excel 识别先产生候选表头块，再为每个表头块定位数据起止行。候选边界综合：

- 数据字段表头词命中与多行合并表头；
- 后续重复表头、章节标题、长空白带和已用区域终点；
- 项目/规格非空率、映射列重复、区域最小有效行数；
- 区域不重叠和行坐标合法性。

LLM 只在规则无法确定表头或边界时裁决，并且每个区域仍须通过确定性健康检查。

### 5. 导入与智能填充共用区域身份，执行语义保持分离

导入读取区域内项目、规格、验收和备注；智能填充读取项目/规格并向验收/备注列写回。两者请求均携带 `regionId`、`dataStartRow` 和 `dataEndRow`。智能填充不得再在验收列缺失时回退到规格列。

预览、执行选择、错误、跳过行和历史回放使用 `(tableIndex, regionId, rowIndex)` 作为组合身份。

### 6. 确认动作同时保存结构和缺失列映射

智能确认提交最终区域列表。对于 Excel 数据导入，服务只从每个区域数据起始行的上一行重建最终采用的字段词，并按 `(customerId, targetField, normalizedPattern)` 幂等 upsert `Learned/Equals/Priority >= 100` 规则；重复表头只写一次，用户修改时只保存修正后的映射。

识别本身、预览失败、取消和未确认结果不学习。结构模板学习保持客户级，不自动晋升为全局；列映射词继续沿用现有多客户晋升机制。

### 7. Excel 数据导入与智能填充确认卡复用紧凑摘要和右侧抽屉

Excel 数据导入与智能填充确认卡的默认结构摘要只展示项目、规格、验收和备注的紧凑完整 A1 范围，例如 `B2:B4`；范围文本必须完整可见，不以省略号隐藏起止坐标。两个入口复用同一个区域编辑组件和结构草稿，默认卡片不直接展示数据起止行输入、四个业务列下拉、A1 编辑框、仅规格开关或表头参数。

用户点击“调整范围”后，页面从右侧打开抽屉且不离开当前确认流程。抽屉首次打开时按项目、规格、验收和备注顺序横向排成四列，每个字段内部显示两行：第一行填写起始单元格，并在输入框后显示该起始单元格的实际内容；第二行填写结束单元格，并在输入框后显示该结束单元格的实际内容。输入框不显示前置可见标签，以包含业务字段名和端点示例的占位文字区分用途，并保留可访问性名称。起止单元格内容通过该区域的单行窗口预览请求读取，不写入结构草稿；起止行为同一行时复用一次结果，区域编号与请求版本共同隔离多区域及陈旧响应。长内容在界面省略但保留完整悬浮提示，空白单元格明确显示为空白。“添加数据区域”入口始终可见，使用户无需展开高级配置即可创建第二个及后续区域；每个新增区域立即显示自己的四组起止单元格及对应内容。数据起始行、数据结束行、四个业务列下拉、显式仅规格开关、重置以及区域复制/删除默认收起，只有用户点击“展开更多配置”后才显示和可操作。关闭并重新打开抽屉时恢复为只显示各区域端点编辑区和新增入口的收起态，避免低频配置长期占据页面。抽屉始终不展示可编辑的表头起始行或表头行数控件。区域表头派生为 `dataStartRow - 1`，`headerRowCount` 始终为 `1`；列下拉使用这一行生成“Excel 列字母 + 完整表头”选项。

结构化区域草稿是唯一真相。抽屉内修改数据起止行或列下拉后，页面从草稿重新生成起止单元格，并同步刷新默认卡片的完整范围摘要；修改任一字段的起点或终点后，页面把该端点的列字母和行号原子写回同一草稿，保持同一字段起止端点同列，并以共享数据起止行重新生成其他非空字段的端点。每次数据起始行变化时，页面同时将表头重算为其上一行并固定一行。页面不得为默认摘要、抽屉行列控件、端点文本、起止单元格内容和表头分别保存可独立提交的状态。

用户修改数据起始行或通过 A1 修改共享数据起始行后，列标题立即按新的上一行刷新。无论原文件是否存在合并或多行表头，Excel 数据导入和智能填充都只读取这一行，不向上搜索更多行、不拼接多行表头，也不保留识别建议中的独立表头范围。

仅规格模式使用显式开关。开启时项目列可以为空；关闭时项目列必须有效。规格列、验收列和备注列在两种模式下都必须有效。清空项目列或项目 A1 不得自动切换仅规格模式。

上述默认摘要与右侧抽屉双向配置同时在 Excel 数据导入和智能填充启用；智能填充仍沿用自身的选择、确认和写回执行链路，只统一范围配置界面与草稿语义。Word 继续使用既有真实行号与字段列配置，不要求采用 Excel 的 A1 摘要或右侧抽屉。

## Risks / Trade-offs

- 区域边界误判可能漏行或多读行。缓解：逐区域健康检查、范围预览、忽略行统计和样本回归测试。
- 同一 Sheet 多区域会打破仅以 `tableIndex` 为键的前端 Map。缓解：统一引入组合键工具并禁止局部自行拼接。
- 历史模板只含单区域。缓解：兼容投影、迁移回填单默认区域和回滚保留旧字段。
- 合并单元格会让多个列读到同一主单元格值。缓解：区域健康检查识别映射列落在同一合并区域时降级确认，并禁止验收目标回退到规格列。
- 自动学习可能污染规则。缓解：只在用户确认最终结构后保存，客户级优先，保存前标准化与去重。
- 默认 A1 摘要与抽屉内行列/A1 控件可能产生状态分叉。缓解：只维护结构化区域草稿，默认摘要只做派生展示，抽屉内所有编辑同步写回该草稿。
- 数据起始行若位于工作表已用区域第一行，将不存在可读取的上一行表头。缓解：提交前校验数据起始行必须在已用区域起始行之后，并将错误定位到具体区域的数据起始行或 A1。

## Migration Plan

1. 新增 `DocumentTemplateRegions` 表和索引，并为已有模板回填一个区域。
2. 部署兼容读取：优先区域表，缺失时由旧字段构造单区域。
3. 扩展识别/确认和导入/智能填充契约；旧字段继续可用。
4. 前端切换到区域列表和组合键；Excel 数据导入与智能填充确认卡复用同一紧凑完整 A1 范围摘要和右侧“调整范围”抽屉，抽屉默认按四列两行显示各字段起止单元格，并在起止坐标后分别显示实际单元格内容，同时常驻新增区域入口；数据起止行、列下拉以及区域复制/删除通过“展开更多配置”使用，并固定从数据起始行上一行派生单行表头。
5. 样本验证稳定后，再评估后续版本是否移除旧模板字段；本变更不删除。

## Open Questions

- 无阻塞问题。示例采用 C/D/I/J 作为项目、规格、验收、备注列；若其他区域列语义不同，由区域级映射独立表达。
