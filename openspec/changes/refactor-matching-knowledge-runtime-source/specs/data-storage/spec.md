## MODIFIED Requirements
### Requirement: 匹配知识配置数据库持久化
系统 SHALL 在 MySQL 中持久化当前生效的单例匹配知识配置，并将数据库内容作为唯一运行时知识来源。

#### Scenario: 服务重启后仍保持相同配置
- **GIVEN** 用户已保存一套匹配知识配置
- **WHEN** 服务重启后再次读取匹配知识
- **THEN** 系统返回与重启前一致的数据库配置内容
- **AND** 不会因为配置文件中的默认规则而隐式叠加额外条目

#### Scenario: 始终只有一套生效配置
- **WHEN** 系统读取当前匹配知识配置
- **THEN** 系统返回唯一的当前生效配置
- **AND** 不要求用户在多个版本之间手工切换

#### Scenario: 空库时导入默认种子
- **GIVEN** 数据库中尚不存在匹配知识配置
- **WHEN** 系统首次初始化匹配知识
- **THEN** 系统将默认种子模板写入数据库作为初始配置
- **AND** 后续运行时读取直接使用该数据库配置

#### Scenario: 清空配置后保持空结果
- **GIVEN** 用户已显式清空当前匹配知识配置
- **WHEN** 服务重启后再次读取匹配知识
- **THEN** 系统保持清空后的数据库内容
- **AND** 不会自动重新写入默认种子
- **AND** 只有显式执行恢复默认操作时才重新导入默认种子
