## ADDED Requirements

### Requirement: 验收规格引用次数按最终采用行累计

系统 SHALL 在智能填充最终成功提交时，按实际采用已有验收规格的行数累计该规格当前内容版本的引用次数。

#### Scenario: 每个最终采用行累计一次
- **GIVEN** 多个填充行最终采用同一条已有验收规格
- **AND** 该规格的验收或备注至少一项包含有效内容
- **WHEN** 填充执行成功提交
- **THEN** 系统按最终采用行数增加该规格的引用次数
- **AND** 不把预览候选、未采用行或失败执行计入引用次数

#### Scenario: 空填充内容不累计
- **GIVEN** 某条验收规格的验收和备注均为空白
- **WHEN** 填充执行最终采用该规格
- **THEN** 系统不增加该规格的引用次数

#### Scenario: 并发执行不丢失增量
- **GIVEN** 两个独立填充执行并发采用同一条验收规格
- **WHEN** 两个执行均成功提交
- **THEN** 系统原子累计两个执行产生的全部采用行数

#### Scenario: 幂等重放不重复累计
- **GIVEN** 某个执行请求已经成功提交并累计引用次数
- **WHEN** 客户端使用同一执行请求标识重放请求
- **THEN** 系统返回既有执行结果
- **AND** 不再次增加引用次数
