## ADDED Requirements

### Requirement: 验收规格引用次数持久化并绑定当前内容版本

系统 SHALL 为每条验收规格持久化当前内容版本的引用次数，并在内容发生实质变化时重置该计数。

#### Scenario: 历史和新建记录从零开始
- **WHEN** 系统应用引用次数数据库迁移或创建新的验收规格
- **THEN** `ReferenceCount` 以非空 `BIGINT` 持久化
- **AND** 初始值为 0
- **AND** 系统不推断或回填历史执行产生的引用次数

#### Scenario: 内容变化后重置
- **GIVEN** 某条验收规格已有非零引用次数
- **WHEN** 项目、规格、验收或备注任一字段在归一化后发生变化
- **THEN** 系统将引用次数重置为 0

#### Scenario: 等价内容更新保留计数
- **GIVEN** 某条验收规格已有非零引用次数
- **WHEN** 更新内容仅存在首尾空格或空白可选值与空值的等价差异
- **THEN** 系统保留原引用次数

#### Scenario: 所有内容更新入口使用相同规则
- **WHEN** 验收规格内容通过手工编辑、文档导入、智能填充回填或备注批量替换发生变化
- **THEN** 系统均使用同一版本重置规则
