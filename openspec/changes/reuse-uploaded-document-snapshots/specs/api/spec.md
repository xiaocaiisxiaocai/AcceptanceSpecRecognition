## ADDED Requirements

### Requirement: 已上传文档解析快照跨请求安全复用
系统 MUST 对同一内容版本的已上传 Word 或 Excel 文档复用短生命周期、容量有界的完整表格解析快照，同时保持权限、数据和业务判断与直接解析一致。

#### Scenario: 元数据识别预览与导入复用未变化文件
- **GIVEN** 用户有权访问一个已上传且内容未变化的文档
- **AND** 该文档的完整解析快照仍在有效期内
- **WHEN** 用户依次读取表格元数据、执行智能结构识别、生成预览并执行导入
- **THEN** 后续请求复用同一内容版本的已完成解析快照
- **AND** 系统不得为这些请求重复解码同一源文档

#### Scenario: 缓存命中不改变识别和导入判断
- **GIVEN** 同一文档分别通过缓存命中和缓存未命中路径处理
- **WHEN** 系统生成表格元数据、智能结构识别、预览、匹配来源或导入数据
- **THEN** 两条路径的表头、数据行、结构化单元格、合并单元格和行列坐标保持一致
- **AND** Prompt、AI 调用策略、列映射规则、置信度、匹配排序和自动采用条件保持不变

#### Scenario: 同一内容版本并发首次读取
- **GIVEN** 同一文档内容版本尚无已完成快照
- **WHEN** 多个请求并发读取该文档
- **THEN** 系统只启动一个底层文档解析任务
- **AND** 其他请求等待并复用该成功结果
- **AND** 单个等待者取消不会把取消或异常结果写入缓存

#### Scenario: 文件内容变化后重新解析
- **GIVEN** 某文件已有缓存快照
- **WHEN** 文件内容成功写回且 `FileHash` 发生变化
- **THEN** 后续读取不得命中旧内容版本
- **AND** 系统重新解析当前内容并返回当前文件数据

#### Scenario: 解析失败不污染后续请求
- **GIVEN** 某内容版本的首次解析失败或被宿主取消
- **WHEN** 后续请求再次读取该内容版本
- **THEN** 系统重新尝试解析
- **AND** 不返回先前失败任务或不完整快照

#### Scenario: 缓存不能绕过文件数据范围
- **GIVEN** 某文件已有缓存快照
- **WHEN** 当前用户无权访问该文件或文件已进入不可访问的删除状态
- **THEN** 系统在读取缓存前按现有规则拒绝访问
- **AND** 不向当前用户返回任何缓存中的表格元数据或内容

#### Scenario: 快照超过缓存预算
- **GIVEN** 文档成功解析但快照估算大小超过单条目预算，或缓存总容量不足
- **WHEN** 系统完成当前请求
- **THEN** 系统返回当前解析结果但不保留超限快照
- **AND** 缓存容量、过期和逐出不会改变请求的业务结果
