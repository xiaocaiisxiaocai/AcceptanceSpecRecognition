## ADDED Requirements

### Requirement: 智能填充匹配方式选择
系统 SHALL 在智能填充匹配配置中提供匹配方式选择，允许用户显式选择“项目+规格”或“仅规格”。

#### Scenario: 用户配置匹配方式
- **WHEN** 用户进入智能填充匹配配置步骤
- **THEN** 页面显示匹配方式选项
- **AND** 默认选中“项目+规格”
- **AND** 用户可手动切换为“仅规格”

#### Scenario: 展示仅规格匹配依据
- **GIVEN** 某行结果来自“仅规格”匹配方式
- **WHEN** 页面展示预览结果或详情
- **THEN** 页面展示“匹配依据：规格”
- **AND** 页面仍展示候选项目，方便用户识别项目差异
