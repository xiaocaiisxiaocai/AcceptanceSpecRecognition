# Change: 新增智能填充规格匹配模式

## Why
部分客户文档中“项目”字段与历史验收规格项目名称不稳定，但“规格”字段能够稳定指向需要回填的验收与备注。当前智能填充默认强依赖“项目+规格”，会导致这类数据无法命中。

## What Changes
- 新增智能填充匹配方式配置，默认保持“项目+规格”。
- 用户手动选择“仅规格”后，系统在客户、机型、制程与权限范围内按规格匹配历史验收规格，并回填验收与备注。
- 仅规格模式下，匹配结果必须展示“匹配依据：规格”，避免用户误解为项目一致。
- 同一范围内同规格存在多条不同候选时，结果必须进入人工确认，不得直接自动采用。

## Impact
- Affected specs: `matching-engine`, `user-interface`
- Affected code: 匹配配置 DTO、匹配配置解析、智能填充预览/执行匹配链路、前端智能填充配置与结果展示
