## ADDED Requirements

### Requirement: 文件对比页面只渲染当前有界窗口

系统 MUST 在文件对比页面以有限行列窗口展示 Excel，并明确当前范围、总量和加载状态。

#### Scenario: 查看大型 Excel

- **WHEN** 用户打开包含大量行列的 Excel 对比结果
- **THEN** 页面首次只加载并渲染配置的首个窗口
- **AND** 页面显示当前行列范围与文档总量
- **AND** 用户可以翻页或跳转到下一处差异

#### Scenario: 两侧窗口保持同步

- **WHEN** 用户切换窗口或跳转差异
- **THEN** 文件 A 与文件 B 使用相同的行列范围
- **AND** 同步滚动不会误把未加载区域显示为已有数据

### Requirement: 文件对比异步请求拒绝过期响应

系统 MUST 取消已失效的文件对比请求，并在响应写入前校验当前文件、Sheet 和请求版本。

#### Scenario: 快速切换 Sheet

- **WHEN** 用户在旧 Sheet 请求完成前切换到新 Sheet
- **THEN** 页面取消或废弃旧请求
- **AND** 旧响应即使最后返回也不得覆盖新 Sheet 数据

#### Scenario: 离开缓存页面

- **WHEN** 文件对比组件被停用或销毁
- **THEN** 页面取消仍在执行的预览请求
- **AND** 取消不显示为业务失败提示
