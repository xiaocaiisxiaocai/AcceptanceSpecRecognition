# Change: 优化大文件对比预览

## Why

文件对比页面当前以 `previewRows=0` 读取整张工作表，并在浏览器中扫描和渲染左右两份完整表格。大 Excel 会同时放大 API 响应、Vue 响应式对象和 DOM 数量，快速切换 Sheet 时旧请求还可能覆盖新状态，形成页面卡死或内容错位。

## What Changes

- 为表格预览增加兼容的行列窗口参数和服务端硬上限，旧客户端未传新参数时保持原行为。
- 文件对比预览默认只返回差异项及完整统计，导出仍保留完整结果。
- 文件对比页面每次只加载有限行列窗口，不再请求或渲染整张工作表。
- 为表格列表、预览和对比请求增加取消与请求版本校验，迟到响应不得覆盖当前文件或 Sheet。
- 提供分页、当前范围、总行列数和差异跳转反馈。

## Impact

- Affected specs: `api`, `table-preview`, `user-interface`
- Affected code: 文档表格预览 API、文件对比 API、文件对比页面与表格组件、API 封装和行为测试
- Compatibility: 新增可选请求参数和响应元数据；旧调用路径、导出结果和既有字段保持兼容
