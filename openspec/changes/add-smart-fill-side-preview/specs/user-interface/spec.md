## ADDED Requirements

### Requirement: 智能填充结构确认支持并排实时预览
系统 MUST 在智能填充结构确认步骤中，为宽屏用户并排展示结构配置和当前待填充数据预览，并从当前结构草稿实时派生预览范围与字段映射。

#### Scenario: 宽屏并排确认与预览
- **GIVEN** 用户进入智能填充结构确认步骤
- **AND** 当前视口满足宽屏布局条件
- **WHEN** 页面展示当前 Sheet 的识别结果
- **THEN** 页面在左侧展示 Sheet 与区域结构配置
- **AND** 页面在右侧展示当前区域的待填充数据预览
- **AND** 预览包含项目、规格、验收和备注业务列

#### Scenario: 结构草稿变化后更新预览
- **GIVEN** 用户正在查看智能填充结构确认与右侧预览
- **WHEN** 用户修改当前区域的数据起止行或字段列
- **THEN** 右侧预览使用当前 `batchTableConfigs` 派生的范围和映射更新
- **AND** 页面不维护与结构确认草稿并行的第二份配置状态
- **AND** 陈旧预览响应不得覆盖最新配置结果

#### Scenario: 切换 Sheet 和区域
- **GIVEN** 智能填充识别结果包含多个 Sheet 或同一 Sheet 包含多个区域
- **WHEN** 用户切换左侧 Sheet 或右侧区域
- **THEN** 右侧预览展示对应 Sheet 和区域的数据
- **AND** 不触发 Embedding 或 LLM 匹配
- **AND** 不改变左侧结构选择和确认状态

#### Scenario: 窄屏恢复上下布局
- **GIVEN** 用户进入智能填充结构确认步骤
- **AND** 当前视口不足以同时容纳结构配置与预览表格
- **WHEN** 页面应用响应式布局
- **THEN** 结构配置与待填充预览按上下顺序展示
- **AND** Sheet、区域切换和数据滚动仍可用

#### Scenario: 预览仅表达源文件当前值
- **GIVEN** 用户尚未进入智能填充匹配预览步骤
- **WHEN** 页面展示结构确认右侧预览
- **THEN** 页面明确标识该区域为待填充数据预览
- **AND** 页面不得把源文件中的验收和备注显示为匹配后的最终结果
