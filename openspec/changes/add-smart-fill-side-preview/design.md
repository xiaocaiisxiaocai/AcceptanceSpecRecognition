## Context
数据导入通过独立侧边预览组件展示已经映射为业务列的待导入清单；智能填充识别确认页目前只渲染共享结构确认 Tabs，右侧虽然有可用空间，却没有消费者。智能填充此时已经拥有 `uploadedFile`、`activeSmartStructureTab`、`batchTableConfigs` 以及每个区域的行列配置，可以在不调用匹配接口的前提下预览源文件。

## Goals / Non-Goals
- Goals: 宽屏同时展示结构配置与当前 Sheet/区域的待填充数据。
- Goals: 预览直接派生自当前 `batchTableConfigs`，不建立第二份结构状态。
- Goals: 复用现有表格预览接口、加载状态、错误处理和陈旧请求保护。
- Goals: 多区域、Sheet 切换和窄屏布局保持可用。
- Non-Goals: 在结构确认阶段提前执行 Embedding 或 LLM 匹配。
- Non-Goals: 增加导入专用的行移出、恢复或重复确认操作。
- Non-Goals: 修改后端接口、数据库或智能填充执行语义。

## Decisions

### 1. 复用现有 TablePreview 数据读取能力
新增智能填充侧边预览宿主，内部复用 `TablePreview`。预览请求仍调用既有文件表格预览接口，并传入当前区域的表头行、数据起止行和四个业务列映射；不新增 API 或复制数据加载实现。

### 2. 预览只读取当前结构草稿派生的配置
活动 Sheet 由 `activeSmartStructureTab` 决定，活动区域来自该 Sheet 的 `batchTableConfigs.regions`。`handleSmartStructureDraftChange` 已将共享确认草稿同步到 `batchTableConfigs`，侧边预览只消费这份状态。范围变化触发重新读取，列映射变化只重新映射现有行。

### 3. 不直接复用 DataImportPreviewPanel
`DataImportPreviewPanel` 同时承载导入行选择、移出、恢复、差异确认和完整数据加载语义。智能填充只需要结构核对，直接复用会把导入专用状态带入另一条业务流程。两者复用底层 `TablePreview` 和一致的双栏视觉规则，而不强行共享业务面板。

### 4. 多区域使用预览内区域切换
单区域直接展示数据表；多区域在预览顶部显示紧凑区域页签。切换区域不改变左侧编辑选择，只改变右侧只读数据窗口。Sheet 切换时优先保留仍存在的区域身份，否则回到第一个区域。

### 5. 响应式双栏
宽屏使用与数据导入相同的左右双栏比例和粘性预览；窄屏改为上下排列。右侧表格使用可用高度并允许内部滚动，不制造固定小高度窗口。

## Risks / Trade-offs
- 多区域切换会增加一个局部活动状态；通过区域身份校验和 Sheet 变化回退避免悬空选择。
- 表格预览只显示源文件当前值，不代表匹配后的最终验收与备注；面板标题和提示明确为“待填充数据预览”。
- 大范围数据只加载现有有界预览窗口，避免在结构确认阶段读取整表；完整匹配结果仍在后续预览步骤生成。

## Migration Plan
纯前端增量能力，无数据迁移。回退时移除侧边预览宿主和双栏样式即可，原结构确认与后续匹配流程保持不变。

## Open Questions
无。用户已明确要求智能填充与数据导入一样在结构确认阶段提供右侧预览。
