# Change: 在智能填充结构确认右侧提供实时预览

## Why
智能填充的结构确认页已经采用左右双栏空间，但当前右栏为空。用户调整 Sheet、区域范围或字段列后无法就地核对实际待填充数据，只能继续到后续匹配预览步骤才发现范围或列配置错误；数据导入已经具备同类实时预览能力，两条结构确认流程的反馈路径不一致。

## What Changes
- 智能填充结构确认页在宽屏采用左侧结构配置、右侧待填充数据预览的双栏布局。
- 右侧预览跟随当前 Sheet 和当前区域，按当前结构草稿展示行数、项目、规格、验收和备注列内容。
- 用户切换 Sheet、切换区域或修改数据范围与字段列时，右侧预览复用现有表格预览接口和当前配置状态实时更新。
- 多区域 Sheet 在右侧提供区域切换；窄屏自动改为上下布局。
- 不修改智能填充确认学习、匹配、执行、写回 API 或数据库结构。

## Impact
- Affected specs: `user-interface`
- Affected code: 智能填充识别确认页、待填充侧边预览组件、结构预览参数转换及前端回归测试
- Compatibility: 仅新增只读预览，不改变现有结构草稿、匹配配置和执行请求契约
