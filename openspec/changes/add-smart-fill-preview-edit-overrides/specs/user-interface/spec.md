## MODIFIED Requirements
### Requirement: 智能填充界面
系统 SHALL 提供基于统一多阶段匹配引擎的智能匹配与文档填充界面，并允许用户在预览阶段对本次导出的验收标准与备注做单行修订。

#### Scenario: 匹配参数配置
- **WHEN** 用户进入匹配配置步骤
- **THEN** 系统提供 Embedding 服务、LLM 服务、高置信阈值、候选过滤阈值、实体判别参数与复核并行参数
- **AND** AI 复核门禁固定开启，不再提供 `SingleStage / MultiStage` 或 `LLM 复核开关` 之类的策略切换
- **AND** 页面不再展示 `UseLlmReview`、`UseLlmSuggestion`、`SuggestNoMatchRows` 等旧兼容项

#### Scenario: 匹配预览
- **WHEN** 用户执行预览
- **THEN** 系统显示每行的匹配结果、最终决策状态、高置信状态与人工确认状态
- **AND** 对无法自动采用的样本给出明确提示
- **AND** 主表与详情以服务端返回的 `decision`、`confidenceLevel`、证据与 AI 裁决结果为准，不再由前端旧兼容字段自行推断

#### Scenario: 预览阶段编辑本次导出值
- **GIVEN** 某行存在可展示的最佳匹配结果
- **WHEN** 用户点击该行的 `编辑`
- **THEN** 系统打开独立编辑弹窗
- **AND** 弹窗只读展示 `项目` 与 `规格`
- **AND** 弹窗允许编辑 `验收标准` 与 `备注`
- **AND** 页面明确这些修改仅用于本次导出

#### Scenario: 保存并采用
- **GIVEN** 用户已在编辑弹窗中修改 `验收标准` 或 `备注`
- **WHEN** 用户点击 `保存并采用`
- **THEN** 系统保存该行覆盖值
- **AND** 自动将该行标记为已选择填充
- **AND** 预览表中的 `验收标准` 与 `备注` 列优先显示覆盖值
- **AND** 页面展示该行已编辑状态

#### Scenario: 取消采用不清空覆盖值
- **GIVEN** 某行已经保存过本次导出的覆盖值
- **WHEN** 用户点击 `不填充`
- **THEN** 系统仅取消该行采用状态
- **AND** 不自动清空已保存的覆盖值

#### Scenario: 执行填充
- **WHEN** 用户确认匹配结果并点击填充
- **THEN** 系统执行填充；Word 提供结果文件下载，Excel 写回源文件后提供下载入口
- **AND** 对需要人工确认但未确认的样本阻止直接自动采用
- **AND** 页面提交当前文件中的 `specId`、人工确认状态与本次导出覆盖值，不再透传旧 suggestion / compatibility 字段
