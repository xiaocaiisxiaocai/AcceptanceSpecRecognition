## MODIFIED Requirements
### Requirement: 智能填充界面
系统 SHALL 提供基于统一多阶段匹配引擎的智能匹配与文档填充界面，并在进入预览前给出明确的 AI 服务状态、数据范围空态与下载恢复入口。

#### Scenario: 匹配参数配置
- **WHEN** 用户进入智能填充的配置步骤
- **THEN** 页面允许选择 Embedding 服务、LLM 服务、范围条件和匹配参数
- **AND** 页面明确说明高置信阈值只用于结果分层展示，不决定自动采用

#### Scenario: 预览前阻断提示
- **WHEN** 页面检测到没有可用 Embedding 服务
- **THEN** 页面在进入预览前提示用户先配置可用 Embedding 服务
- **AND** 页面不再只在请求失败后给出笼统错误

#### Scenario: 范围空态提示
- **WHEN** 当前客户/制程/机型范围内没有可用于匹配的验收规格
- **THEN** 页面给出明确空态提示
- **AND** 提示用户调整范围或补充验收规格数据

#### Scenario: 下载失败后可恢复
- **GIVEN** 智能填充执行已经成功
- **AND** 首次浏览器下载失败或被用户稍后处理
- **WHEN** 用户回到预览确认区域
- **THEN** 页面仍显示重新下载入口
- **AND** 执行按钮权限与下载按钮权限分开判定

#### Scenario: 详情区结论以当前 AI 决策为准
- **WHEN** 用户查看智能填充详情弹窗
- **THEN** 页面显示 AI 等价裁决、风险等级和建议动作
- **AND** 不再使用“存在差异，请先确认”之类的旧差异确认文案覆盖当前结论

### Requirement: 配置管理界面
系统 SHALL 提供 AI 服务与 Prompt 模板的 Web 配置页面；列映射规则配置页面已删除。

#### Scenario: AI服务配置
- **WHEN** 用户访问AI配置页面
- **THEN** 系统显示AI服务列表并支持新增、编辑、删除、启用、禁用

#### Scenario: Prompt 模板配置
- **WHEN** 用户访问 Prompt 模板页面
- **THEN** 系统显示系统模板场景列表并支持编辑、预览测试与恢复默认
- **AND** 页面不再以“设为默认模板”作为主操作

## REMOVED Requirements
### Requirement: 智能填充一次性严格复用界面
**Reason**: 当前分支已移除严格复用前端入口，主链只保留当前文件的 AI 智能填充。
**Migration**: 前端不再显示“应用到相同验规”入口。

### Requirement: 智能填充界面支持实体判别配置
**Reason**: 实体判别仍存在，但其开关文案不再暗示旧品牌配置或本地规则拦截；该能力已并入智能填充主界面要求统一描述。
**Migration**: 无额外迁移动作。

### Requirement: 列映射规则配置界面
**Reason**: 旧列映射规则能力已删除，不再提供独立页面。
**Migration**: data-import 仅保留手工字段映射，不再跳转或返回旧规则页面。

#### Scenario: 旧列映射规则页面不可再访问
- **WHEN** 用户进入配置管理菜单
- **THEN** 页面与导航中不再出现列映射规则入口
