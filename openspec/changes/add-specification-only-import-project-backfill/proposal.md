# Change: 仅规格导入时用规格补项目

## Why
当前智能结构识别和智能填充已支持仅规格模式，但数据导入仍要求项目列。部分验收文件天然只有规格语义，用户希望这类数据也能进入历史规格库，同时避免把“项目列漏识别”的表误当成仅规格表。

## What Changes
- 在导入链路中支持明确仅规格表：缺少项目列时用规格值同时写入 `Project` 和 `Specification`。
- 仅当结构识别明确为仅规格，或用户在确认界面显式确认仅规格时启用补项目。
- 疑似存在项目列但低置信、项目/规格疑似判反或规格列不健康时不得自动补项目，必须人工确认。
- 导入判重和 AI 疑似重复识别继续使用最终导入行的 `Project + Specification`，即补齐后按 `规格 + 规格` 参与现有规则。
- 前端导入确认必须提示“项目由规格自动补齐”，避免用户误认为原文存在项目列。

## Impact
- Affected specs: `api`, `matching-engine`, `user-interface`
- Affected code:
  - Word / Excel 导入预览与执行应用服务
  - 智能结构识别到导入配置的转换逻辑
  - 导入重复检测输入构造
  - 数据导入确认页提示与请求构造
  - API / Core / 前端回归测试
