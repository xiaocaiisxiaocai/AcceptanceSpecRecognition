## ADDED Requirements

### Requirement: 数据导入字段候选冲突确认

系统 SHALL 在数据导入所选 Sheet 的同一业务字段存在多个分数接近且无法可靠自动区分的高置信列候选时，在生成正式导入预览、学习配置和开始导入之前要求用户明确选择最终列。

#### Scenario: 数据导入检测到字段候选冲突

- **GIVEN** 数据导入页面至少勾选一张可导入 Sheet
- **AND** 所选 Sheet 的同一业务字段存在两个或以上高置信候选
- **AND** 候选之间的分差不足以可靠自动决策
- **WHEN** 结构识别完成并确定默认已选 Sheet
- **THEN** 系统弹出字段冲突选择框
- **AND** 每个候选显示工作表、字段、列标、表头、数据范围、置信度和非空样例
- **AND** 系统可以标记推荐候选，但不得代替用户完成冲突确认
- **AND** 系统应默认预选推荐候选，但不得自动确认或进入下一步
- **AND** 没有推荐候选的冲突应保持未选
- **AND** 系统不得在冲突解决前生成正式导入预览

#### Scenario: 用户确认数据导入字段候选

- **GIVEN** 数据导入字段冲突选择框已经展示
- **WHEN** 用户为每个冲突字段选择一个候选并确认
- **THEN** 系统将最终列写回对应 Sheet 的识别结果
- **AND** 系统基于最终列生成确认草稿、字段范围和导入预览
- **AND** 用户执行文件级主操作时，系统再完整校验、按工作表顺序确认学习并开始导入

#### Scenario: 用户取消数据导入字段候选选择

- **GIVEN** 数据导入字段冲突选择框已经展示
- **WHEN** 用户取消或关闭弹框
- **THEN** 系统停留在识别确认步骤
- **AND** 系统不得生成正式导入预览
- **AND** 系统不得学习存在未解决冲突的 Sheet
- **AND** 系统不得开始导入
- **AND** 用户此前的 Sheet 勾选、范围调整和其他结构草稿必须保留

#### Scenario: 数据导入没有字段候选冲突

- **GIVEN** 所有已选 Sheet 均不存在未解决的高置信字段候选冲突
- **WHEN** 用户执行文件级确认学习并导入操作
- **THEN** 系统不得额外弹出字段选择框
- **AND** 原有批量确认学习和导入流程继续执行

#### Scenario: 数据导入复用自动学习别名

- **GIVEN** 用户此前确认的多个不同表头被自动学习为同一业务字段
- **WHEN** 数据导入再次识别相同或相似文档
- **THEN** 自动学习规则可以参与最终列映射
- **AND** 自动学习规则不得单独制造新的字段候选冲突
- **AND** 内置规则或人工维护规则之间的真实歧义仍应要求用户确认

#### Scenario: 未选 Sheet 的冲突不阻塞导入

- **GIVEN** 未勾选 Sheet 存在未解决的字段候选冲突
- **AND** 所有已勾选 Sheet 均不存在未解决冲突
- **WHEN** 用户执行文件级确认学习并导入操作
- **THEN** 系统不得为未勾选 Sheet 弹出字段选择框
- **AND** 未勾选 Sheet 不得阻塞已选 Sheet 的确认学习和导入

#### Scenario: 后续勾选此前未选的冲突 Sheet

- **GIVEN** 结构识别后某张存在字段冲突的 Sheet 未被默认勾选
- **WHEN** 用户在识别确认页勾选该 Sheet 并执行文件级主操作
- **THEN** 系统必须在学习和导入前要求用户解决该 Sheet 的字段冲突
- **AND** 已经解决冲突的其他 Sheet 不得重复要求确认
