## ADDED Requirements

### Requirement: 数据导入字段候选冲突确认

系统 SHALL 在数据导入所选 Sheet 的同一业务字段存在多个分数接近且无法可靠自动区分的高置信列候选时，在学习配置和开始导入之前要求用户明确选择最终列。

#### Scenario: 数据导入检测到字段候选冲突

- **GIVEN** 数据导入页面至少勾选一张可导入 Sheet
- **AND** 所选 Sheet 的同一业务字段存在两个或以上高置信候选
- **AND** 候选之间的分差不足以可靠自动决策
- **WHEN** 用户点击文件级确认学习并导入操作
- **THEN** 系统弹出字段冲突选择框
- **AND** 每个候选显示工作表、字段、列标、表头、数据范围、置信度和非空样例
- **AND** 系统可以标记推荐候选，但不得代替用户完成冲突确认

#### Scenario: 用户确认数据导入字段候选

- **GIVEN** 数据导入字段冲突选择框已经展示
- **WHEN** 用户为每个冲突字段选择一个候选并确认
- **THEN** 系统将最终列写回对应 Sheet 的识别结果和确认草稿
- **AND** 页面立即显示更新后的字段列及数据范围
- **AND** 系统重新执行完整校验、按工作表顺序确认学习并开始导入

#### Scenario: 用户取消数据导入字段候选选择

- **GIVEN** 数据导入字段冲突选择框已经展示
- **WHEN** 用户取消或关闭弹框
- **THEN** 系统停留在识别确认步骤
- **AND** 系统不得学习存在未解决冲突的 Sheet
- **AND** 系统不得开始导入
- **AND** 用户此前的 Sheet 勾选、范围调整和其他结构草稿必须保留

#### Scenario: 数据导入没有字段候选冲突

- **GIVEN** 所有已选 Sheet 均不存在未解决的高置信字段候选冲突
- **WHEN** 用户执行文件级确认学习并导入操作
- **THEN** 系统不得额外弹出字段选择框
- **AND** 原有批量确认学习和导入流程继续执行

#### Scenario: 未选 Sheet 的冲突不阻塞导入

- **GIVEN** 未勾选 Sheet 存在未解决的字段候选冲突
- **AND** 所有已勾选 Sheet 均不存在未解决冲突
- **WHEN** 用户执行文件级确认学习并导入操作
- **THEN** 系统不得为未勾选 Sheet 弹出字段选择框
- **AND** 未勾选 Sheet 不得阻塞已选 Sheet 的确认学习和导入
