# Change: 将字段候选冲突确认扩展到数据导入

## Why

智能填充已经会在同一业务字段存在多个高置信候选时要求用户选择最终列，但数据导入仍直接进入批量确认学习，可能把系统默认候选当成用户最终决定。两个入口共享同一套结构识别结果，应保持一致的人工确认门禁。

## What Changes

- 数据导入文件级主操作在学习和导入前检查全部已选 Sheet 的字段候选冲突。
- 存在冲突时复用与智能填充一致的集中选择弹框，展示工作表、字段、候选列、范围、置信度和样例。
- 用户确认后将最终列写回对应结构草稿与识别结果，再继续既有批量确认学习和导入流程。
- 用户取消或关闭弹框时保留当前选择与调整，不学习也不开始导入。
- 抽取中性的共享冲突选择组件与辅助逻辑，保持智能填充现有行为不变。

## Impact

- Affected specs: `user-interface`
- Affected code: 数据导入批量确认编排、共享结构冲突弹框与选择辅助逻辑、智能填充兼容接入、前端回归测试
- Compatibility: 不修改结构识别和确认 API，不改变无冲突文件的现有流程
