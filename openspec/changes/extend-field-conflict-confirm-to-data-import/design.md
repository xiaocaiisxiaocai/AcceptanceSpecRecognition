## Context

结构识别响应已经为 Word 和 Excel 返回字段候选冲突。智能填充在文件级主操作前集中解决冲突，但数据导入尚未接入该门禁。

## Goals / Non-Goals

- Goals: 数据导入与智能填充使用一致的字段冲突确认语义；用户选择后继续既有学习与导入编排；无冲突流程不增加操作。
- Non-Goals: 不改变候选生成算法；不修改确认 API；不新增数据库表；不改变导入数据差异覆盖弹框。

## Decisions

- 将当前智能填充专用的冲突收集、选择应用逻辑和弹框抽取为共享结构识别能力，两个入口共同复用。
- 数据导入仅检查已勾选 Sheet；未勾选、建议跳过或不可导入的 Sheet 不进入弹框。
- 冲突选择同时更新识别结果和当前确认草稿，随后重新执行数据导入既有的完整校验、按序学习和导入流程。
- 弹框取消只关闭门禁，不清空用户已完成的 Sheet 勾选、范围调整或其他字段草稿。

## Risks / Trade-offs

- 共享抽取可能影响智能填充现有入口：保留相同行为并运行两个入口的定向回归。
- 多 Sheet 冲突较多时弹框内容较长：继续使用现有集中列表和完成进度，不新增连续弹框。

## Migration Plan

无需数据迁移。旧识别结果没有字段候选冲突时直接沿用现有数据导入流程。
