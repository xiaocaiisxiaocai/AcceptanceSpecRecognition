## MODIFIED Requirements

### Requirement: 文件清理
系统 SHALL 在删除文件记录、临时会话到期或产物到期时幂等清理对应物理文件，并使周期性清理独立于业务请求流量。

#### Scenario: 删除文件记录
- **WHEN** 用户删除文件记录且无关联验收规格
- **THEN** 系统删除对应物理文件

#### Scenario: 独立清理过期临时文件
- **GIVEN** BatchReply session 或下载产物超过保留期
- **WHEN** hosted cleanup 执行周期扫描
- **THEN** 系统清理对应 manifest、临时来源文件、目标文件和到期产物
- **AND** 无需等待新的用户请求触发扫描

#### Scenario: 清理与活跃会话竞争
- **WHEN** 清理任务遇到正在变更的同一会话
- **THEN** 系统通过同一会话协调机制避免删除活跃数据
- **AND** 删除前重新确认保留期并保持重复执行安全

#### Scenario: 文件元数据提交结果不确定
- **GIVEN** 文件已落盘，但数据库提交因连接中断而无法确认成功或失败
- **WHEN** 文件/元数据巡检在安全宽限期后执行
- **THEN** 系统先确认没有数据库记录引用该物理文件，再将其作为孤儿文件清理
- **AND** 无法证明无引用时保留文件并记录不含敏感路径内容的诊断事件

## ADDED Requirements

### Requirement: 文档解析与写回受取消和资源预算约束
系统 MUST 对 Word/Excel 解析、预览、写回和结果生成传播取消信号，并限制同时执行的高成本文档操作及单文件结构预算。

#### Scenario: 等待文档处理预算时取消
- **GIVEN** 当前文档处理并发已达到配置上限
- **WHEN** 等待中的请求被取消
- **THEN** 系统终止等待且不开始解析或写回
- **AND** 释放已取得的临时资源

#### Scenario: 解析或写回期间取消
- **WHEN** Word/Excel 操作处理到可安全检查取消的表格或行批次边界
- **THEN** parser 或 writer 检查并传播取消
- **AND** 不发布未完成的结果文件

#### Scenario: 文档结构超过预算
- **WHEN** 文档的解压大小、表格数、行列数、单元格长度或等价结构指标超过配置预算
- **THEN** 系统以明确错误拒绝继续处理
- **AND** 不因无界内存分配或无界并行导致进程失稳
