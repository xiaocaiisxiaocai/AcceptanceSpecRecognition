## ADDED Requirements

### Requirement: 关键用户工作流具备真实浏览器回归验证
系统 MUST 使用真实浏览器自动化验证用户可见的关键工作流，而不是只依赖源码字符串断言或组件级模拟。

#### Scenario: 导入与智能填充浏览器回归
- **WHEN** CI 运行关键浏览器 E2E
- **THEN** 自动化用户可以使用合成文档完成登录、上传、结构识别/映射、导入确认、智能填充确认和结果下载
- **AND** 测试验证页面状态、接口结果与下载产物的一致性

#### Scenario: BatchReply 与权限拒绝浏览器回归
- **WHEN** CI 运行 BatchReply 和权限路径 E2E
- **THEN** 自动化用户可以完成来源/目标上传、预览、执行和下载
- **AND** 缺少权限的用户看到明确拒绝且不能触发受限操作

#### Scenario: 浏览器测试失败保留诊断信息
- **WHEN** 浏览器 E2E 失败
- **THEN** CI 保存必要的截图、trace 与脱敏日志
- **AND** fixture 与诊断产物不包含真实业务样本或密钥
