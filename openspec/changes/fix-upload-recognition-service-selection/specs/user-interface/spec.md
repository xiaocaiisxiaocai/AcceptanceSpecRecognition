## ADDED Requirements

### Requirement: 文件上传与表结构读取状态独立展示
系统 SHALL 在数据导入和智能填充页面分别展示文件保存与表结构读取状态，并在文件保存成功后立即停止上传中提示。

#### Scenario: 上传成功后读取表结构
- **GIVEN** 文件保存接口已经成功返回
- **WHEN** 页面开始读取工作表或表格结构
- **THEN** 上传卡显示“文件已上传”
- **AND** 页面单独显示“正在读取工作表结构”
- **AND** 读取成功后显示实际表格数量

#### Scenario: 表结构读取失败可重试
- **GIVEN** 文件已经上传成功
- **AND** 表结构读取发生超时或网络错误
- **WHEN** 页面展示失败状态
- **THEN** 页面保留已上传文件
- **AND** 明确提示表结构读取失败
- **AND** 提供重试表结构读取的操作

#### Scenario: 同一文件不重复读取表结构
- **GIVEN** 同一文件的表结构请求正在进行或已经成功
- **WHEN** 页面步骤切换或隐藏的表选择组件挂载
- **THEN** 页面复用进行中的请求或已有结果
- **AND** 不得为同一文件重复发起表结构读取

### Requirement: 表结构就绪后才允许智能识别
系统 MUST 在表结构读取完成前阻止用户发起智能结构识别，并说明当前等待阶段。

#### Scenario: 读取期间识别按钮禁用
- **GIVEN** 文件已上传但表结构仍在读取
- **WHEN** 用户查看智能识别操作
- **THEN** 识别按钮处于禁用状态
- **AND** 页面说明需等待工作表结构读取完成

### Requirement: 智能结构识别默认使用可用 AI 服务
系统 SHALL 在数据导入和智能填充页面提供一致的 AI 增强开关；存在可用 LLM 时每次新文件流程默认开启并自动采用 AI 服务配置中优先级最高的服务，不要求业务用户选择模型；没有可用 LLM 时提示配置并自动回退规则识别。

#### Scenario: 存在可用服务时默认开启
- **GIVEN** 至少存在一个已启用且用途为 LLM 的服务
- **WHEN** 用户进入新文件识别流程
- **THEN** 页面默认开启 AI 增强
- **AND** 在内部自动采用排序后优先级最高的可用 LLM
- **AND** 页面不得展示服务选择下拉
- **AND** 页面可以只读方式说明当前自动采用的服务
- **AND** 识别请求显式提交该服务标识

#### Scenario: 用户关闭时提交规则识别
- **GIVEN** 用户主动关闭 AI 增强
- **WHEN** 用户发起智能结构识别
- **THEN** 请求明确提交关闭 LLM 辅助
- **AND** 页面不要求用户选择 Qwen、DeepSeek 或其他 LLM

#### Scenario: 没有可用服务时回退规则识别
- **GIVEN** 没有已启用且用途为 LLM 的服务，或服务列表加载失败
- **WHEN** 用户进入新文件识别流程
- **THEN** 页面关闭并禁用 AI 增强开关
- **AND** 明确提示当前使用规则识别
- **AND** 有 AI 服务配置权限时提供前往配置页的入口

#### Scenario: 开启时必须存在一个可用 LLM
- **GIVEN** 用户开启 AI 增强
- **WHEN** 用户准备发起智能结构识别
- **THEN** 系统只从已启用且用途为 LLM 的服务中采用优先级最高项
- **AND** 没有可用服务时识别按钮不可用并给出提示
- **AND** 请求只提交系统自动采用的一个服务标识
