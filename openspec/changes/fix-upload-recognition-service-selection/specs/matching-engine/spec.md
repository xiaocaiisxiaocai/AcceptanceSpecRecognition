## ADDED Requirements

### Requirement: 智能结构识别限制 LLM 调用范围
系统 MUST 将智能结构识别的 LLM 调用限制为用户明确选择的服务，并在同一文档内共享失败状态，避免一个故障服务按表格重复超时。

#### Scenario: 未开启辅助时调用预算为零
- **GIVEN** 智能结构识别未开启 LLM 辅助
- **WHEN** 文档包含多个表格或工作表
- **THEN** 每个表格均只执行确定性识别
- **AND** 整个请求的 LLM 调用次数为零

#### Scenario: 认证或连接失败后停止后续调用
- **GIVEN** 多表文档开启 LLM 辅助并选择一个服务
- **AND** 第一次 LLM 调用发生认证失败、连接失败或超时
- **WHEN** 系统继续处理文档剩余表格
- **THEN** 后续表格不得再次调用该 LLM
- **AND** 后续表格继续生成确定性识别结果
- **AND** 系统不得切换到其他 LLM 服务

#### Scenario: 所选服务成功时仍受调用预算约束
- **GIVEN** 所选 LLM 服务可用
- **WHEN** 多个歧义表格需要辅助裁决
- **THEN** 系统只在现有共享调用预算内调用所选服务
- **AND** 预算耗尽后继续使用确定性结果
