## MODIFIED Requirements

### Requirement: 智能结构确认卡以业务范围作为唯一编辑入口
系统 SHALL 允许用户在范围摘要中按表头选择字段列，并允许用户在范围摘要旁打开区域调整界面按坐标编辑；系统内部兼容字段 SHALL 由最终表头选择和坐标范围同步反推，不得形成互不一致的两套配置。

#### Scenario: 按表头选择并保留坐标展示
- **GIVEN** Excel 区域的最下面一行有效表头包含“功能项目”“需求说明”“设备信息点需求”和“说明”
- **WHEN** 页面展示该区域的项目、规格、验收和备注映射
- **THEN** 每个字段以“字段角色[表头标题]”形式提供表头下拉选择
- **AND** 下方继续纵向显示对应 A1 起止坐标
- **AND** 用户切换表头后，系统同步更新该字段的实际列与 A1 坐标

#### Scenario: 按坐标调整并同步表头
- **WHEN** 用户点击“调整范围”
- **THEN** 页面继续允许按 `C9:C112` 格式新增、删除和修改项目、规格、验收及备注范围
- **AND** 保存坐标后，确认卡根据实际列同步显示对应的表头标题
- **AND** 项目范围留空时系统将该区域反推为仅规格模式，项目范围非空时反推为普通模式
- **AND** 保存前页面校验格式、跨列、范围越界、反向、字段行号不一致、重复列和区域重叠

#### Scenario: 多行与合并表头生成候选
- **GIVEN** Excel 区域存在多行或合并表头
- **WHEN** 系统生成可选择的表头标题
- **THEN** 系统使用数据区上方最下面一行有效表头
- **AND** 同一个合并表头只显示一个候选标题
- **AND** 无有效标题的列仍可通过坐标范围配置

#### Scenario: Word 继续使用原有范围配置
- **GIVEN** 当前文件不是 Excel
- **WHEN** 用户调整结构范围
- **THEN** 页面继续使用真实行号和字段列配置
