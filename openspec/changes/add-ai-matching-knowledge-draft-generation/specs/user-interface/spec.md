## MODIFIED Requirements
### Requirement: 配置管理界面
系统 SHALL 提供 AI 服务与文本处理的 Web 配置页面，并支持在匹配知识配置页中通过 AI 生成可审核的自定义知识草稿。

#### Scenario: AI服务配置
- **WHEN** 用户访问AI配置页面
- **THEN** 系统显示AI服务列表并支持新增、编辑、删除

#### Scenario: 连接测试
- **WHEN** 用户点击测试连接按钮
- **THEN** 系统测试AI服务连接并显示结果

#### Scenario: 文本处理配置
- **WHEN** 用户访问文本处理配置页面
- **THEN** 系统显示简繁转换、同义词、OK/NG等配置选项

#### Scenario: 匹配知识单分类 AI 生成入口
- **GIVEN** 用户位于匹配知识配置页面的某一分类 Tab
- **WHEN** 用户点击 `AI 生成候选`
- **THEN** 系统只针对当前分类打开草稿生成弹窗
- **AND** 不会一次性生成其他分类候选

#### Scenario: 草稿审核后导入自定义扩展
- **GIVEN** 用户在草稿弹窗中完成勾选、编辑或删除
- **WHEN** 用户点击导入
- **THEN** 系统仅把选中的候选项导入当前分类的自定义扩展
- **AND** 不会改动系统内置（只读）层

#### Scenario: 临时上传文档参与草稿生成
- **GIVEN** 用户在草稿弹窗中选择临时上传文档
- **WHEN** 用户上传符合格式要求的 Word 或 Excel 文件
- **THEN** 系统允许用户选择“仅本次使用”或“保存到已上传文档”
- **AND** 该文档可作为当前分类草稿生成的输入来源
