## ADDED Requirements

### Requirement: 运行数据库强制单公司不变量

系统 MUST 在进入就绪状态前确认运行数据库恰好存在一个公司根记录。

#### Scenario: 公司根记录数量异常

- **WHEN** 数据库包含零个或多个公司根记录
- **THEN** 就绪检查失败且业务流量不被接入
- **AND** 系统只报告计数与诊断标识，不自动创建、删除或合并公司数据

### Requirement: 安全上下文变更使旧会话及时失效

系统 MUST 在账号状态、角色或组织关系变化后使旧安全上下文失效。

#### Scenario: 管理员调整用户角色

- **WHEN** 用户角色、组织或启用状态被修改
- **THEN** 旧访问令牌在下一次受保护校验时被拒绝或在短时上限内失效
- **AND** 该用户的活动刷新会话被撤销

### Requirement: 本地账号密码最小长度统一为四位

系统 MUST 对种子账号、管理员创建用户和重置密码采用一致的 4 到 200 个字符长度边界。

#### Scenario: 设置四位密码

- **WHEN** 运维配置四位种子账号密码，或管理员创建用户、重置密码时提交四位新密码
- **THEN** 系统接受该密码并仅持久化安全哈希

#### Scenario: 设置不足四位的密码

- **WHEN** 任一新密码少于四个字符
- **THEN** 系统拒绝请求或启动配置
- **AND** 前后端显示一致的最小长度提示
