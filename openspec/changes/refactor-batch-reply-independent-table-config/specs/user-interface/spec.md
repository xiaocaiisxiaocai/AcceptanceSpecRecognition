## ADDED Requirements

### Requirement: 批量回复页面支持来源与目标逐表独立配置
系统 SHALL 在“批量回复”页面中同时支持来源文件和目标文件的逐表独立配置，而不是只复用来源表配置。

#### Scenario: 来源文件逐表独立配置
- **GIVEN** 用户已上传来源文件
- **WHEN** 用户进入来源配置区域
- **THEN** 页面按来源文件的 `Sheet/表格` 展示独立配置入口
- **AND** 每张来源表都允许单独配置表头起始行、表头行数、数据起始行、项目列、规格列、验收列和备注列

#### Scenario: 目标文件逐文件逐表独立配置
- **GIVEN** 用户已上传多个目标文件
- **WHEN** 用户进入目标配置区域
- **THEN** 页面按“目标文件 -> Sheet/表格”展示多层级配置入口
- **AND** 每个目标表都允许单独配置行配置、列映射和是否参与执行

#### Scenario: 目标表允许显式选择来源表
- **GIVEN** 来源文件中存在多张来源表
- **WHEN** 用户配置某个目标表
- **THEN** 页面提供来源表选择下拉
- **AND** 默认带出首选来源表
- **AND** 用户可改为任意其他来源表

#### Scenario: Word 页面支持列映射
- **GIVEN** 来源文件或目标文件为 Word 文档
- **WHEN** 用户配置某张 Word 表格
- **THEN** 页面仍允许配置项目列、规格列、验收列和备注列
- **AND** 不要求 Word 使用固定列位

### Requirement: 批量回复页面支持按表预览而不是整批预检门禁
系统 SHALL 将批量回复的反馈方式调整为按表预览与按文件执行，不再要求用户先完成一次整批预检。

#### Scenario: 当前目标表实时预览
- **GIVEN** 用户已完成某个目标表的来源表选择和映射配置
- **WHEN** 用户点击该目标表的预览
- **THEN** 页面展示该目标表的逐行匹配与写回结果预览
- **AND** 页面展示不可写回原因（如缺列、重复键、键不一致）

#### Scenario: 页面按文件判断是否可执行
- **GIVEN** 某个目标文件下存在多张参与执行的目标表
- **WHEN** 用户准备执行批量回复
- **THEN** 页面仅在该目标文件所有参与表都配置完整且可预览时允许执行该文件
- **AND** 其他未完成配置的目标文件不影响已完成文件的执行

#### Scenario: 执行结果独立展示
- **WHEN** 用户执行批量回复
- **THEN** 页面在结果区域按目标文件和目标表展示成功/失败结果
- **AND** 用户无需回到配置区域即可查看失败原因
