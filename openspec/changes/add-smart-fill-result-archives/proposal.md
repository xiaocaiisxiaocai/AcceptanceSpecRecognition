# Change: 新增智能填充结果文件存档

## Why
当前系统已保存智能填充的执行记录与匹配回放，但最终填充后的 Word/Excel 结果文件仍依赖仅保留 24 小时的任务快照。用户无法长期查询并重新下载每一次成功填充对应的结果文件。

## What Changes
- 每次智能填充最终成功时，在服务器额外保存一份不可变的结果文件存档，并与执行记录建立唯一关联。
- 普通执行填充和“回填验收规格库后执行填充”共用同一归档规则；失败、取消或相同幂等任务重试不产生重复存档。
- 在“其他”菜单增加“填充存档”入口，提供按来源文件名、执行时间、部门和操作人查询的紧凑列表。
- 支持查看每份存档的执行摘要并重新下载当时生成的 Word/Excel 文件。
- 历史旧记录没有结果文件存档时明确显示不可下载，不伪造或重新生成历史文件。
- 普通用户只能访问本部门存档，管理员可以访问当前公司内所有部门的存档，任何角色都不能跨公司访问；存档保留 365 天。

## Impact
- Affected specs: `api`, `data-storage`, `file-storage`, `user-interface`
- Affected code: 智能填充最终提交链路、执行历史实体与迁移、文件存储、执行历史查询/下载 API、导航权限清单、`其他`菜单及填充存档页面
- Compatibility: 现有执行记录和下载接口保持可用；旧记录按无结果存档降级展示
- Storage: 每次成功填充会额外占用一份结果文件空间，清理由执行历史保留策略和孤儿文件巡检共同兜底
