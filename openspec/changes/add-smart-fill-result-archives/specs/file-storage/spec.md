## ADDED Requirements
### Requirement: 智能填充最终结果文件存档
系统 SHALL 为每次最终成功的智能填充保存一份不可变的 Word 或 Excel 结果文件存档，并使其生命周期独立于短期任务下载产物。

#### Scenario: 保存 Word 结果存档
- **WHEN** Word 智能填充最终提交成功
- **THEN** 系统将当时生成的 Word 结果文件保存到智能填充结果存档命名空间
- **AND** 存档与对应执行记录建立唯一关联

#### Scenario: 保存 Excel 结果存档
- **WHEN** Excel 智能填充最终写回和提交成功
- **THEN** 系统将本次最终 Excel 内容额外保存为结果存档
- **AND** 后续源文件变化不修改该次存档内容

#### Scenario: 失败不保留可查询存档
- **WHEN** 智能填充被取消、文件写入失败或数据库最终提交失败
- **THEN** 系统不生成可查询的成功存档记录
- **AND** 系统清理本次已创建但未被成功记录引用的文件或交由孤儿巡检回收

#### Scenario: 幂等重试不重复存档
- **GIVEN** 相同任务标识的智能填充已经成功并保存结果存档
- **WHEN** 客户端重试相同幂等请求
- **THEN** 系统返回既有任务结果
- **AND** 不创建第二份结果文件存档

#### Scenario: 存档随执行历史生命周期清理
- **WHEN** 对应执行历史超过配置的保留期限并被删除
- **THEN** 其结果存档不再作为有效业务文件保留
- **AND** 系统通过受控清理或孤儿文件巡检回收物理文件
