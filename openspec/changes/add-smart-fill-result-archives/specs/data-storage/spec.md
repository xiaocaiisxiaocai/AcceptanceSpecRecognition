## ADDED Requirements
### Requirement: 执行历史保存智能填充结果存档元数据
系统 SHALL 在智能填充执行历史中以结构化字段保存结果存档的安全引用和完整性元数据，并兼容没有存档的历史旧记录。

#### Scenario: 保存结果存档元数据
- **WHEN** 智能填充结果文件与执行记录最终提交成功
- **THEN** 执行历史保存存档相对路径、下载文件名、内容类型、文件大小和 SHA-256
- **AND** 一条执行记录最多关联一份结果存档

#### Scenario: 读取历史旧记录
- **GIVEN** 某条旧执行记录没有结果存档元数据
- **WHEN** 系统查询该记录
- **THEN** 系统仍返回原有执行摘要和回放数据
- **AND** 明确标记该记录没有可下载的结果存档
