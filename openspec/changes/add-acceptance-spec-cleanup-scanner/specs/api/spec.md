## ADDED Requirements

### Requirement: 验收规格清理扫描 API

系统 SHALL 提供受权限和数据范围保护的异步扫描 API，并返回真实任务进度和可解释的分页结果。

#### Scenario: 启动扫描
- **WHEN** 有权用户提交有效的新数据保护期和长期未引用阈值
- **THEN** 系统创建扫描任务并立即返回任务 ID
- **AND** 任务只统计该用户当前公司与组织数据范围内的 Active 规格

#### Scenario: 查询真实进度
- **WHEN** 用户查询自己有权访问的扫描任务状态
- **THEN** 响应返回任务状态、总数、已处理数和分类计数
- **AND** 进度来自服务器已完成的扫描结果而非客户端估算

#### Scenario: 分页查询分类结果
- **WHEN** 用户按建议清理、人工确认或正常分类查询扫描结果
- **THEN** 响应按稳定排序分页返回结果
- **AND** 每项包含判定原因、扫描版本、引用汇总、最近引用时间和内容时间

#### Scenario: 迁移前引用不可追溯
- **GIVEN** 某规格存在时间为空的迁移前引用基线
- **WHEN** 扫描对该规格分类
- **THEN** API 将其返回为人工确认
- **AND** 不将空引用时间表达为从未引用

#### Scenario: 取消扫描
- **WHEN** 有权用户取消仍在排队或运行的扫描
- **THEN** 系统停止后续批次并返回已处理进度
- **AND** 已产生的结果不触发任何规格清理动作

### Requirement: 验收规格隔离操作 API

系统 SHALL 提供批量忽略、隔离和恢复 API，并对每项返回独立处理结果。

#### Scenario: 批量移入隔离区
- **WHEN** 有权用户提交扫描结果项及其扫描内容版本
- **THEN** 系统逐项校验数据范围、Active 状态、版本和判定快照
- **AND** 成功项进入隔离区，失败项返回明确原因且不掩盖成功项

#### Scenario: 扫描后规格发生变化
- **GIVEN** 规格在扫描后发生内容修改或新增引用
- **WHEN** 用户按旧扫描结果尝试隔离
- **THEN** 系统返回该项冲突并要求重新扫描
- **AND** 不隔离该规格

#### Scenario: 保留当前扫描结果
- **WHEN** 用户将结果标记为保留
- **THEN** 系统只更新当前扫描项的审阅状态
- **AND** 不修改规格可用状态或后续扫描资格

#### Scenario: 忽略后续扫描
- **WHEN** 有权用户将 Active 规格标记为忽略后续扫描
- **THEN** 后续普通扫描不再返回该规格
- **AND** 操作记录操作人、时间和可选原因

#### Scenario: 恢复隔离规格
- **WHEN** 有恢复权限的用户恢复数据范围内的隔离规格
- **THEN** 规格重新成为 Active 并可被业务查询使用
- **AND** 正文、内容版本和引用历史保持不变

### Requirement: 验收规格永久删除 API

系统 MUST 仅允许对隔离期满的规格执行带二次确认和并发校验的永久删除。

#### Scenario: 隔离期未满
- **WHEN** 用户请求永久删除尚未到期的隔离规格
- **THEN** 系统拒绝请求并返回可删除时间
- **AND** 不删除任何规格或历史数据

#### Scenario: 缺少独立权限或二次确认
- **WHEN** 用户缺少永久删除权限或请求未提交明确二次确认
- **THEN** 系统拒绝永久删除
- **AND** 不以隔离或恢复权限替代永久删除权限

#### Scenario: 永久删除到期规格
- **WHEN** 有权用户二次确认删除数据范围内已到期且版本未变化的隔离规格
- **THEN** 系统在事务中删除规格及其专属版本、引用和缓存数据
- **AND** 系统保留不含规格正文的删除留痕和操作审计

#### Scenario: 越权数据不泄露
- **WHEN** 用户查询或操作数据范围外的扫描项或隔离规格
- **THEN** 系统按既有规格访问边界拒绝请求
- **AND** 响应不泄露该规格的内容、分类、引用或隔离状态
