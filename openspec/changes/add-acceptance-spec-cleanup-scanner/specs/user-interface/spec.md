## ADDED Requirements

### Requirement: 验收规格扫毒清理工作台

系统 SHALL 提供紧凑的验收规格扫毒清理界面，展示真实扫描进度、分类结果和可解释的判定依据。

#### Scenario: 开始扫描
- **WHEN** 用户从验收规格页进入扫毒清理并点击开始扫描
- **THEN** 页面展示服务器返回的已处理数、总数、百分比和分类计数
- **AND** 页面不得用与服务器进度无关的动画伪造完成比例

#### Scenario: 扫描完成查看分类
- **WHEN** 扫描任务完成
- **THEN** 页面通过分段控件提供建议清理、人工确认和正常视图
- **AND** 每个视图显示数量并使用服务端分页表格

#### Scenario: 查看判定依据
- **WHEN** 用户查看任一扫描结果
- **THEN** 页面显示判定建议、具体原因、当前与全版本引用汇总、最近引用时间和内容更新时间
- **AND** 迁移前时间不可追溯时明确显示“人工确认”，不显示“从未引用”

### Requirement: 用户显式选择保留或清理

系统 MUST 让用户逐项或批量选择处理方式，且扫描结果默认不预选、不自动清理。

#### Scenario: 默认不选择候选项
- **WHEN** 页面首次展示建议清理结果
- **THEN** 所有结果默认未勾选
- **AND** 未经用户明确操作不得进入隔离区

#### Scenario: 批量处理选择项
- **WHEN** 用户勾选一项或多项结果
- **THEN** 页面显示保留、忽略后续扫描和移入隔离区操作
- **AND** 操作只作用于本次明确选择的项目

#### Scenario: 部分项目处理失败
- **WHEN** 批量隔离中部分规格因版本变化或权限变化失败
- **THEN** 页面分别显示成功数量和失败项目原因
- **AND** 保留失败项目的选择以便用户重新扫描或处理

### Requirement: 验收规格隔离区界面

系统 SHALL 在同一清理工作台提供隔离区，允许恢复以及在到期后永久删除规格。

#### Scenario: 查看隔离区
- **WHEN** 有权用户切换到隔离区
- **THEN** 页面分页展示隔离原因、隔离人、隔离时间、可永久删除时间和当前状态
- **AND** 未到期项目的永久删除操作保持禁用并说明到期时间

#### Scenario: 恢复隔离规格
- **WHEN** 用户选择隔离规格并确认恢复
- **THEN** 页面调用恢复操作并从隔离列表移除成功项
- **AND** 页面提示该规格已重新参与正常业务查询

#### Scenario: 二次确认永久删除
- **WHEN** 用户对到期规格点击永久删除
- **THEN** 页面展示不可恢复警告和待删除数量
- **AND** 只有用户再次明确确认后才提交永久删除请求

### Requirement: 扫毒效果保持企业后台密度

系统 SHALL 通过扫描图标、线性进度和语义状态形成扫毒体验，同时遵守现有后台视觉与密度规范。

#### Scenario: 扫描中的视觉反馈
- **WHEN** 扫描正在运行
- **THEN** 页面展示稳定尺寸的扫描状态、线性进度、已处理数量和取消操作
- **AND** 主表格和工具栏不因进度变化发生布局跳动

#### Scenario: 紧凑工作型布局
- **WHEN** 用户在桌面或移动视口访问清理工作台
- **THEN** 页面使用现有中性与语义色令牌、紧凑工具栏和单层表格布局
- **AND** 不使用嵌套卡片、大面积装饰动画或遮挡业务数据的视觉效果
