# Change: 避免生成冗余客户级列映射学习规则

## Why

当前智能结构确认会先写入客户级 `Learned` 列映射规则，即使已有启用的全局规则能够把同一匹配词映射到同一目标字段。运行时虽然会折叠重复项，但数据库和配置页面仍保留冗余记录，导致管理员误以为客户存在特殊映射，也使“删除结构模板后仍能识别”的来源难以理解。

## What Changes

- 全局启用规则已覆盖同一规范化匹配词和目标字段时，不再新增客户级学习规则。
- 全局规则与客户确认的目标字段不同时，继续保存客户级学习规则作为显式覆盖。
- 学习词提升为全局规则后，清理被该全局规则覆盖的客户级 `Learned` 冗余记录。
- 清理历史冗余记录，但保留手动规则、禁用规则、不同目标字段的客户覆盖以及无法安全判定覆盖关系的正则规则。
- 为同一规范化匹配词的学习、全局提升和清理建立串行化边界，避免并发确认重新产生冗余记录。

## Impact

- Affected specs: `data-storage`
- Affected code: 智能结构学习服务、列映射规则持久化清理、数据库迁移及相关 API/并发测试
- API 与数据库表结构不变；历史冗余学习记录会被删除，但对应的启用全局规则继续提供相同映射行为
