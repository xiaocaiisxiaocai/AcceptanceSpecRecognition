#### 3.3.3 AI 等价裁决设计（新增功能）

**触发条件**

- 当前最佳候选无硬冲突
- 当前最佳候选最终得分 ≥ 0.6（中置信门槛）

**裁决模型**

```csharp
// 等价裁决结论
public enum LlmEquivalenceVerdict
{
    Equivalent = 1,    // 等价
    Different = 2,     // 不同
    Uncertain = 3      // 不确定
}

// 等价裁决原因类型
public enum LlmEquivalenceReasonType
{
    FormatOnly = 1,           // 仅格式差异
    PunctuationOnly = 2,      // 仅标点差异
    EquivalentExpression = 3, // 等价表达
    SymbolEquivalent = 4,     // 符号等价（≈/约等于）
    SemanticDifference = 5,   // 语义差异
    SymbolConflict = 6,        // 符号冲突
    Uncertain = 7             // 无法确定
}
```

**裁决处理策略**

| 裁决结论 | 置信度 | 前端展示 | 服务端决策 |
|---------|--------|---------|-----------|
| Equivalent | 保持 | 显示"AI 判断为等价表达"提示 | autoApply（如无硬冲突） |
| Different | 降低 | 显示"AI 判断为不同"提示 | manualReview |
| Uncertain | 降低 | 显示"AI 无法确定"提示 | manualReview |

**Prompt 设计**

```
输入：
- 源项目、源规格
- 候选项目、候选规格
- 当前证据摘要、冲突状态、分数明细

输出（严格 JSON）：
{
  "verdict": "equivalent | different | uncertain",
  "reasonType": "format_only | punctuation_only | ...",
  "reason": "不超过80字的中文原因",
  "confidence": 0.0
}
```

## 4. 核心算法设计

### 4.1 Embedding 向量匹配

**算法流程**

1. 对源文本和候选文本分别计算 Embedding 向量
2. 使用余弦相似度计算相似度分数
3. 按分数降序排列，选取 Top-K 候选

**向量缓存**

```csharp
public class EmbeddingCache
{
    public int Id { get; set; }
    public int SpecId { get; set; }
    public string ModelName { get; set; }      // 模型名称
    public byte[] Vector { get; set; }         // float[] 序列化
    public DateTime CreatedAt { get; set; }
}
```

### 4.2 实体关系判别

**判别类型**

- `alias_same`：别名，同一实体
- `same`：同一实体
- `different`：不同实体
- `unknown`：无法确定

**判别流程**

1. 提取源文本和候选文本中的实体候选
2. 调用 LLM 判别实体关系
3. 根据判别结果生成证据

### 4.3 等价裁决算法

**触发条件**

```csharp
public bool ShouldTriggerEquivalenceAdjudication(MatchResult result)
{
    // 无硬冲突
    if (result.ConflictSummary.Any(c => c.Contains("conflict")))
        return false;
    
    // 达到中置信门槛
    return result.Score >= 0.6;
}
```

**裁决结果处理**

```csharp
public void ProcessEquivalenceVerdict(MatchResult result, LlmEquivalenceResult verdict)
{
    result.LlmEquivalence = verdict;
    
    switch (verdict.Verdict)
    {
        case LlmEquivalenceVerdict.Equivalent:
            // 保持置信度，添加提示
            result.Decision = result.ConflictSummary.Any() 
                ? "manualReview" 
                : "autoApply";
            break;
            
        case LlmEquivalenceVerdict.Different:
        case LlmEquivalenceVerdict.Uncertain:
            // 降低置信度，进入人工确认
            result.Decision = "manualReview";
            break;
    }
}
```
