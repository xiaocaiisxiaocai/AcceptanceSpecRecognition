> **文档版本**: V1.0

## 1. 文档概述

### 1.1 目的

本文档描述验收规格管理系统的数据库设计，包括数据库选型、实体关系、索引策略、迁移管理等。

### 1.2 数据库选型

| 属性 | 选择 |
|------|------|
| **数据库** | MySQL 8.0 |
| **ORM 框架** | Entity Framework Core 8 |
| **驱动** | Pomelo.EntityFrameworkCore.MySql 8.0.3 |
| **字符集** | utf8mb4 |
| **迁移管理** | EF Core Migrations |

### 1.3 设计原则

- Schema 变更必须通过 EF Core 迁移，禁止直接修改数据库
- 使用 Repository + UnitOfWork 模式抽象数据访问
- 数据范围按组织隔离

## 3. 核心业务表

### 3.1 验收规格表 (AcceptanceSpec)

```sql
CREATE TABLE `AcceptanceSpecs` (
    `Id` int NOT NULL AUTO_INCREMENT,
    `CustomerId` int NOT NULL,
    `ProcessId` int NULL,
    `MachineModelId` int NULL,
    `Project` varchar(500) NOT NULL,
    `Specification` varchar(2000) NOT NULL,
    `Acceptance` varchar(2000) NULL,
    `Remark` varchar(2000) NULL,
    `OwnerOrgUnitId` int NULL,
    `CreatedByUserId` int NULL,
    `WordFileId` int NOT NULL,
    `ImportedAt` datetime(6) NOT NULL,
    PRIMARY KEY (`Id`),
    INDEX `IX_AcceptanceSpecs_CustomerId` (`CustomerId`),
    INDEX `IX_AcceptanceSpecs_ProcessId` (`ProcessId`),
    INDEX `IX_AcceptanceSpecs_MachineModelId` (`MachineModelId`),
    INDEX `IX_AcceptanceSpecs_OwnerOrgUnitId` (`OwnerOrgUnitId`),
    INDEX `IX_AcceptanceSpecs_CustomerId_ProcessId` (`CustomerId`, `ProcessId`),
    CONSTRAINT `FK_AcceptanceSpecs_Customers_CustomerId` 
        FOREIGN KEY (`CustomerId`) REFERENCES `Customers` (`Id`) ON DELETE RESTRICT,
    CONSTRAINT `FK_AcceptanceSpecs_Processes_ProcessId` 
        FOREIGN KEY (`ProcessId`) REFERENCES `Processes` (`Id`) ON DELETE RESTRICT,
    CONSTRAINT `FK_AcceptanceSpecs_MachineModels_MachineModelId` 
        FOREIGN KEY (`MachineModelId`) REFERENCES `MachineModels` (`Id`) ON DELETE RESTRICT,
    CONSTRAINT `FK_AcceptanceSpecs_WordFiles_WordFileId` 
        FOREIGN KEY (`WordFileId`) REFERENCES `WordFiles` (`Id`) ON DELETE RESTRICT
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| Id | int | PK, AUTO_INCREMENT | 主键 |
| CustomerId | int | NOT NULL, FK | 客户ID（必填） |
| ProcessId | int | NULL, FK | 制程ID（可选） |
| MachineModelId | int | NULL, FK | 机型ID（可选） |
| Project | varchar(500) | NOT NULL | 项目名称（查找键） |
| Specification | varchar(2000) | NOT NULL | 规格内容（查找键） |
| Acceptance | varchar(2000) | NULL | 验收标准（填充目标） |
| Remark | varchar(2000) | NULL | 备注（填充目标） |
| OwnerOrgUnitId | int | NULL | 数据归属组织 |
| CreatedByUserId | int | NULL | 创建人 |
| WordFileId | int | NOT NULL, FK | 来源文件 |
| ImportedAt | datetime | NOT NULL | 导入时间 |

**索引设计**：

| 索引名 | 字段 | 类型 | 用途 |
|--------|------|------|------|
| IX_AcceptanceSpecs_CustomerId | CustomerId | 普通 | 客户筛选 |
| IX_AcceptanceSpecs_ProcessId | ProcessId | 普通 | 制程筛选 |
| IX_AcceptanceSpecs_CustomerId_ProcessId | CustomerId, ProcessId | 复合 | 组合筛选 |
| IX_AcceptanceSpecs_OwnerOrgUnitId | OwnerOrgUnitId | 普通 | 数据范围过滤 |

## 8. 数据库迁移

### 8.1 迁移管理

- 使用 EF Core Migrations 管理数据库结构变更
- 启动时 `DatabaseInitializer.InitializeAsync()` 自动应用待执行迁移
- Testing 环境跳过迁移自动化

### 8.2 迁移命令

```bash
# 添加迁移
dotnet ef migrations add <MigrationName> -p src/AcceptanceSpecSystem.Data -s src/AcceptanceSpecSystem.Api

# 应用迁移
dotnet ef database update -p src/AcceptanceSpecSystem.Data -s src/AcceptanceSpecSystem.Api

# 移除迁移
dotnet ef migrations remove -p src/AcceptanceSpecSystem.Data -s src/AcceptanceSpecSystem.Api
```

## 9. 数据约束

### 9.1 业务约束

| 约束 | 说明 |
|------|------|
| 客户名称唯一 | 同一公司下客户名称不能重复 |
| 用户名唯一 | 系统内用户名不能重复 |
| AI 服务名称唯一 | 服务名称不能重复 |
| 最后管理员保护 | 禁止删除或停用最后一个启用的 admin 用户 |
| 单角色约束 | 每个用户只能有一个角色 |
| 单组织约束 | 每个用户只能有一个组织归属 |

### 9.2 数据完整性

| 约束类型 | 实现方式 |
|---------|---------|
| 外键约束 | ON DELETE RESTRICT |
| 唯一约束 | UNIQUE INDEX |
| 非空约束 | NOT NULL |
| 默认值 | DEFAULT |

## 10. 数据初始化

### 10.1 默认账号初始化

当 `SystemUsers` 表为空时，自动写入默认账号：

- **admin**：管理员账号，具有所有权限
- **common**：普通用户账号

### 10.2 默认角色初始化

- **admin**：管理员角色
- **common**：普通用户角色

### 10.3 内置权限初始化

按 `IsBuiltIn = true` 标记内置权限，包括：
- 页面权限：`page:module:page` 格式
- 按钮权限：`btn:resource:action` 格式
- API 权限：`api:controller:action` 格式
