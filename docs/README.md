## 术语对照表

| 术语 | 英文 | 说明 |
|------|------|------|
| 验收规格 | Acceptance Specification | 产品或过程检验的质量标准 |
| 项目 | Project | 验收规格的分类维度 |
| 规格 | Specification | 具体的技术规格描述 |
| 验收标准 | Acceptance | 判定合格的量化标准 |
| 备注 | Remark | 补充说明信息 |
| 查找键 | Lookup Key | 用于匹配检索的字段组合 |
| 填充目标 | Fill Target | 匹配成功后写入的字段 |
| 嵌入向量 | Embedding | 文本的向量表示 |
| 等价裁决 | Equivalence Adjudication | AI 判断两文本是否等价 |
| 实体判别 | Entity Resolution | AI 判断两个实体是否指代同一对象 |

## 贡献指南

编辑文档时请遵循以下规范：

1. **版本更新**：修改版本号并添加维护记录
2. **编号规范**：需求编号按模块连续编号
3. **格式统一**：使用标准 Markdown 格式
4. **图表规范**：优先使用 Mermaid 语法，其次使用 ASCII 艺术
