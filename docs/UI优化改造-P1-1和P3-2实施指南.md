## P1-1：MatchConfig 双列网格布局优化

### 现状分析

- **文件**：`web/src/views/smart-fill/components/MatchConfig.vue`
- **行数**：939 行
- **form-item 数**：42 个
- **问题**：单列布局导致首屏只能显示 6 个参数，需要大量滚动
- **目标**：首屏显示 12+ 个参数（通过双列网格）

### 改造方案

#### 第一阶段：启用双列网格（低风险）

**1. 修改基础配置区域（line 434~700）**

将单列 `<el-form>` 改为支持双列网格的结构：

```vue
<!-- 原：单列 -->
<el-form label-width="130px">
  <el-form-item label="仅精确匹配">...</el-form-item>
  <el-form-item label="Embedding 服务">...</el-form-item>
  <el-form-item label="LLM 服务">...</el-form-item>
  <!-- 更多 item... -->
</el-form>

<!-- 新：双列网格 -->
<el-form label-width="130px">
  <el-row :gutter="20">
    <!-- 左列 -->
    <el-col :span="12">
      <el-form-item label="仅精确匹配">...</el-form-item>
      <el-form-item label="Embedding 服务">...</el-form-item>
      <el-form-item label="LLM 服务">...</el-form-item>
    </el-col>
    <!-- 右列 -->
    <el-col :span="12">
      <el-form-item label="匹配链路">...</el-form-item>
      <el-form-item label="匹配方式">...</el-form-item>
    </el-col>
  </el-row>
</el-form>
```

**分组策略**：按功能分组放入左右列

- **左列**：仅精确匹配、Embedding 服务、LLM 服务（高级设置项）
- **右列**：匹配链路、匹配方式、最小得分阈值、高置信阈值

**2. 修改阈值区域（line 517~610）**

已有双列结构，保持不变。但改进 gutter 间距：

```vue
<!-- 改前 -->
<el-row :gutter="20">
  <el-col :span="12">...</el-col>
  <el-col :span="12">...</el-col>
</el-row>

<!-- 改后（确保一致性）-->
<el-row :gutter="24">  <!-- 增加间距以提升视觉层次 -->
  <el-col :span="12">...</el-col>
  <el-col :span="12">...</el-col>
</el-row>
```

#### 第二阶段：优化提示文案（中等风险）

删除冗长的 `.form-inline-tip` 内容，改为 label 右侧 icon + popover：

```vue
<!-- 原：冗长文案占用横向空间 -->
<el-form-item label="最小得分阈值">
  <el-slider v-model="config.minScoreThreshold" ... />
  <div class="form-inline-tip">
    该阈值仅用于保留候选，不决定自动采用
  </div>
</el-form-item>

<!-- 新：icon + popover -->
<el-form-item label="">
  <template #label>
    <span>最小得分阈值</span>
    <el-popover trigger="hover" title="说明">
      <template #reference>
        <el-icon class="label-help-icon" style="cursor: help;">
          <QuestionFilled />
        </el-icon>
      </template>
      <div class="popover-tip">
        该阈值仅用于保留候选，不决定自动采用
      </div>
    </el-popover>
  </template>
  <el-slider v-model="config.minScoreThreshold" ... />
</el-form-item>
```

**新增样式**（加到 `<style scoped>` 末尾）：

```css
.label-help-icon {
  margin-left: 4px;
  font-size: 14px;
  color: var(--app-text-secondary);
}

.label-help-icon:hover {
  color: var(--app-primary);
}

.popover-tip {
  font-size: 12px;
  line-height: 1.6;
  color: var(--app-text-secondary);
}
```

**受影响的 form-item**（按优先级）：

| Item | 说明 | 优先级 |
|------|------|--------|
| 仅精确匹配 | 开启后无需 AI/Embedding... | P1 |
| 匹配链路 | 固定执行 Embedding 召回... | P1 |
| 匹配方式 | 允许项目不一致时按规格命中 | P1 |
| 最小得分阈值 | 仅用于保留候选... | P2 |
| 高置信阈值 | 会参与确定性自动通过... | P2 |
| 过滤空行 | 关闭后保留空行 | P3 |
| 确定性自动通过 | 无硬冲突且达到高置信... | P2 |
| LLM 语义优先 | 开启后 LLM 裁决最高权威... | P2 |
| 语义召回下限 | Embedding 分≥此值的候选... | P2 |
| 高Emb自动通过 | 候选 Embedding≥此值... | P2 |

## P3-2：PureTableBar 集成到高频 CRUD 页面

### 现状分析

- **涉及页面**：
  - `web/src/views/base-data/customers/index.vue`
  - `web/src/views/base-data/processes/index.vue`
  - `web/src/views/base-data/machine-models/index.vue`

- **功能需求**：
  - 密度切换（default / small / large）
  - 列可见性控制
  - 全屏显示

- **现状问题**：列定义嵌入模板，无法动态控制

### 改造方案

#### 改造步骤（以 customers 为例）

**1. 导入 PureTableBar 和 icon**

```typescript
import { PureTableBar } from "@/components/RePureTableBar";
import { QuestionFilled } from "@element-plus/icons-vue";
```

**2. 定义列配置（script 内）**

```typescript
// 列配置
const tableColumns = ref([
  {
    label: "ID",
    prop: "id",
    width: 80,
    hide: !canDelete.value
  },
  {
    label: "客户名称",
    prop: "name",
    minWidth: "min(200px, calc(100vw - 32px))"
  },
  {
    label: "创建时间",
    prop: "createdAt",
    width: "min(180px, calc(100vw - 32px))",
    formatter: (row: Customer) => new Date(row.createdAt).toLocaleString()
  },
  {
    label: "操作",
    prop: "operation",
    width: "min(150px, calc(100vw - 32px))",
    fixed: "right",
    hide: !hasOperationActions.value,
    // slot 处理器，在模板中定义
  }
]);

// 表格 ref（用于全屏）
const tableRef = ref();
```

**3. 修改表格部分模板**

```vue
<!-- 原：硬编码列 -->
<el-table-column prop="id" label="ID" width="80" />
<el-table-column prop="name" label="客户名称" ... />

<!-- 新：使用 PureTableBar 动态列 -->
<template v-for="column in tableColumns" :key="column.prop">
  <el-table-column
    v-if="!column.hide"
    v-bind="column"
  >
    <!-- 操作列的特殊处理 -->
    <template v-if="column.prop === 'operation'" #default="{ row }">
      <el-button v-if="canUpdate" type="primary" link @click="handleEdit(row)">
        编辑
      </el-button>
      <el-button v-if="canDelete" type="danger" link @click="handleDelete(row)">
        删除
      </el-button>
    </template>
  </el-table-column>
</template>
```

**4. 在工具栏集成 PureTableBar**

```vue
<template #header>
  <div class="simple-crud-toolbar">
    <PureTableBar
      title="客户列表"
      :columns="tableColumns"
      :table-ref="tableRef"
      @refresh="loadData"
    />
    <!-- 原有搜索/操作区保留 -->
    <el-form class="simple-crud-search" :inline="true">
      <!-- ... 原有搜索框 ... -->
    </el-form>
    <div class="simple-crud-actions">
      <!-- ... 原有操作按钮 ... -->
    </div>
  </div>
</template>
```

**5. 修改表格 ref 绑定**

```vue
<el-table
  ref="tableRef"
  v-loading="loading"
  :data="tableData"
  height="100%"
  stripe
  @selection-change="handleSelectionChange"
>
```
