> **文档版本**: V1.0

## 1. 文档概述

### 1.1 目的

本文档是验收规格管理系统的需求规格说明书（SRS），详细定义系统的功能需求、非功能需求、数据需求和接口需求，作为开发、测试和验收的基准依据。

本文档与以下文档配合使用：

| 配套文档 | 侧重内容 |
|---------|---------|
| 需求分析文档.md | 业务背景、痛点、用例分析、需求来源 |
| 功能设计说明书.md | 技术架构、模块设计、算法设计 |
| 数据库设计说明书.md | 数据模型、索引策略、迁移管理 |

### 1.2 范围

本文档覆盖系统的所有功能需求规格，包括：
- 基础数据管理功能
- 文档导入导出功能
- 智能匹配与填充功能
- 配置管理功能
- 权限管理功能
- 审计日志功能

### 1.3 术语定义

本文档使用的关键术语定义如下：

| 术语 | 定义 |
|------|------|
| 验收规格 | Acceptance Specification，产品或过程检验的质量标准 |
| 查找键 | 用于匹配检索的字段组合（项目 + 规格） |
| 填充目标 | 匹配成功后写入的字段（验收标准 + 备注） |
| 等价裁决 | AI 判断两文本是否语义等价 |
| Embedding | 文本的向量表示，用于相似度计算 |

## 2. 功能需求规格

### 2.1 基础数据管理模块

#### 2.1.1 客户管理

**FR-CUS-001**: 系统应提供客户列表查询功能
- 支持分页展示，每页默认 20 条
- 支持按客户名称关键词搜索
- 返回字段：Id、Name、CreatedAt

**FR-CUS-002**: 系统应提供客户新增功能
- 客户名称不允许为空
- 客户名称在同一系统中唯一
- 创建后返回新记录的完整信息

**FR-CUS-003**: 系统应提供客户编辑功能
- 仅允许修改客户名称
- 不允许修改为已存在的客户名称

**FR-CUS-004**: 系统应提供客户删除功能
- 删除前检查是否存在关联的验收规格
- 存在关联数据时拒绝删除，返回错误信息
- 删除成功后返回操作结果

#### 2.1.2 制程管理

**FR-PRO-001**: 系统应提供制程列表查询功能
- 支持分页展示，每页默认 20 条
- 支持按制程名称关键词搜索
- 返回字段：Id、Name、CreatedAt

**FR-PRO-002**: 系统应提供制程新增功能
- 制程名称不允许为空
- 返回新记录的完整信息

**FR-PRO-003**: 系统应提供制程编辑功能
- 仅允许修改制程名称

**FR-PRO-004**: 系统应提供制程删除功能
- 删除前检查是否存在关联的验收规格
- 存在关联数据时拒绝删除

#### 2.1.3 机型管理

**FR-MOD-001**: 系统应提供机型列表查询功能
- 支持分页展示，每页默认 20 条
- 支持按机型名称关键词搜索
- 返回字段：Id、Name、CreatedAt

**FR-MOD-002**: 系统应提供机型 CRUD 功能
- 新增、编辑、删除操作
- 机型名称不允许为空

#### 2.1.4 验收规格管理

**FR-SPEC-001**: 系统应提供验收规格列表查询功能
- 按客户 + 制程组合筛选（必选客户，可选制程）
- 支持分页展示，每页默认 50 条
- 支持按项目名称关键词搜索
- 返回完整规格字段：Id、CustomerId、ProcessId、MachineModelId、Project、Specification、Acceptance、Remark、ImportedAt

**FR-SPEC-002**: 系统应提供验收规格编辑功能
- 允许修改：Project、Specification、Acceptance、Remark、MachineModelId
- 不允许修改：CustomerId、ProcessId、WordFileId、ImportedAt

**FR-SPEC-003**: 系统应提供验收规格删除功能
- 删除时同步删除关联的 Embedding 缓存记录

**FR-SPEC-004**: 系统应提供 AI 语义搜索功能
- 基于 Embedding 向量相似度搜索
- 返回 Top-K 相似结果
- 支持设置相似度阈值

**FR-SPEC-005**: 系统应提供验收规格统计功能
- 按客户统计规格数量
- 按制程统计规格数量
- 返回统计数据

### 2.2 文档导入模块

#### 2.2.1 文件上传

**FR-IMP-001**: 系统应支持 Word 文档 (.docx) 上传
- 支持文件大小不超过 10MB
- 上传后返回 FileId 用于后续操作
- 自动检测文件类型

**FR-IMP-002**: 系统应支持 Excel 文档 (.xlsx) 上传
- 支持文件大小不超过 10MB
- 上传后返回 FileId 用于后续操作
- 自动检测文件类型

**FR-IMP-003**: 系统应支持文件哈希去重
- 使用 SHA256 计算文件哈希
- 已存在的文件返回原有 FileId，不重复存储

#### 2.2.2 表格预览

**FR-IMP-006**: 系统应提供表格列表查询功能
- 返回文档中所有表格的索引和基本信息
- Word 返回段落数和行数估计
- Excel 返回 Sheet 名称列表

**FR-IMP-007**: 系统应提供表格内容预览功能
- 默认预览前 10 行数据
- 支持指定预览行数
- 返回行列数据用于配置列映射

#### 2.2.3 列映射配置

**FR-IMP-008**: 系统应支持自动列映射
- 根据列映射规则自动识别表头
- 支持的映射类型：项目(Project)、规格(Specification)、验收(Acceptance)、备注(Remark)
- 匹配模式：Contains（包含）、Equals（完全匹配）、Regex（正则表达式）

**FR-IMP-009**: 系统应支持手动列映射
- 用户手动指定各列的映射类型
- 必须指定项目列和规格列
- 验收列和备注列为可选

**FR-IMP-010**: 系统应校验列映射完整性
- 项目列未指定时拒绝导入
- 规格列未指定时拒绝导入

#### 2.2.4 数据导入

**FR-IMP-011**: 系统应提供数据导入功能
- 根据列映射提取表格数据
- 关联客户和制程信息
- 记录来源文件信息

**FR-IMP-012**: 系统应计算并存储 Embedding 向量
- 组合 Project + Specification 作为向量计算文本
- 使用配置的 Embedding 服务计算向量
- 存储向量到 EmbeddingCache 表

#### 2.2.5 疑似重复检测

**FR-IMP-013**: 系统应检测完全匹配重复
- 检查 Project + Specification 是否已存在
- 规则命中优先于 AI 判断

**FR-IMP-014**: 系统应支持 AI 辅助疑似重复判断
- 对相似但不完全匹配的记录调用 LLM
- LLM 返回判断结果：alias_same（别名）、same（同一）、different（不同）、unknown（无法确定）
- 仅 alias_same 和 same 判定为疑似重复

**FR-IMP-015**: 系统应提供冲突处理选项
- 覆盖已有记录
- 保留已有记录
- 取消导入该行

### 2.3 智能匹配模块

#### 2.3.1 匹配配置

**FR-MAT-001**: 系统应支持配置 Embedding 服务
- 从 AI 服务配置中选择 Embedding 服务
- 使用该服务计算源文本向量

**FR-MAT-002**: 系统应支持配置 LLM 服务
- 从 AI 服务配置中选择 LLM 服务
- 用于实体判别和等价裁决

**FR-MAT-003**: 系统应支持配置召回参数
- TopK：召回的候选数量，默认 2
- MinScoreThreshold：召回准入阈值，默认 0.3
- HighConfidenceThreshold：高置信阈值，默认 0.98
- AmbiguityMargin：歧义分差，默认 0.02

**FR-MAT-004**: 系统应支持配置实体判别
- UseLlmEntityResolution：是否启用，默认关闭
- LlmEntityResolutionTopCandidates：判别候选数，默认 2

#### 2.3.2 匹配流程

**FR-MAT-005**: 系统应执行文本归一化
- 最小安全归一化处理
- 去除无关字符，保留语义等价信息

**FR-MAT-006**: 系统应计算 Embedding 向量
- 使用配置的 Embedding 服务
- 对源文本和候选文本分别计算

**FR-MAT-007**: 系统应执行 TopK 召回
- 使用余弦相似度计算分数
- 按分数降序排列
- 返回 TopK 候选

**FR-MAT-008**: 系统应过滤低于阈值的候选
- 低于 MinScoreThreshold 的候选不进入后续流程
- 无候选时返回空结果

#### 2.3.3 证据提取

**FR-MAT-009**: 系统应提取数值约束证据
- 识别源文本和候选文本中的数值约束
- 比较数值约束是否兼容

**FR-MAT-010**: 系统应提取实体证据
- 识别型号、料号、品牌、单位等实体
- 比较实体是否相同

**FR-MAT-011**: 系统应生成证据摘要
- 汇总所有证据提取结果
- 按证据类型分组说明

#### 2.3.4 AI 实体关系判别

**FR-MAT-012**: 系统应支持 AI 实体关系判别
- 仅当 UseLlmEntityResolution 为 true 时启用
- 对 TopK 候选执行判别
- 返回判别结果和置信度

**FR-MAT-013**: 系统应处理判别结果
- alias_same：作为同义实体处理
- same：作为同一实体处理
- different：降低该候选分数
- unknown：保持原有分数

#### 2.3.5 AI 等价裁决

**FR-MAT-014**: 系统应支持 AI 等价裁决
- 触发条件：当前最佳候选无硬冲突 且 最终得分 ≥ 0.6
- 对当前最佳候选执行裁决

**FR-MAT-015**: 系统应解析裁决结果
- 裁决结论：Equivalent、Different、Uncertain
- 原因类型：FormatOnly、PunctuationOnly、EquivalentExpression、SymbolEquivalent、SemanticDifference、SymbolConflict、Uncertain
- 裁决原因：不超过 80 字的中文描述

**FR-MAT-016**: 系统应根据裁决结果调整决策
- Equivalent：保持置信度，无冲突时 autoApply
- Different：降低置信度，转 manualReview
- Uncertain：保持分数，转 manualReview

#### 2.3.6 匹配决策

**FR-MAT-017**: 系统应生成最终匹配决策
- autoApply：自动采用
- manualReview：需要人工确认

**FR-MAT-018**: 系统应计算置信度等级
- 高置信：最终得分 ≥ 0.98
- 中置信：0.6 ≤ 最终得分 < 0.98
- 低置信：最终得分 < 0.6

**FR-MAT-019**: 系统应检测高歧义状态
- 触发条件：Top1 和 Top2 分数差 ≤ AmbiguityMargin
- 标记为高歧义，强制 manualReview

#### 2.3.7 匹配预览

**FR-MAT-020**: 系统应提供批量预览功能
- 支持预览指定行范围
- 返回每行的匹配结果

**FR-MAT-021**: 预览结果应包含
- 源项目、源规格
- 匹配的项目、规格、验收、备注
- 匹配分数和分数明细
- 匹配决策（autoApply / manualReview）
- 置信度等级
- 证据摘要和冲突摘要
- 等价裁决结果（如有）
- 歧义状态

**FR-MAT-022**: 系统应提供预览统计
- 总行数
- 自动采用行数
- 人工确认行数
- 已匹配行数
- 未匹配行数

#### 2.3.8 LLM 流式复核

**FR-MAT-023**: 系统应支持 LLM 流式复核
- 仅对标记为 manualReview 的行执行
- 使用 SSE 实时推送复核进度

**FR-MAT-024**: 复核应返回
- 复核结论
- 复核原因
- 更新后的决策

#### 2.3.9 填充执行

**FR-MAT-025**: 系统应支持 Word 文档填充
- 生成新的填充结果文件
- 保留原文档样式和格式
- 提供文件下载

**FR-MAT-026**: 系统应支持 Excel 文档填充
- 修改源文件对应单元格
- 保留原文件格式
- 提供文件下载

## 3. 接口需求规格

### 3.1 统一响应格式

**IR-RESP-001**: 所有 API 应返回统一格式

```json
{
    "code": 0,
    "message": "操作成功",
    "data": {}
}
```

**IR-RESP-002**: 错误响应格式

```json
{
    "code": 40001,
    "message": "参数校验失败",
    "errors": [
        {
            "field": "name",
            "message": "名称不能为空"
        }
    ]
}
```

### 3.2 错误码定义

| HTTP 状态码 | Code | 说明 |
|------------|------|------|
| 200 | 0 | 成功 |
| 400 | 40001 | 参数校验失败 |
| 401 | 40101 | 未认证 |
| 401 | 40102 | 令牌过期 |
| 403 | 40301 | 无权限 |
| 404 | 40401 | 资源不存在 |
| 409 | 40901 | 资源冲突 |
| 500 | 50001 | 服务器错误 |

## 4. 数据需求规格

### 4.1 主数据

**DR-001**: 验收规格数据
- 按客户 + 制程维度组织
- 查找键：Project + Specification
- 填充目标：Acceptance + Remark

**DR-002**: 客户数据
- 名称唯一
- 可关联多个制程

**DR-003**: 制程数据
- 名称唯一性不限
- 必选关联客户

**DR-004**: 机型数据
- 名称唯一
- 可选关联制程

### 4.2 向量数据

**DR-010**: Embedding 向量
- 与规格记录一一对应
- 按模型名称区分
- 支持批量更新

### 4.3 配置文件

**DR-020**: AI 服务配置
- 支持多服务商
- ApiKey 加密存储

**DR-021**: Prompt 模板
- 按场景分类
- 系统模板不可删除

**DR-022**: 列映射规则
- 按优先级匹配
- 支持启用/禁用

### 4.4 权限数据

**DR-030**: 用户数据
- 用户名唯一
- 支持单角色 + 单组织

**DR-031**: 角色权限
- 支持页面级、按钮级、API 级
- 数据范围按组织隔离

### 4.5 业务数据

**DR-040**: 执行记录
- 记录完整执行过程
- 支持回放

**DR-041**: 审计日志
- 记录所有操作
- 保留期限 ≥ 180 天
