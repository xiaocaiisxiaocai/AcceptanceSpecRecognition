## ⚠️ 关于 P3-2（PureTableBar 集成）

**原计划**：在 customers/processes/machine-models 三个 CRUD 页面集成 PureTableBar（密度切换/列设置/全屏）

**现状**：**已撤销**

**原因**：
- PureTableBar 是一个独立的重型组件，包含完整的UI工具栏
- 项目现有的 `simple-crud-toolbar` 布局与 PureTableBar 的设计不兼容
- 强行集成会导致样式冲突和布局混乱
- 需要对现有页面进行大规模重构才能支持

**可选方案**（未实施）：
1. **轻量级密度切换**：纯 CSS 类切换（margin/padding/font-size），无需复杂组件
2. **完整重构**：重新设计三个 CRUD 页面使用 PureTableBar，工作量 6-8h
3. **保持现状**：现有功能已足够，密度优化通过 P1-1/P2 级改造已实现
