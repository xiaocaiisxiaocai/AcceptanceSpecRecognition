# 原子表头优先识别设计

## 背景

真实样本 `翻板机验收规范-SAC20260514.xlsx` 的第 8 行已经包含 `具體項目`、`規格`、`OK/NG`、`Remark` 等可直接映射的字段，但当前识别器仍向上合并分组标题、向下误收首条数据，最终生成 4 行复合表头并造成列映射偏移。

## 设计

1. 表头检测到评分锚点后，在既有最大表头行数窗口内查找可独立使用的原子表头。原子表头必须同时覆盖项目、规格、验收、备注四类字段，且存在重复字段标题。
2. 命中原子表头时，固定 `HeaderRowCount = 1`，`DataStartRowIndex = HeaderRowIndex + 1`，不再向上拼接分组标题或向下吞入数据行。
3. 未命中原子表头时，继续沿用现有多行表头扩展逻辑，保留真正复合表头的兼容能力。
4. 同类型字段存在多个同置信候选时，保持现有从左到右取首列的规则。因此样本会选择第一个 `規格`、第一个 `OK/NG` 和对应的 `Remark`。
5. 智能结构确认卡的配置顺序调整为：模板名、项目列、规格列、验收列、备注列、仅规格、行范围。

## 验收标准

- 样本工作表 1 返回：表头行 8、表头行数 1、数据起始行 9。
- 列映射返回：项目列 `具體項目`、规格列第一个 `規格`、验收列第一个 `OK/NG`、备注列 `Remark`。
- 既有多行表头识别用例继续通过。
- 前端确认卡中项目列位于规格列之前。
