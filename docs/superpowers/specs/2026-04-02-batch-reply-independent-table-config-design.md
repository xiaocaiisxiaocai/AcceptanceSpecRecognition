# 批量回复来源与目标逐表独立配置设计

## 背景
当前批量回复更像“把来源表配置整包复用到目标文件”的严格复用工具，但实际业务里来源文件和目标文件的 `Sheet/表格` 结构经常不一致。用户希望它改成更接近智能填充的配置体验：来源表和目标表都能各自逐表配置，目标表还能显式选择对应的来源表。

## 设计结论
- 页面改成三个顶层 Tab：`来源配置`、`目标配置`、`执行结果`
- 来源文件和目标文件都支持逐表独立配置
- 每个目标表必须显式绑定一个来源表，默认可按同索引带出
- Word 也支持列映射，不再依赖固定列位
- 预览下沉到目标表级，不再要求单独做整批预检
- 执行以“单个目标文件配置完整”为最小单元

## 关键规则
1. 匹配键仍使用 `项目 + 规格`
2. 行顺序允许不同
3. 重复键一律拒绝自动处理
4. 写回仅修改验收列与备注列，不删行不删列

## 预期收益
- 用户能直接处理多 `Sheet`、多模板轻微差异场景
- 错误反馈更接近真实问题位置，减少整批预检后再回头找表的成本
- 保持与智能填充一致的“逐表看、逐表调、逐表预览”体验
