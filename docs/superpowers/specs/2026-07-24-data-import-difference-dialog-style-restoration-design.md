# 数据导入差异确认弹窗样式恢复设计

## 背景

`DataImportDifferenceConfirmDialog.vue` 已从数据导入主页面拆为子组件，但对应的 `.difference-dialog__*`、`.difference-card__*` 与 `.difference-sheet__*` 样式仍位于父页面 `index.styles.css`，并由父页面以 `scoped` 方式加载。Vue 的 scoped 属性不会自动覆盖子组件内部 DOM，导致弹窗内容退化成近乎无样式的文本流。

## 目标

- 让差异确认弹窗恢复清晰的信息层级和双栏对比布局。
- 保持现有覆盖、部分覆盖、跳过、批量决策、分页和最终确认逻辑不变。
- 差异字段醒目标记，但不使用过量颜色或装饰。
- 在窄屏下自动切换为单栏，内容仍可读、可操作。

## 方案

采用组件样式归属方案：

1. 将仅服务于差异确认弹窗的样式从父页面 `index.styles.css` 迁移到 `DataImportDifferenceConfirmDialog.vue` 的 scoped style。
2. `DataImportDifferenceDialog.vue` 只负责 Element Plus 弹窗壳层，并通过 `:deep()` 控制弹窗主体最大高度、内边距和 footer 分隔线。
3. 弹窗内容保持三个稳定区域：
   - 顶部：风险提示、决策统计、批量操作。
   - 中部：逐条差异卡片，数据库已有数据与本次导入数据左右对照。
   - 底部：分页摘要与最终操作。
4. 每条卡片的决策按钮放在独立浅色操作带中；当前决策继续由右上角状态标签反馈。
5. 项目、规格、验收、备注以字段标签加内容的方式呈现，保留换行和长文本折行。

## 视觉规则

- 弹窗宽度沿用 `min(1100px, calc(100vw - 32px))`。
- 主体滚动区域限制在视口内，标题和 footer 不随内容滚走。
- 数据库侧使用中性灰蓝底，本次导入侧使用轻微暖色边界。
- 仅发生变化的字段使用浅黄色背景，不改变文字内容。
- 卡片间距 12–16px，圆角 8–10px，保持当前后台系统的克制风格。
- 900px 以下切换单栏；字段表格在窄屏下改为标签与值成组排列。

## 测试与验收

- 添加样式归属测试，确保差异弹窗样式存在于子组件，父页面不再保留孤立选择器。
- 运行数据导入相关定向测试、Vue 类型检查、ESLint 和 Prettier。
- 在当前 8849 页面检查弹窗：双栏对比、变化高亮、决策按钮、分页与 footer 均正常。
- 不修改导入请求、差异判定和数据库数据。
