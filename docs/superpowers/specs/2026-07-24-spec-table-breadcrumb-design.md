# 验收规格表格精简与面包屑设计

## 目标

- 表格删除 `ID`、`客户`、`机型`、`制程` 四列。
- 顶部现有分组标签改为面包屑。
- 全局搜索显示 `验收规格 / 全局搜索`。
- 选择分组后显示 `客户 / 机型 / 制程`，缺失层级使用现有的“未指定机型”“未指定制程”文案。

## 边界

- 保留选择框、项目、规格内容、验收标准、备注和操作列。
- 保留全局搜索接口、筛选条件、详情弹窗及重复排查/AI 搜索所需的客户、机型、制程数据。
- 面包屑仅用于展示当前数据范围，不改变左侧树选择或查询行为。

## 验收

- 全局搜索与分组搜索均不再渲染四个被删除列。
- 面包屑随全局搜索开关和左侧分组选择同步更新。
- 表格释放出的宽度由项目、规格内容、验收标准和备注列使用。
