# 内置角色编辑放开设计

## 背景
当前 RBAC 将内置角色 `admin/common` 视为完全只读对象，前后端都禁止编辑。这与当前“直接调整现有内置角色权限范围”的管理诉求冲突。

## 设计结论
- 放开内置角色编辑能力。
- 允许修改字段：角色名称、角色描述、状态、权限配置、验收规格数据范围与组织节点。
- 保持角色编码只读，不允许通过编辑流程改动。
- 保持内置角色删除限制不变。

## 落地方式
- 后端移除 `AuthRolesController.Update` 中针对 `IsBuiltIn` 的更新拦截。
- 前端角色管理页面移除内置角色编辑拦截和编辑按钮禁用，同时保留删除按钮禁用。
- 集成测试改为覆盖“内置角色更新成功”与“内置角色删除失败”。
